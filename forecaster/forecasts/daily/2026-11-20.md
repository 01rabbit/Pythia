## 推奨アクション
- VMware vCenter（VCF／VVF／Telco 同梱含む）を Broadcom 勧告 39495 の修正版へ即時更新し、vmdird（2012）・VAMI（5480）を許可リスト IP 以外から遮断する。侵害時は STS SAML 署名鍵・マスター鍵・PostgreSQL・NTDS の全面更新を前提に対応する。
- Cisco Expressway を X15.5.20 へ更新、または TCP 4371〜4372 を信頼済みクラスタノード以外から遮断する。Erlang システムログと内部探索を点検する。
- Apache Roller を 6.1.6／6.1.7 へ更新し XML-RPC を外部遮断する（管理画面での無効化は不十分・KEV 期限 11-21 の fc-20261118-1 検証中）。
- AVX-512 VBMI 環境の JDK 17.0.6 以降を棚卸しし Oracle CPU 等の修正版へ更新、未提供製品は -XX:-UseBASE64Intrinsics・AVX-512 無効化・露出停止を暫定策とする。
