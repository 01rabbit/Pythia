1. CVE-2026-20200 / Cisco Integrated Management Controller (IMC)
対象: UCS C-Series M7/M8 ラックサーバ（スタンドアロンモード）および同 IMC ベースの各種アプライアンス
------------------------------------------------------------

優先度: 高
CVSS: 8.8 (High)
状態: PoC公開
パッチ提供: 提供済み（Cisco 公式アドバイザリ記載の修正版（具体版数は一次情報で未確認））

【24時間以内の変化】
[Help Net Security 2026-08-06] ドイツ NSIDE ATTACK LOGIC の研究者 Christoph Peil 氏が PoC ツール「CIMCown」を GitHub で公開したと報道（採用条件F: PoC・Exploitコードの新規公開）。Cisco PSIRT は実悪用を認識していないと明記している

【概要】
Cisco IMC（Integrated Management Controller）の Web ベース管理インターフェースに存在する脆弱性で、低権限で認証済みのリモート攻撃者が基盤 OS 上で任意コマンドを実行できる。CVSS は NVD 値 8.8（AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H・出典は CNA psirt@cisco.com。NVD Primary スコアは未付与）で、ベンダー・一部メディアが 9.8 と記載する例があるが本レポートは pipeline-1-cve.md の規定により NVD を正とする。本CVEを含む Cisco の一斉ハードニングリリース（cisco-sa-hardening-imc 系・2026-08-05 16:00 GMT 公開）自体は調査窓の開始前であり、同一バッチの Cisco Catalyst SD-WAN・IOS XE 各CVEは窓外として除外した。本CVEのみ 2026-08-06 に第三者研究者による PoC ツール「CIMCown」の公開が報じられ、採用条件F（PoC新規公開）が窓内で成立したため採用する。CISA KEV 未登録・実悪用未確認、EPSS パーセンタイル 0.545（2026-08-06）。軸1は5点にとどまるが、Cisco UCS 系サーバは国内の行政・金融データセンタで広く採用されており、PoC 公開により具体的リスクが顕在化したため参考A（国内影響あり）へ昇格した。なお本CVEは悪用に有効な認証情報を要する（PR:L）ため、poc-exploitation-criteria.json の T3 採用必須条件A（無認証）を満たさず、予報化は見送り本欄の注意点に留める（教訓10）。

攻撃の流れ:
1. IMC Web 管理インターフェースへ低権限の認証済みアクセスを取得する
2. 管理インターフェース経由でコマンドインジェクションを行い基盤 OS 上で任意コマンドを実行する
3. 管理コントローラ権限を奪取し、配下サーバの構成改変・永続化の起点とする

【IoC】
IoC: 確認されず

【監視ポイント】
・UCS / IMC 管理インターフェースへの認証済みリクエストのうち、コマンド実行を伴う異常なパラメータ・短時間の多量アクセスを監視する。管理インターフェースがインターネットまたは業務 VLAN から到達可能でないかを併せて棚卸しする。
Splunk SPL: index=network sourcetype=cisco:imc OR sourcetype=cisco:ucs | stats count values(uri_path) as paths by src_ip user | where count > 50
Splunk SPL: index=proxy OR index=firewall dest_port IN (80,443) | search dest_category="management_interface" OR dest_ip IN (<IMC管理IPレンジ>) | stats dc(src_ip) as src_count by dest_ip | where src_count > 5
→ 正規の運用保守作業（ファームウェア更新・構成バックアップ）でも管理 API への連続アクセスは発生するため、保守ウィンドウ外・未登録の送信元 IP からのアクセスに絞って確認する。

【参照】
https://www.helpnetsecurity.com/2026/08/06/cisco-imc-cve-2026-20200-public-poc-exploit/
https://services.nvd.nist.gov/rest/json/cves/2.0?cveId=CVE-2026-20200

1. 対象ホストへのログイン権限またはシステムドライブへの書き込み権限を取得する

【IoC】
IoC: 確認されず

【監視ポイント】

→ 正規の追加モジュールも非標準パスに置かれる場合があるため、資産管理台帳と突合し未登録のパスからのロードのみを調査対象とする。
