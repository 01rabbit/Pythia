【概要】
2026-08-04、npmレジストリ上でkeyv@6.0.0を起点とする自己増殖型の認証情報窃取マルウェアが大規模に拡散した。BleepingComputerは本キャンペーンを「ChainDrop」と呼び、月間合計20億ダウンロードを持つ1,300超のパッケージが侵害されたと報じ、The Hacker NewsはAikidoの分類に基づき既知のShai-Huludファミリーの再来と位置づけた。侵害規模は調査機関ごとに異なり、SafeDepが420パッケージ名・1,684汚染バージョン、Aikidoが868パッケージ・1,381バージョンを報告している。侵入起点はKeyvメンテナのGitHubアカウント侵害で、正規のGitHub Actionsワークフローを悪用して悪性コードが注入され、利用者が npm install を実行した時点でペイロードが自動実行される。窃取対象はGitHub PAT／ワークフロートークン、npmトークン、AWS認証情報およびSecrets Managerの値、Kubernetesシークレット、HashiCorp Vaultトークン、データベース／Stripe／Slack／Twilio／Azure／GCPの各認証情報と広範で、GitHub Actionsランナーのメモリ読み取りも行う。加えて侵害リポジトリ内に .claude/settings.json および .vscode/tasks.json のフックを設置し、開発者が当該リポジトリを開いた際にペイロードが実行される経路を用意する。ワークスペース信頼（workspace trust）が有効な場合は自動実行がブロックされるが、信頼済みワークスペースとして開かれた場合は成立する。影響先にはDeliveroo・Ornikar・OneReach・Picsart・Qlik・ServiceTitanの各組織に紐づくパッケージが含まれる。窃取先ドメインとして npm-cache[.]com が特定され、Wiz・StepSecurity・Aikido・Socket・Ox Securityの5社がハッシュおよびネットワーク成果物を公開している。攻撃者の国家帰属を示す情報は本調査窓時点でいずれのソースからも提示されていない。

攻撃の流れ（判明分）:
1. Keyvパッケージのメンテナが保有するGitHubアカウントを侵害する
2. 当該リポジトリの正規GitHub Actionsワークフローを悪用して悪性コードを注入し、汚染バージョンをnpmへ公開する
3. 利用者が npm install を実行した時点でペイロードが自動実行され、GitHub PAT・npmトークン・AWS/Azure/GCP認証情報・Kubernetesシークレット・Vaultトークン等を窃取する
4. 窃取したnpmトークンを用いて、先行して侵害したパッケージを利用する他メンテナのパッケージへ横展開し、ワーム的に感染を拡大する
5. 侵害リポジトリに .claude/settings.json・.vscode/tasks.json のフックを設置し、開発者が信頼済みワークスペースとしてリポジトリを開いた際の再実行経路を確保する

・[ログソース / SIEM（Splunk等）] ビルド環境からの想定外ドメインへの外向き通信と、リポジトリ内フックファイルの改変を検知する
Splunk SPL: index=* sourcetype=proxy OR sourcetype=dns query="npm-cache.com" OR dest_host="npm-cache.com" | stats count by src_ip user dest_host
Splunk SPL: index=* sourcetype=ci:audit (command="npm install*" OR command="npm ci*") earliest="08/04/2026:00:00:00" | stats count values(repo) by build_agent

→ npm-cache[.]com は正規のnpmレジストリドメイン（registry.npmjs.org）と紛らわしい名称であるため、プロキシログでのタイポスクワッティング照合を優先する。CI/CDランナーからの新規外向き宛先は本来限定的であり、ビルド時間帯の新規宛先を洗い出すことで未公開の窃取先も検出できる。
