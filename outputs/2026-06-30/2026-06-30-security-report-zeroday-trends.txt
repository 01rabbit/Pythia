1. CVE-2026-46817 / Oracle E-Business Suite (EBS) - Payments / File Transmission
対象: 12.2.3〜12.2.15（2026年5月CSPU未適用環境）
------------------------------------------------------------

優先度: 緊急
CVSS: 9.8 (Critical)
状態: 実悪用確認
パッチ: 2026年5月CSPU提供済み（未適用環境が標的）

【24時間以内の変化】
[SecurityWeek 2026-06-30] Defused Cyberのハニーポットで2026-06-27に最初の実悪用観測を確認したと報告。PoC公開前の実悪用として詳報
[SecurityAffairs 2026-06-30] Oracle EBS Payments/File Transmissionモジュールへの未認証ファイル読み取り試行が継続していることを報告

【概要】
Oracle E-Business Suite（Oracle Payments / File Transmissionコンポーネント）のCVE-2026-46817（CVSS 9.8）はPoC公開前の段階から実悪用が観測されている権限管理不備・認証バイパスの脆弱性で、未認証の攻撃者がHTTPネットワークアクセスのみでOracle Paymentsインスタンスを乗っ取り可能。Defused Cyberのハニーポットは2026年6月27日に単一の発信元から6件の未認証ファイル読み取り試行を観測しており、これはOracleが2026年5月のCritical Patch Update Supplementでパッチを提供してから約6週間後、かつ公開PoCが存在しない時点での実悪用であることが特徴。財務・ERPシステムを狙う標的型の性格が強い。

攻撃の流れ:
1. 攻撃者がOracle EBS Payments/File Transmissionの公開エンドポイントへ未認証のHTTPリクエストを送信する
2. 権限管理不備を悪用してOracle Paymentsインスタンスの制御を奪取し、ファイル読み取り・書き込みを行う
3. 財務・決済データへアクセスし、C2インフラ（45.84.137.125等）へ情報を持ち出す

【暫定緩和策】
・2026年5月CSPU（Critical Patch Update Supplement）を即時適用する
・Oracle EBS Payments / File Transmissionモジュールをインターネットから直接到達不能にする（VPN・IP制限の追加）
・/OA_HTML/ibytransmit 等の関連エンドポイントへのアクセスログを6月27日以降に遡って確認する

【IoC】
IP: 45.84.137.125

【監視ポイント】
・[Oracle EBS Webサーバーログ / ネットワークフロー] 異常アクセスを監視する
Splunk SPL: index=oracle_ebs_logs request_path="/OA_HTML/ibytransmit" method=POST | stats count by src_ip, user_agent | where count > 3
Splunk SPL: index=network_logs (dest_ip="45.84.137.125" OR src_ip="45.84.137.125") | stats count by src_ip, dest_ip, dest_port
→ 未認証ユーザーエージェントからのibytransmitへの連続POSTリクエスト、および45.84.137.125との通信は即時インシデント対応へ

1. Mustang Panda（別名: TA416 / RedDelta / Bronze President / Earth Preta / 帰属: CN・高信頼度）
活動ID: MustangPanda-2026-ZohoWorkDriveIndia
------------------------------------------------------------

採用契機: P（新規マルウェア・C2手法初報）・Q（インド政府機関への侵害確認）・V（重要インフラ・政府機関への侵害）
標的: 政府機関・エネルギー（水力発電） / インド・台湾関連MOU機関
マルウェア: SHARDLOADER（ローダー）・MINIRECON（RAT）・ZOHOMURK（バックドア）

【24時間以内の変化】
[Acronis TRU 2026-06-29] インド政府機関の水力発電セクターおよび台湾とのMOU関連機関を標的とした2件の並行キャンペーンを初報。Zoho WorkDriveをC2として悪用する新マルウェアZOHOMURKを特定

【概要】
Acronis Threat Research Unitが2026-06-29に公開した分析によると、中国国家系APTグループMustang Panda（高信頼度帰属）がインド政府機関の水力発電セクターおよび台湾との協力覚書（MOU）関連機関を標的に2件の並行キャンペーンを展開している。新規ツールキットSHARDLOADER・MINIRECON・ZOHOMURKを使用し、ZOHOMURKはハードコードされたZoho OAuth認証情報を用いて攻撃者管理下のZoho WorkDriveアカウントをデッドドロップ（命令受信箱・窃取データ送信箱）として悪用する。2026年6月12日〜22日にアクティブなビーコニングが確認され、インド政府機関の上級職員端末を含む侵害がAcronisにより確認された。CERT-Inと連携して通報・対処を実施中。

攻撃の流れ（判明分）:
1. 標的のインド政府機関・水力発電セクター職員へスピアフィッシングでSHARDLOADERを配送する
2. MINIRECONで内部偵察を実施し、ZOHOMURKを展開してZoho WorkDriveアカウントをC2チャネルとして確立する
3. Zoho WorkDriveの受信箱フォルダから命令を取得し、窃取データを送信箱フォルダへアップロードして情報窃取を継続する

【新規TTP】
・[T1102] Web Service — Zoho WorkDriveを命令受信・データ送信のデッドドロップとして悪用（Acronis TRU明示）
・[T1566] Phishing — SHARDLOADER配送のための標的型フィッシング（Acronis TRU明示）

【IoC】
IoC: 確認されず（ファイル名のみ判明: SHARDLOADER・MINIRECON・ZOHOMURK）

【推奨アクション】
・Zoho WorkDriveを業務利用するインド国内・関連組織は不審なOAuthアプリ登録・未承認アカウント作成を監査する
・台湾関連MOU機関は標的型フィッシングへの警戒を強化する
・CERT-Inのアドバイザリを参照し侵害指標の照合を行う
・[プロキシログ] Zoho WorkDriveとの定期通信を監視する
Splunk SPL: index=proxy_logs dest_domain="*workdrive.zoho.com*" | stats count by src_ip, user, dest_domain | where count > 20

攻撃の流れ（判明分）:
1. GammaPhishによる標的型スピアフィッシングでウクライナ政府・軍事機関職員へ初期アクセスする
2. GammaLoadがクラウドストレージサービスをC2チャネルとして悪用し追加ペイロードをステージングする
3. GammaWormで内部ネットワークへ自己増殖し、GammaSteelでデータを窃取する

・[T1102] Web Service — 正規クラウドストレージサービスをC2チャネルとして悪用（The Hacker News報道に基づく）

・リムーバブルメディア経由の自己増殖型VBScriptワームに対するUSB制御ポリシーを強化する
・[エンドポイントログ] wscript/cscript実行を監視する
