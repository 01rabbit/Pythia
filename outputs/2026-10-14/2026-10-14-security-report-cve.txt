1. CVE-2026-104935 Ivanti Connect Secure（認証回避＋RCE の連鎖。3件目の権限昇格は未修正）（CVSS 8.6）
------------------------------------------------------------
優先度: critical  軸1=14 軸2=4  KEV登録: あり（追加 2026-10-13・期限 2026-10-16）  悪用: 確認  パッチ: あり
影響バージョン: Connect Secure 25.1.3.0 より前（CVE 記載）。22.7R2.14 以前は影響なし。Volexity が調査した侵害アプライアンスは『最新パッチ適用済み』の 22.8R2.4 で、CVE 記載の影響範囲と整合しない点は記事で未調整（THN）

【24時間以内の変化】
[CISA KEV Catalog 2026-10-13] CISA が CVE-2026-104935 を KEV へ追加（期限 2026-10-16・ランサムウェア利用: Unknown）。
[BleepingComputer / The Hacker News / SecurityWeek / Volexity 2026-10-13] Ivanti が Connect Secure のゼロデイ悪用を警告し即時パッチを要請。Volexity が3件のゼロデイ連鎖で root 権限に至る未認証 RCE を公表（UTA0576・初期悪用 2026-10-03）。

【概要】
Ivanti Connect Secure（ICS）の認証回避と RCE（CVE-2026-104935・Ivanti 評価 CVSS 8.6）が『限定的な実環境悪用』を受けて修正され、CISA が 2026-10-13 に KEV へ追加した（期限 10-16）。Volexity によれば攻撃者（UTA0576）は3件のゼロデイを連鎖させて未認証で root としてコマンドを実行し、うち2件は修正済み、権限昇格の1件は未修正（Ivanti は将来リリースで修正予定）。エクスプロイトはライブラリをメモリ上でのみ書き換え、変更した設定データを復元するため Ivanti の Integrity Checker Tool を回避し、バックドアや Web シェルも残さずコマンドごとに連鎖を再実行していた。侵害後は保存済み認証情報（LDAP ドメイン認証情報を含む）の窃取、Active Directory 内のパスワード探索、パスワードスプレーが確認された。Volexity は動機を『低い確度で金銭目的（諜報ではない）』と評価している。被害数と、アップグレードで既存の侵害が除去されるかは未公表。恒久修正が未完のため、KEV 期限内に適用できる修正に加えて露出の最小化と痕跡調査が必要。

【攻撃フロー】
1. 細工リクエストで ICS の認証を回避し（CVE-2026-104935 の1段目）、cgi-server ユーザーとしてコマンドを実行
2. 権限昇格（CVE 未付与・未修正）で root 権限を取得
3. メモリ上のみの書き換えで Integrity Checker を回避しつつ、コマンドごとに連鎖を再実行
4. 保存済み認証情報（LDAP 等）を窃取し、AD 内のパスワード探索・パスワードスプレーへ展開

【ATT&CK】
・T1190 Exploit Public-Facing Application: ICS の認証回避と RCE の連鎖を未認証で悪用（Ivanti/Volexity）
・T1068 Exploitation for Privilege Escalation: cgi-server ユーザーから root への権限昇格（未修正の3件目・Volexity）
・T1110.003 Password Spraying: 侵害後にパスワードスプレー攻撃を実施（Volexity）

【暫定緩和策】
・修正版（25.1.3.0 以降）へ即時更新する（KEV 期限 2026-10-16）。ただし3件目の権限昇格は未修正のため、更新だけでは連鎖が完全には閉じない可能性がある（推測）
・ICS の管理・ユーザー向けインタフェースの到達元を最小化し、Ivanti の追加リリースと侵害調査手順（External ICT を含む）を確認する
・LDAP 等の ICS に保存された認証情報の漏えいを前提に、サービスアカウントの資格情報をローテーションする

【IOC】
・ips: 108.165.147[.]64
・urls: /dana-na/auth/url_default/welcome.cgi（大量リクエスト）
・filenames: /data/.icscap/（ディレクトリ）

【監視】
ICS の Web ログで /dana-na/auth/url_default/welcome.cgi への大量リクエストと、URL パスと値が一致しない X-DSCGI-PATH ヘッダを確認する。/data/.icscap/ の存在を点検する。侵害後の LDAP バインドの急増・パスワードスプレーを AD 側で確認する。
Splunk SPL: index=ivanti sourcetype=ivanti:ics (uri_path="/dana-na/auth/url_default/welcome.cgi") | stats count by src_ip, uri_path | where count>100
Splunk SPL: index=ad sourcetype=WinEventLog:Security EventCode=4625 | bin _time span=10m | stats dc(user) as users count by src_ip, _time | where users>10
IOC は Volexity が調査した1件の侵害に基づく。攻撃者はバックドア・Web シェルを残さないため、ファイル検査だけでは侵害を否定できない。

2. CVE-2026-96951 Microsoft Windows Shell（コマンドインジェクションによるセキュリティ機能バイパス・Mark of the Web 回避）（CVSS 8.8）
------------------------------------------------------------
優先度: high  軸1=11 軸2=3  KEV登録: あり（追加 2026-10-13・期限 2026-10-16）  悪用: 確認  パッチ: あり
影響バージョン: Windows 各版（影響範囲の詳細は MSRC 月例アップデートを参照。本窓では未取得）

【24時間以内の変化】
[CISA KEV Catalog 2026-10-13] CISA が CVE-2026-96951 を KEV へ追加（期限 2026-10-16・ランサムウェア利用: Unknown）。
[BleepingComputer / SANS ISC 2026-10-13] Microsoft 2026年10月の月例で、実悪用が確認された Windows Shell のゼロデイとして報道。

【概要】
Microsoft の2026年10月月例（Patch Tuesday）で、Windows Shell の CVE-2026-96951（CVSS 8.8・コマンドインジェクション起因のセキュリティ機能バイパス）が『実悪用確認済み』として修正された。BleepingComputer によれば Mark of the Web（MotW）の保護を回避する。CISA が同日 KEV へ追加した（期限 2026-10-16）。攻撃者・悪用の規模・初期侵入経路（ユーザーが開くファイル形式等）は本窓の取得情報にない。MotW 回避は『ダウンロードしたファイルが警告なしに実行される』経路の前提となるため、メール添付・ダウンロードファイル経由の初期アクセスと組み合わされる可能性がある（推測）。

【攻撃フロー】
1. 細工したファイル/リンクを被害者の Windows 環境へ配布（経路は未取得）
2. Windows Shell の脆弱性で MotW によるセキュリティ警告を回避
3. 警告なしに後続のコード実行へ（詳細は未取得）

【ATT&CK】
・T1553.005 Subvert Trust Controls: Mark-of-the-Web Bypass: Windows Shell の脆弱性で Mark of the Web の保護を回避（BleepingComputer の記述）

【暫定緩和策】
・2026年10月の月例累積更新を速やかに適用する（KEV 期限 2026-10-16）
・適用までの間、インターネット経由のファイル受領経路（メール添付・ダウンロード）に対するフィルタリングとファイル実行の制限を強化する

【監視】
MotW が付与されたファイルが警告なしに実行される挙動、Explorer/Shell からの不審な子プロセス起動を監視する。
