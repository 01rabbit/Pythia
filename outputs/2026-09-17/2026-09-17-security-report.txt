1. CVE-2026-76460 / Cisco Identity Services Engine (ISE) / ISE-PIC
対象: ISE/ISE-PIC 全サポートバージョン（Cisco公式アドバイザリ参照）
------------------------------------------------------------

優先度: critical
CVSS: 10.0 (Critical)
状態: KEV登録済み / 実悪用確認 / ゼロデイ

【24時間以内の変化】
[CISA 2026-09-16] CVE-2026-76460をKEVカタログへ新規追加。連邦機関対応期限2026-09-19。
[The Hacker News / securityonline.info 2026-09-16] Cisco ISE APIの認証バイパス脆弱性が実悪用下にあると報道。

【概要】
Cisco Identity Services Engine (ISE) および ISE-PIC のAPIに認証制御不備があり、未認証のリモート攻撃者が細工したリクエストをAPIエンドポイントへ送信することで、Web管理インターフェースの認証をバイパスし対象デバイスへ不正アクセスできる。CISAは実悪用を確認しKEVカタログへ追加した（連邦機関対応期限2026-09-19）。

攻撃の流れ:
1. 未認証で細工したAPIリクエストを対象ISEエンドポイントへ送信
2. Web管理インターフェースの認証制御をバイパス
3. 管理者相当のアクセス権限で対象デバイスを不正操作

【IoC】
IoC: 確認されず

【監視ポイント】
・Cisco ISE/ISE-PIC 管理API・Web管理インターフェースへの認証なしアクセス試行を監視する
Splunk SPL: index=network_infra sourcetype=cisco:ise | search uri_path="*api*" http_status=200 auth_status=none | stats count by src_ip, uri_path
→ 正常な管理端末以外からのISE API呼び出し、認証ヘッダ欠如のリクエストを優先確認する

https://www.cisa.gov/news-events/alerts/2026/09/16/cisa-adds-two-known-exploited-vulnerabilities-catalog

2. CVE-2026-58704 / Pixel（Cellular Modem コンポーネント）

------------------------------------------------------------

優先度: critical
CVSS: 8.8 (High)
状態: KEV登録済み / 実悪用確認 / ゼロデイ

Pixel端末のセルラーモデムに論理エラーによる権限バイパスの欠陥があり、追加の実行権限やユーザー操作なしに近接・隣接した経路からの権限昇格が可能。Googleは限定的・標的型の実悪用の兆候を確認したとして2026年9月のPixelセキュリティアップデートで修正した。CISAはKEVカタログへ追加している。

1. 近接/隣接経路（セルラー通信等）からモデムの論理エラーを悪用
2. 追加権限なしに権限昇格（Escalation of Privilege）
3. 標的端末に対する限定的・標的型の侵害

【IoC】
IoC: 確認されず

【監視ポイント】

------------------------------------------------------------

優先度: high
CVSS: 9.8 (Critical)
状態: 実悪用確認

【24時間以内の変化】
[watchTowr / The Hacker News 2026-09-16] watchTowrのハニーポットが2026-09-13以降、管理者権限を偽装したJWTトークンによる実悪用試行を捕捉と報道。

【概要】
WSO2 API ManagerでJWT認証の署名検証に不備があり、サポート対象外アルゴリズムで署名されたトークンにより認証をバイパスできる。watchTowrのハニーポットが管理者権限を偽装したJWTトークンによる悪用試行を観測しており、悪用に成功すると全登録アプリケーションのAPIバックエンド・認証情報・コンシューマーキー等へアクセスされ得る。KEV登録は本日時点で未確認。

攻撃の流れ:
1. サポート対象外アルゴリズムで署名した偽造JWTトークンを作成
2. 偽造トークンでWSO2 API Managerの認証をバイパス
3. 全登録アプリケーションのAPIバックエンド・認証情報へ不正アクセス

【IoC】

【監視ポイント】
・WSO2 API Managerの認証ログで、サポート対象外アルゴリズム署名のJWTや管理者クレームを含む不審トークンを監視

→ RS256以外のアルゴリズムで署名されたトークンや、通常発行されない管理者クレームの出現を優先確認

3. アップロードしたWebシェル経由でリモートコード実行

【IoC】
Filename: shell.php

【監視ポイント】
