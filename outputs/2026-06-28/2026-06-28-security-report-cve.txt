・CVE-2026-43503 / Linux kernel (net/sched) — DirtyClone LPE
CVSS: 8.8 (High) 状態: PoC公開
Linuxカーネルnet/schedサブシステムのpedit（パケット編集）モジュールにおけるCopy-On-Write（COW）処理の競合状態（CVE-2026-43503、通称DirtyClone）。ローカル権限昇格（LPE）を可能にし、unprivileged user namespacesが有効なDebian・Ubuntu・Fedora系環境で一般ユーザーからroot権限取得が可能。JFrog Security Researchが2026年6月25日にPoCを公開し、Kubernetesマルチテナント環境でのコンテナエスケープとして注目を集めている。パッチはv7.1-rc5で提供済みだが、LTSカーネルへのバックポートは未完了の可能性がある。国内ではLinux系サーバ・コンテナ環境への影響が想定される。対処: Linuxカーネルv7.1-rc5以降へのアップデート。unprivileged user namespacesの無効化（sysctl kernel.unprivileged_userns_clone=0）による一時緩和が可能。
IoC: 確認されず

監視: [Linuxシステムコールログ / auditd] clone syscallの異常発行を監視
Splunk SPL: index=linux_audit type=SYSCALL syscall=clone | stats count by uid, auid | where uid!=0 AND count>50
→ 一般ユーザー（uid!=0）からの大量clone syscall発行はLPEエクスプロイト試行のシグナル。Kubernetesノードでは特にコンテナブレイクアウトと関連付けて調査する
