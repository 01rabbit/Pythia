軸X=7 軸Y=1  採用契機: A-R/A-S  被害: 確認された侵害・被害の報告なし（NVD/GHSA 記載の脆弱性公開のみ）

【24時間以内の変化】
[NVD / GitHub Advisory 2026-10-10] NVD に CVE-2026-108263 が公開（2026-10-09 21:17 UTC・GHSA 起点）。網羅スイープで捕捉。

【概要】
AI エージェントを構築・実行するエージェント型ワークフロー基盤 Astron Agent の 1.1.2 より前で、/console-api/workflow/code/run と /workflow/v1/run を通る既定のワークフロー・コードノード経路が、CODE_EXEC_TYPE を明示変更しない限り core/workflow/engine/nodes/code/code_node.py の LocalExecutor を選択し、動的コード実行に完全な Python 組み込みを与えるため、権限の低い認証済みユーザーが任意コードを実行できる（NVD 記述・CVSS v3.1 9.9・AV:N/PR:L/S:C）。悪用確認・PoC の報道はなく KEV 未登録。外部ソースの詳細分析は本窓で未取得のため NVD/GHSA 記載の範囲で記録する。

【監視】
Astron Agent を運用している場合、/workflow/v1/run・/console-api/workflow/code/run の呼び出し元と CODE_EXEC_TYPE 設定を確認し 1.1.2 以降へ更新する。
Splunk SPL: index=web sourcetype=access_combined (uri_path="/workflow/v1/run" OR uri_path="/console-api/workflow/code/run") | stats count by src_ip, user, uri_path
コードノードの実行はワークフロー作成者の操作として正常に発生するため、未知ユーザー・時間外・高頻度の実行を異常の起点にする。

【24時間以内の変化】
[NVD / GitHub Advisory 2026-10-10] NVD に CVE-2026-107824 が公開（2026-10-09 18:17 UTC・GHSA 起点）。網羅スイープで捕捉。

【概要】
x64dbg 向けのネイティブ Model Context Protocol（MCP）プラグイン x64dbg-MCP Server の 1.1 より前は、デバッガの全機能を HTTP と SSE で認証なしに公開し、既定で 0.0.0.0 を待ち受けるため、既定ポート（x64: 9094 / x32: 9095）へ到達できる未認証のネットワーククライアントがデバッガ経由で任意コードを実行できる（NVD 記述・CVSS v4.0 9.3・AV:N/PR:N）。悪用確認・PoC の報道はなく KEV 未登録。解析端末上の MCP サーバが LAN 全体へ露出する典型例で、AI コーディング/解析エージェント連携基盤（MCP）の既定設定リスクとして記録する（2026-09-11 OmniRoute・2026-09-16 PraisonAI 等と同系統）。

【監視】
解析端末・開発端末で TCP 9094/9095 の外部からの接続と、ローカル以外へバインドした MCP サーバの存在を確認する。
Splunk SPL: index=firewall OR index=netflow dest_port IN (9094,9095) action=allowed | stats count by src_ip, dest_ip, dest_port
MCP サーバは本来 localhost 待ち受けで足りる。LAN 内からの接続は設定ミスか横展開の可能性。
