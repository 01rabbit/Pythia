CVE-2026-132224 [9] Optimizely Web Experimentation（旧 Optimizely Experiment／A/B テスト・実験配信基盤）
------------------------------------------------------------
対象: Optimizely / ベンダー勧告参照（CISA KEV 期限 2026-11-27）
KEV 追加: 2026-11-24（FCEB 期限 2026-11-27）
【概要】
CISA は 2026-11-24、Optimizely Web Experimentation の脆弱性 CVE-2026-132224 を KEV へ追加した（期限 2026-11-27）。KrebsOnSecurity によれば、攻撃者はサイトの体験最適化・A/B テストに使われる Optimizely を悪用し、過去約 24 時間で BBC・CNN・Equifax・Ledger・Zoom を含む少なくとも 178 の著名 Web サイトが、閲覧者に対しデータ窃取型マルウェアを静かに配信していた。多くの人気サイトが第三者コンテンツの読み込み元に厳格な制限（CSP／SRI）をかけていないことが被害を拡大させたとされる。正規の実験配信基盤を経由したサプライチェーン型のブラウザ側攻撃で、影響範囲が広い。CVSS スコアは公開要約では確認できないため付与しない（行動原則1）。
【一時緩和】
  - Optimizely を修正版へ更新。第三者スクリプトの読み込み元を CSP で限定し、Subresource Integrity（SRI）を適用。実験配信タグの改ざん・不審な配信を点検する。
【TTP】
  - T1189 (initial-access): 正規の実験配信基盤を悪用し、閲覧者のブラウザへ悪性スクリプトを注入（drive-by）
【IOC】IP: なし / ファイル: なし
【監視】サイトから配信される第三者スクリプトの異常な変化、閲覧者へのマルウェア配信・データ窃取の痕跡。
  参照: https://krebsonsecurity.com/2026/11/attackers-used-optimizely-to-a-b-test-malware-on-top-websites (KrebsOnSecurity)
  参照: https://www.cisa.gov/known-exploited-vulnerabilities-catalog (CISA)

CVE-2026-132165 [8] Drupal core 11.4.13／11.3.22／10.6.22 未満（同梱インストーラ /core/install.php）
------------------------------------------------------------
対象: Drupal Security Team / Drupal core < 11.4.13／< 11.3.22／< 10.6.22（SA-CORE-2026-017）
KEV 追加: 2026-11-24（FCEB 期限 2026-11-27）
【概要】
CISA は 2026-11-24、Drupal core の同梱インストーラ呼び出しの脆弱性 CVE-2026-132165 を KEV へ追加した（期限 2026-11-27）。本脆弱性は 11-20 に本紙がトレンド欄で既報（SA-CORE-2026-017・Drupal Security Team 2026-11-18・当時は実悪用報告なし）だったもので、未認証で /core/install.php を呼び出しサイトを再インストールして乗っ取り／RCE を狙う経路を持つ。CISA の KEV 収載により実悪用が確認された扱いとなった。既定 .htaccess は必ずしも遮断せず、Web サーバーが settings.php に書込不可の構成では一部経路が塞がる。
【一時緩和】
  - Drupal core を 11.4.13／11.3.22／10.6.22 以降へ更新。/core/install.php への到達を Web サーバー設定で遮断し、settings.php への書込可否と不審な再インストール痕跡を点検する。
【TTP】
  - T1190 (initial-access): 同梱インストーラ /core/install.php を未認証で呼び出しサイト再インストール→乗っ取り／RCE
【IOC】IP: なし / ファイル: なし
【監視】/core/install.php への未認証アクセス、settings.php の改変、サイト再インストールの痕跡。
  参照: https://www.drupal.org/sa-core-2026-017 (Drupal Security Team)
  参照: https://www.cisa.gov/known-exploited-vulnerabilities-catalog (CISA)
