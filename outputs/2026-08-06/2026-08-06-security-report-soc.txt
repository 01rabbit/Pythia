2. Poison Claude: 盗用AWSクレジットを用いたClaude API不正転売・プロンプト盗聴サービス
観点: AI攻撃関連
採用契機: δ
------------------------------------------------------------

優先度: 低
対象: Anthropic Claude API / AWS Bedrock

【24時間以内の変化】
[Okta (The Hacker News経由) 2026-08-06] Okta研究者が、AWS Bedrockの新規アカウント無料クレジット($100)をプールし正規Claude API料金の5〜15%で再販する不正サービス『Poison Claude』を報告。運営者が全顧客のプロンプトを閲覧可能な構成で約870名の利用者を確認

【概要】
AWS Bedrockの新規アカウント無料クレジットを不正取得したアカウント群をプールし、Anthropic Claudeへの割安アクセスを転売するプロキシサービス『Poison Claude』が確認された。顧客はAPIキー経由でこのプロキシへリクエストを転送するため、運営者は全顧客のプロンプト内容を閲覧できる構成になっており、機密情報を含むプロンプトの窃取・悪用リスクがある。自組織の開発者が非公式・割安なLLM APIアクセスサービスを利用していないか注意喚起する価値がある。

【推奨アクション】
・開発者向けに、公式チャネル以外の割安API再販サービス利用を禁止する社内ポリシーを周知する
・[プロキシ/EGRESSログ] api.claudeopus[.]shop・poison-claude.bitsender[.]top 等の非公式ドメインへの通信有無を確認する
Splunk SPL: index=web_proxy dest_domain IN ("*claudeopus*","*bitsender*") | stats count by src_ip user dest_domain
→ 公式Anthropicエンドポイント以外へのANTHROPIC_BASE_URL等環境変数リダイレクトが確認された端末を優先調査する

【参照】
https://thehackernews.com/2026/08/poison-claude-sells-discounted-claude.html
