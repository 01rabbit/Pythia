1. CVE-2026-114625 Arista VeloCloud Orchestrator（VCO・オンプレミス版）の SQL インジェクション（read-only アカウントから operator 権限へ昇格）（CVSS 9.9）
------------------------------------------------------------
優先度: critical  軸1=14 軸2=5  KEV登録: なし  悪用: 確認  パッチ: あり
影響バージョン: 5.2 系は 5.2.3.18 未満、6.1 系は 6.1.3.10 未満、6.4 系は 6.4.2.12 未満（7.0 系は対象外・サポート終了版は Arista が未検証）。Hosted／Dedicated は修正済み。VeloCloud Gateway／Edge は対象外

【24時間以内の変化】
[The Hacker News（Arista PSIRT 引用） 2026-10-22] Arista が CVE-2026-114625（CVSS 9.9）の悪用を確認と公表。VCO での悪用確認は 7 月（CVE-2026-16812）・9 月（CVE-2026-93952）に続く3件目で、今回が初めてログインを要する。攻撃開始時期・被害組織・攻撃後の挙動は未公表。KEV 未収載（カタログ版 2026.10.21）。

【概要】
THN が引用する Arista の勧告によれば、VeloCloud Orchestrator に SQL インジェクションがあり、Enterprise Read Only（顧客ユーザーの最下位ロール）でログインできる攻撃者が local superuser（最上位の運用権限）を得られ、VCO ホストへの影響やオーケストレーターが管理するデータの漏えい・改変・妨害に至る可能性がある。VCO は既定で公開され、公開を止める設定はない。7 月・9 月の悪用済み脆弱性の修正版を適用した環境でも、今回の修正版より古ければ影響を受ける。Arista は悪用に使われた IP アドレス 2 件を公表した。攻撃者の帰属・被害件数は未公表。

【攻撃フロー】
1. VCO の Web インターフェースへ到達し、read-only 以上の有効なログインを得る（Arista 記述：最低ロールは Enterprise Read Only）
2. SQL インジェクションで operator（local superuser）権限へ昇格（Arista 記述）
3. VCO ホストや管理データへ影響しうる（Arista 記述。実際の悪用後の行動は未公表）

【ATT&CK】
- T1068 Exploitation for Privilege Escalation: SQL インジェクションにより read-only ロールから最上位の operator 権限へ昇格する（Arista の記述に基づく）。初期アクセス手段（ログイン情報の入手経路）は未公表のため付与しない

【暫定対策】
- 5.2.3.18／6.1.3.10／6.4.2.12 以降へ更新する（Hosted／Dedicated は修正済み）
- 更新までは VCO の Web インターフェースを信頼できる管理ネットワークに限定し、不明な IP からの接続を監視する
- 更新前に VCO の Web アクセスログ・バックエンドログ・システムログ等の証拠を保全する（Arista 推奨）
- ホストからの想定外の外向き通信、バックドアのデーモン・Web シェル、管理者アクティビティの不審な変更を確認する

【IOC】
- ips: 74.82.197[.]86, 38.54.50[.]151

【監視】
VCO の Web アクセスログで URL 状の異常なパス構成要素・エンコード文字・内部サービス参照・高頻度リクエスト、上記 IP からの接続を確認する。
