1. CVE-2026-114625 Arista VeloCloud Orchestrator（VCO・オンプレミス版）の SQL インジェクション（read-only アカウントから operator 権限へ昇格）（CVSS 9.9）
------------------------------------------------------------
優先度: critical  軸1=14 軸2=5  KEV登録: なし  悪用: 確認  パッチ: あり
影響バージョン: 5.2 系は 5.2.3.18 未満、6.1 系は 6.1.3.10 未満、6.4 系は 6.4.2.12 未満（7.0 系は対象外・サポート終了版は Arista が未検証）。Hosted／Dedicated は修正済み。VeloCloud Gateway／Edge は対象外

【24時間以内の変化】
[The Hacker News（Arista PSIRT 引用） 2026-10-22] Arista が CVE-2026-114625（CVSS 9.9）の悪用を確認と公表。VCO での悪用確認は 7 月（CVE-2026-16812）・9 月（CVE-2026-93952）に続く3件目で、今回が初めてログインを要する。攻撃開始時期・被害組織・攻撃後の挙動は未公表。KEV 未収載（カタログ版 2026.10.21）。

【概要】
THN が引用する Arista の勧告によれば、VeloCloud Orchestrator に SQL インジェクションがあり、Enterprise Read Only（顧客ユーザーの最下位ロール）でログインできる攻撃者が local superuser（最上位の運用権限）を得られ、VCO ホストへの影響やオーケストレーターが管理するデータの漏えい・改変・妨害に至る可能性がある。VCO は既定で公開され、公開を止める設定はない。7 月・9 月の悪用済み脆弱性の修正版を適用した環境でも、今回の修正版より古ければ影響を受ける。Arista は悪用に使われた IP アドレス 2 件を公表した。攻撃者の帰属・被害件数は未公表。

【攻撃フロー】
1. VCO の Web インターフェースへ到達し、read-only 以上の有効なログインを得る（Arista 記述：最低ロールは Enterprise Read Only）
2. SQL インジェクションで operator（local superuser）権限へ昇格（Arista 記述）
3. VCO ホストや管理データへ影響しうる（Arista 記述。実際の悪用後の行動は未公表）

【ATT&CK】
- T1068 Exploitation for Privilege Escalation: SQL インジェクションにより read-only ロールから最上位の operator 権限へ昇格する（Arista の記述に基づく）。初期アクセス手段（ログイン情報の入手経路）は未公表のため付与しない

【暫定対策】
- 5.2.3.18／6.1.3.10／6.4.2.12 以降へ更新する（Hosted／Dedicated は修正済み）
- 更新までは VCO の Web インターフェースを信頼できる管理ネットワークに限定し、不明な IP からの接続を監視する
- 更新前に VCO の Web アクセスログ・バックエンドログ・システムログ等の証拠を保全する（Arista 推奨）
- ホストからの想定外の外向き通信、バックドアのデーモン・Web シェル、管理者アクティビティの不審な変更を確認する

【IOC】
- ips: 74.82.197[.]86, 38.54.50[.]151

【監視】
VCO の Web アクセスログで URL 状の異常なパス構成要素・エンコード文字・内部サービス参照・高頻度リクエスト、上記 IP からの接続を確認する。

Storm0940-2026-ConnectWiseCloudBackup-ARTEX Storm-0940（Microsoft 追跡名）
------------------------------------------------------------
帰属: China state-aligned（Microsoft の評価）（信頼度: medium）/ 軸P=8 軸Q=7
標的: it, government, finance, manufacturing, energy, defense, legal, media / global

【24時間以内の変化】
[The Hacker News（Microsoft） 2026-10-22] Microsoft が ConnectWise Cloud Backup のサプライチェーン侵害の背後に Storm-0940 がいると公表。ARTEX による 2,250 超のテナントへのサインイン試行（毎分 2,900 回）、10-15 以降の ConnectWise クラウドアプリの ID を使った顧客環境への認証を確認。

【概要】
THN が報じた Microsoft の発表によれば、Storm-0940 は 2026 年 9 月以降、ARTEX を使って偵察・パスワードスプレー・OAuth アプリ悪用を機械速度で自動化し、複数の業種の数百組織を狙った。10-10〜14 に 144.172.64[.]99 の基盤から Microsoft 365 と Exchange Online への大量サインイン失敗（15万件超・ピーク 10-11 に毎分 2,900 件）があり、成功は検知されなかったが、10-15 に ConnectWise のクラウドアプリの ID を掌握してからは、アプリが既に持つ信頼を使って顧客テナントに認証した。一部では Microsoft Graph・ディレクトリ操作に進み、アプリ資格情報の改変で永続化を図った（初期ターゲティングから特権取得まで3時間未満の例もある）。Microsoft は ARTEX が複数地域の別の攻撃者にも使われていると説明している。

【攻撃フロー】
1. ConnectWise Cloud Backup に関連するクラウドアプリの ID を掌握（サプライチェーン侵害・詳細な経路は未確認）
2. ARTEX が盗んだアプリ資格情報で顧客テナントに認証し、Graph・ディレクトリで偵察
3. アプリ資格情報の改変・ID／グループ／特権ロールの変更で永続化・権限拡大を試みる

【TTP】
- T1110.003 Password Spraying
- T1098.001 Additional Cloud Credentials
- T1195.002 Compromise Software Supply Chain

【IOC】
- ips: 144.172.64[.]99

【推奨アクション】
Entra ID／Microsoft 365 で ConnectWise 関連アプリの同意・資格情報の変更履歴を確認し、不審なアプリ資格情報の追加・権限変更を取り消す。Microsoft 公表の IP 144.172.64[.]99 を含む、短時間に大量のサインイン失敗が出ている送信元の遮断と、パスワードスプレーの検知強化を行う。

【検知メモ】
帰属は Microsoft の評価（China state-aligned）。ATT&CK ID は情報源が明示するパスワードスプレー・アプリ資格情報の改変・サプライチェーン侵害に限って付与。

CVE-2026-109618 PHP（OOM 時の longjmp 処理＝PHP2Shell）
------------------------------------------------------------
ベンダー: PHP Group / 影響: PHP 8.5.12 未満／8.4.27 未満／8.3.36 未満／8.2.35 未満（情報源：PHP 5.4 まで遡る広範囲。8.1 以前は公式更新なし・ソースバックポートのみ）
CVSS v3: 9.8 / v4: 9.2 / KEV: 未収載 / PoC: 公開 / 実悪用: 未確認
パッチ: 8.5.12／8.4.27／8.3.36／8.2.35 以降（ディストリビューションは旧版番号のまま修正を含む場合あり）

【24時間以内の変化】
[The Hacker News（Amazon Threat Intelligence・CrowdStrike 引用） 2026-10-22] Amazon が 10-17（公開4日前）の MadPot への悪用試行を報告（匿名化ネットワーク経由・単発のプローブと説明）。THN は公開後に広範な悪用試行が出ていると報じるが、侵入成功の確認報告は確認できない。CrowdStrike は悪用の痕跡がほぼ残らないと説明。KEV 未収載（カタログ版 2026.10.21）。[既報・更新]
[Security NEXT 2026-10-22] CISA が修正プログラムの即時適用を勧告（困難な場合はインターネット公開を控えることを推奨）。

【概要】
THN によれば、PHP は OOM 時に longjmp() で現在のコンテキストを抜けるが、リクエストメモリを指すグローバル状態が残る場合があり、未認証のリモートコード実行に至る（PHP 評価 CVSS v4.0 9.2・NVD の v3.1 は 9.8）。Wiz Research・Calif・OpenAI Codex Security が発見。Calif が 10-20 に PoC 動画を誤って投稿し、watchTowr が再現。Cloudflare が事前に攻撃試行を観測、watchTowr が 10-21 14:19 UTC に悪用試行を報告した。個別サーバーでの侵入成功は未確認。オランダの DigiD 等と BambooHR が予防的に停止した。

【攻撃フロー】
1. 細工した大容量マルチパート要求などでメモリ上限に到達させる
2. longjmp による異常脱出で壊れたグローバル状態が残る
3. mod_php 等で未認証のコード実行（情報源が単一リクエストでの実証と記述）

【ATT&CK】
- T1190 Exploit Public-Facing Application: 細工したマルチパート要求等で PHP 実行環境（mod_php／PHP-FPM 等）の脆弱性を未認証で突く（情報源の記述：mod_php で単一の未認証リクエストによる実証）

【暫定対策】
- PHP を 8.5.12／8.4.27／8.3.36／8.2.35 以降へ更新する（ディストリビューションの changelog で CVE を確認）
- 暫定: memory_limit=-1 を固定し post_max_size を低く保ち、Web サーバー／プロキシでリクエストサイズを制限（RLIMIT_AS／RLIMIT_DATA は使わない）
- 更新後は新しいハードメモリ上限でプロセスが終了し得るため設定を見直す

【監視】
マルチパート要求後のメモリ上限エラー・HTTP 500 の連続、PHPSESSID の異常に大きい応答 Cookie、PHP ワーカーの原因不明の再起動を監視する。

CVE-2026-111497 Brotli デコーダー（Node.js 同梱・範囲外書込み）
------------------------------------------------------------
ベンダー: Google（Brotli）／OpenJS Foundation（Node.js） / 影響: Node.js 22.x は 22.23.4 未満、24.x は 24.22.1 未満、26.x は 26.12.1 未満（20.x 以前は EOL で修正なし）。Brotli 1.2.1／1.1.1／1.0.10 で修正
CVSS v3: None / v4: None / KEV: 未収載 / PoC: 公開 / 実悪用: 未確認
パッチ: Node.js 22.23.4／24.22.1／26.12.1、Brotli 1.2.1／1.1.1／1.0.10

【24時間以内の変化】

【暫定対策】
