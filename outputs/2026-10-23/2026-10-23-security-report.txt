AI-2026-10-23-001 Microsoft が Storm-0940 による ARTEX（agentic AI ペネトレーションテスト・フレームワーク）の悪用を公表：ConnectWise 関連攻撃で機械速度のパスワードスプレー・OAuth アプリ悪用
------------------------------------------------------------
カテゴリ: A/A4 / 軸X=8 軸Y=7
被害規模: 2,250 超のテナントへ毎分 2,900 回のサインイン試行。Microsoft は多数の業種の数百組織が標的になったと説明（成功件数は非公表）。特権取得まで3時間未満の例あり。

【24時間以内の変化】
[The Hacker News（Microsoft・Recorded Future・Zscaler） 2026-10-22] Microsoft が Storm-0940 による ARTEX 悪用を公表。Recorded Future は ARTEX を使う別クラスター TAG-217（韓国の金融機関を標的）を追跡し、Zscaler は標的が韓国以外にも広がると報告。

【概要】
THN によれば、ARTEX は Go 製の agentic AI ペネトレーションテスト・フレームワークで、韓国の金融機関への攻撃での悪用を受けてクローズドソース化された。Storm-0940 は ARTEX でスキャン・偵察・パスワードスプレー・OAuth アプリ悪用を機械速度で自動化した。Zscaler の分析した TAG-217 の ARTEX 環境では、DeepSeek・GLM・Grok を指定する設定と、調査タスクを分担して相互レビューさせるプロンプトが確認されたという（金銭目的の可能性が指摘されている）。Microsoft は複数地域の攻撃者が ARTEX を使っていると説明している。

【攻撃フロー】
1. ARTEX が偵察・パスワードスプレーを自動実行
2. 盗んだアプリ資格情報で顧客テナントへ認証し、Graph・ディレクトリを操作
3. アプリ資格情報の改変などで永続化を試みる

【監視】
短時間の大量サインイン失敗（毎分数千件規模）、既存アプリへの資格情報追加、特権ロール／グループの変更を監視する。

------------------------------------------------------------
カテゴリ: C/C3 / 軸X=6 軸Y=4
被害規模: OpenCode 1.0.137〜1.18.32 の Windows／WSL。macOS／Linux は対象外。悪用の報告なし。1.18.33（9-28）で修正済みだが CVE・勧告は未発行。

【24時間以内の変化】
[The Hacker News（Pillar Security） 2026-10-22] Pillar Security が 10-19 に公開（提案 CVSS 9.8）。Anomaly は MCP サーバーは信頼境界の外として CVE を要請していない。

【概要】
THN によれば、OpenCode は MCP サーバーが返す OAuth の認可エンドポイントを PowerShell で組み立てたコマンドへエスケープせずに渡しており、細工したアドレスで開発者のサインイン時（opencode mcp auth 等）にコードが実行される。攻撃には開発者が追加した MCP サーバーの掌握が必要で、後から乗っ取られたサーバーでも成立する。CVE が無いため脆弱性スキャナーに検出されず、バージョンを直接確認する必要がある。

【攻撃フロー】
1. 悪意ある（または乗っ取られた）MCP サーバーが細工した認可エンドポイントを返す
2. 開発者が MCP サーバーへのサインインを実行
3. PowerShell 経由でコマンドが開発者の権限で実行される

【監視】
開発端末の OpenCode のバージョンを棚卸しし、追加済み MCP サーバーの提供元を確認する。

【参照】
- OpenCode Flaw Lets Malicious MCP Servers Execute Code During Sign-In on Windows and WSL (The Hacker News) https://thehackernews.com/2026/10/opencode-flaw-lets-malicious-mcp.html
