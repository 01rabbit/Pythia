【概要】
FBI は USSS・IRS-CI とともに、Binance を巡る 60 億ドル超（THN は 64.3 億ドル、BleepingComputer は 63 億ドル）の暗号資産窃取を、北朝鮮系の TraderTraitor（Jade Sleet／Pressure Chollima／PUKCHONG／Slow Pisces／UNC4899）によるものと帰属した。11 のブロックチェーンにまたがり、82% が Ethereum と Bitcoin。史上最大の暗号資産窃取で、2025 年 2 月の Bybit（14.6 億ドル）を上回る。Elliptic は北朝鮮の累計窃取額を 65 億ドル超と推計し、今回でほぼ倍増したとする。約 28.5 億ドルが Tether・Circle・Ripple・Arbitrum・Optimism によりオンチェーンで凍結された。攻撃者は主に ETH へ換金しており、FBI は DeFi・即時スワップ経由の追加洗浄を見込む。Binance は出金を一時停止し、段階的に再開（入金は継続）。侵入経路は、前日までの報道で Binance が説明した侵害された DevOps エンジニアのノート PC が起点とされる。THN は同グループの手法として、偽リクルーター・前面会社による偽採用面接、Terraform プロバイダ経由の Bash ローダー、FLATROOF／ROOFDECK、生成 AI による誘い文句の作成を記すが、Binance 事案での使用は明示されていない。

【攻撃フロー】
1. Binance の DevOps エンジニアのノート PC が侵害されたと Binance が説明（前日までの報道）
2. 約 60 億ドル超の資産が 11 のブロックチェーンから窃取され、主に ETH へ換金（FBI・Elliptic）
3. DeFi・即時スワップ経由の追加洗浄が見込まれる（FBI の見解・推測）。約 28.5 億ドルは凍結済み

【概要】
Kaspersky は今週、アジアの政府機関だけが使うカスタム Windows 10 を標的にした「高度な感染チェーン」を公表した（THN）。未文書化の .NET アセンブリ読み込みフレームワーク NetamLoader を展開する。.config ファイルによる AppDomainManager の悪用で任意の .NET アセンブリを読み込み、正規の Patch My PC のコンポーネントに悪性ファイルを同梱して偽装する。多層のエンコード・圧縮・暗号化されたペイロード（XAML・.NET アセンブリ・JSON）を使い、AMSI をバイパスし、dllhost.exe 内で XAML を実行し、抽出ファイル・CLR 使用ログ・Prefetch を削除する。C2 へは初回に 20〜40 分のランダム待機を入れ、有効な応答後は 5〜6 分、それ以外は 22〜28 時間待機する。サプライチェーン攻撃の疑いがあるが未確認。攻撃者の帰属はなく、テレメトリ上の被害者は 1 件。

2. .config による AppDomainManager 悪用で .NET アセンブリを読み込み、AMSI をバイパスして dllhost.exe 内で XAML を実行
3. C2 をジッタ付きでポーリングし、XAML を受け取り隔離した AppDomain で実行。抽出ファイル・ログを削除

【概要】
Alpine Linux は、開発基盤の GitLab に対し 10-20〜21 に CVE-2026-97229 を狙った悪用試行があったとして、GitLab を再構築し全パスワードをリセットした（BleepingComputer）。攻撃者は細工した CI 設定を送り、ワーカーを 8 回クラッシュさせ、うち 4 回は部分的に成功したが完全な成功は確認されていない。Alpine は 10-27 までリポジトリのコミット・パッケージ・リリースの改ざんは見つかっていないとする。署名鍵は GitLab サーバー上になく露出していない。一方でログ欠落と外向き通信記録の不在によりコード実行を否定できないため、再構築を選んだ。攻撃者が GitLab のコンテナイメージをダウンロードしていた点を、記事はサプライチェーン攻撃準備の可能性として挙げる（推測）。原因は、Alpine が 19.3.4 を導入し、19.3.6 でも Ruby 側の修正が自社イメージに無かったこと。本 CVE は CISA KEV に 10-29 収載済みで、攻撃者の帰属はない。

- T1190 Exploit Public-Facing Application: HTTPS API へネットワーク到達でき、信頼済みクライアントの公開証明書を知る攻撃者が、秘密鍵なしにそのクライアントとして認証される（THN）

SOC-2026-11-02-001 GitLab CVE-2026-97229：Ruby（Onigmo）側の修正も含めて更新状況を確認し、侵害を否定できない場合は再構築と秘密情報の交換を行う
------------------------------------------------------------
対象: GitLab CE/EE（自前ビルド・カスタムコンテナ含む）

【24時間以内の変化】
[BleepingComputer 2026-11-01] Alpine Linux が悪用試行を受け GitLab を再構築。GitLab 本体の更新だけでは Ruby 側が未修正のまま残る場合があった。

【概要】
GitLab のパッチ適用後も、同梱／ベースイメージの Ruby が修正版（3.3.13 以降）でない環境は脆弱なまま残る。本 CVE は KEV 収載済みで公開 PoC もあり、CI/CD 設定を介して未認証で到達できる。

【推奨アクション】
- 1) GitLab 本体に加え Ruby の版を確認し、カスタムコンテナは alpinelinux/gitlab:19.3.6 相当の修正を取り込む。2) ログと外向き通信記録を保全する。3) 侵害を否定できない場合は再構築し、ユーザーのパスワード・2FA シークレット・CI/CD シークレット・連携の資格情報を交換する。

【監視】
CI 設定内の異常な正規表現、GitLab ワーカーの繰り返しクラッシュ、コンテナイメージの不審なダウンロード。

【参照】
- Alpine Linux rebuilds GitLab after attempted RCE attack (BleepingComputer) https://www.bleepingcomputer.com/news/security/alpine-linux-rebuilds-gitlab-after-attempted-rce-attack/

SOC-2026-11-02-002 Binance 窃取の TraderTraitor 帰属：偽採用面接と Terraform プロバイダ経由のローダーへの対策を再確認する
------------------------------------------------------------
対象: 暗号資産・DevOps・AI・ブロックチェーン関連の組織

【24時間以内の変化】
[FBI／THN／BleepingComputer 2026-11-01] FBI が Binance 窃取を TraderTraitor に公式帰属。

【概要】
THN によれば TraderTraitor は偽リクルーター・前面会社を使った偽採用面接で開発者に接触し、Terraform プロバイダ経由の Bash ローダーで macOS・Linux・Windows 向けマルウェアを配布する（同グループの手法の記述で、Binance 事案での使用は明示されていない）。標的はサイバーセキュリティ・AI・ブロックチェーン・採用関連企業。

【推奨アクション】
- 1) 採用面接を名目とするコード課題・リポジトリの実行を、隔離環境以外で禁止する。2) Terraform プロバイダの取得元を固定し、未検証プロバイダを拒否する。3) DevOps 端末と署名権限を分離し、署名鍵への到達経路を棚卸す。4) FBI 公表のウォレットアドレスを原典で確認し、送金スクリーニングに反映する。

【監視】
開発者端末からの Terraform プロバイダ取得元の逸脱、Bash ローダーの実行、不審な採用担当者を名乗る接触。

【参照】

SOC-2026-11-02-004 Polymarket 事案：署名・取引画面から外部スクリプトを排除し、SRI・CSP・版固定を適用する
------------------------------------------------------------
対象: Web3／金融サービスのフロントエンド

【24時間以内の変化】
[The Hacker News 2026-11-01] サードパーティの RUM スクリプトが差し替えられ、署名リクエスト経由で資金が持ち出された。

【概要】
外部ベンダーのスクリプトは、ベンダーの DNS やドメイン登録事業者の侵害で悪性コードに差し替えられうる。署名・取引ページに外部コードがあると、ユーザーの署名者にリクエストを出せる。

【監視】
外部スクリプトのハッシュ変化、CSP 違反レポート、署名リクエストの急増。
