SOC-2026-10-13-001 GitLab が最大深刻度の CI/CD 正規表現コンパイラ RCE を警告 — セルフホスト GitLab の緊急パッチ確認
------------------------------------------------------------
【24時間以内の変化】
[BleepingComputer 2026-10-12] GitLab が CI/CD Regular Expression Compiler の最大深刻度 RCE に即時パッチ適用を警告。

【概要】
GitLab は CI/CD の Regular Expression Compiler にリモートコード実行につながる最大深刻度の脆弱性があるとして直ちにパッチを適用するよう警告した。CVE 番号・影響バージョン・悪用有無は要約から未取得（推測: 2026-09-25 既報の CVE-2026-89078 / CVE-2026-93577 の系統の可能性があるが確認できていない）。セルフホスト環境は GitLab の公式アドバイザリで該当バージョンを確認すること。

【推奨アクション】
・GitLab 公式のセキュリティリリースで該当バージョンを確認し、セルフホスト GitLab を修正版へ更新する
・更新までの間、外部へ公開している GitLab の到達性制限と、CI/CD 設定ファイル（.gitlab-ci.yml）変更の監査を強化する

【監視】
GitLab の CI/CD パイプライン作成・設定変更イベントと、runner 上の不審プロセスを監視する。
IOC 未取得。

【参照】
・BleepingComputer: GitLab warns of max severity code execution vulnerability https://www.bleepingcomputer.com/news/security/gitlab-warns-of-max-severity-rce-flaw-in-regex-compiler-engine

SOC-2026-10-13-002 Bricksforge（WordPress）CVE-2026-85097 が悪用中 — WordPress プラグインの棚卸しと一時無効化の判断
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News / SecurityWeek 2026-10-12] Patchstack 情報として Bricksforge の CVSS 10.0 脆弱性の悪用を報道。

【概要】
Section 2 注目CVE として記録した CVE-2026-85097（未認証 PHP アップロード→RCE・悪用中）の対応。Bricksforge を使う WordPress サイトの有無を確認し、修正版が無ければ無効化を検討する。修正版の有無は要約から未取得。

【推奨アクション】

・導入サイトは修正版の有無を確認し、未修正ならプラグインを一時無効化、uploads 配下の不審 PHP を点検する

【監視】
uploads 配下への PHP 新規作成と未認証 POST を監視する。
IOC 未取得。

SOC-2026-10-13-003 AnyDesk 8.0.3 未満に未認証 RCE（CVE-2026-109390・CVSS 9.8）— リモート接続ツールの更新確認
------------------------------------------------------------
【24時間以内の変化】
[NVD / MITRE 2026-10-12] NVD に CVE-2026-109390 が公開（2026-10-12 15:17 UTC・CVE 採番は MITRE）。

【概要】
セッションプロトコルのモード 5 のストリームパケットハンドラでペイロード長が検証されず、ヒープベースのバッファオーバーフローにより未認証のリモート攻撃者が任意コードを実行できる。Linux では被害者がデスクトップ制御を承認しないまま root でコマンド実行できる実証が記載される（NVD 記述）。悪用確認・KEV 登録は未確認。修正は 8.0.3。

【推奨アクション】
・管理下端末の AnyDesk バージョンを棚卸しし 8.0.3 以降へ更新する
・不要な端末の AnyDesk を削除し、外部からの AnyDesk 接続を許可リスト制にする

【監視】
AnyDesk プロセスからの子プロセス生成と、未知の送信元からのセッション接続を監視する。
IOC 未取得。

【参照】
・NVD: NVD CVE-2026-109390 https://nvd.nist.gov/vuln/detail/CVE-2026-109390
