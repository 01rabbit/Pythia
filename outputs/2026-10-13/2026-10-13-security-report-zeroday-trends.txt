1. CVE-2026-85097 Bricksforge（WordPress プラグイン）（CVSS 10.0）
------------------------------------------------------------
優先度: high  軸1=13 軸2=2  KEV登録: なし  悪用: 確認  パッチ: 未確認

【24時間以内の変化】
[The Hacker News / SecurityWeek 2026-10-12] Patchstack の情報として、Bricksforge の CVSS 10.0 脆弱性 CVE-2026-85097 が実環境で悪用されていると THN と SecurityWeek が報道。

【概要】
WordPress プラグイン Bricksforge の CVE-2026-85097（CVSS 10.0）は、未認証の攻撃者が任意の PHP コードをアップロード・実行でき、RCE によりサイトの乗っ取りに至る。Patchstack によれば実環境で悪用中（THN 報道）。修正版の有無・影響バージョン・悪用規模は RSS 要約から取得できていないため未確認。CISA KEV 未登録（本窓のスイープで KEV 追加 0 件）。公開 PoC の有無も未確認。

【暫定緩和策】
・Bricksforge を利用する WordPress サイトでは修正版の有無を Patchstack / ベンダーで確認し、未修正ならプラグインを一時無効化する
・wp-content 配下の不審な PHP ファイルと新規管理者アカウントを点検する

【監視】
WordPress の uploads 配下に新規作成された PHP ファイルと、プラグインのエンドポイントへの未認証 POST を監視する。
IOC は要約から取得できていないため検知シグネチャは提供できない。

【参照】
・The Hacker News: Attackers Exploit CVSS 10.0 Bricksforge WordPress Flaw Enabling Unauthenticated RCE https://thehackernews.com/2026/10/attackers-exploit-cvss-100-bricksforge.html
・SecurityWeek: Bricksforge WordPress Plugin Vulnerability Exploited in the Wild https://www.securityweek.com/bricksforge-wordpress-plugin-vulnerability-exploited-in-the-wild
