TREND-2026-10-25-001 Eye Security：放棄された Popcorn Time 派生アプリ Time4Popcorn の更新機構（CVE-2026-30612・CVSS 9.8）を、2025-11〜2026-03 に 200 万件超の更新で遠隔無効化
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News（Eye Security） 2026-10-24] Eye Security の Operation IXIM を THN が報道。Hack.lu（10-22）での発表内容に基づく。

【概要】
THN によれば、Time4Popcorn（2014年に終了した Popcorn Time の放棄された複製）の更新機構は、暗号化されていない通信で更新を確認し、送信元を検証せず SYSTEM／root 権限で導入する（CVE-2026-30612・CISA 評価 CVSS 9.8・Windows 6.2.1.18 以下／Mac 6.2.1.17 以下／Android 3.5.0.173 以下）。更新先ドメインが未登録だったため、取得した者は端末へコードを配布できた。Eye Security は顧客端末の脅威ハンティングでこれを発見し、ドメインを自ら登録して 2025-11〜2026-03 に更新機構を停止する更新を 200 万件超配信（削除・情報収集なし）、2026-06 に開示、2026-10-22 の Hack.lu で公表した。推定規模は Windows 250〜300万台・Mac 25〜35万台（ハードウェアID 380万件超は信頼性が低いと同社が修正）。2026-10-23 時点で CISA KEV には未収載。悪用の実害報告は確認できない。アプリ本体も 2014 年のブラウザエンジン・サンドボックス無効・暗号化なし通信で危険が残り、Eye は概念実証を作成済み。
