CVE-2026-131914 [9] Idunno.AntiCsrf（ASP.NET WebForms 向け第三者 anti-CSRF ライブラリ）
------------------------------------------------------------
対象: Idunno.AntiCsrf（OSS・2008年以降更新停止） / Idunno.AntiCsrf 0.9.1.0 および 0.9.1 Beta
評点: CVSS v4 9.3
【概要】
Mandiant（Google）は、ASP.NET WebForms 向けの第三者 anti-CSRF ライブラリ Idunno.AntiCsrf（Idunno.AntiCsrf.dll）に存在する重大な安全でないデシリアライゼーションの脆弱性 CVE-2026-131914（CVSS 9.3）について『in the wild での実悪用を観測した』と警告した。AntiCsrfModule が CSRF フォームトークンを MAC/署名検証なしの unkeyed な System.Web.UI.ObjectStateFormatter でデシリアライズするため、攻撃者は事前認証も有効な CSRF トークンも無しに単一の HTTP POST だけで IIS ワーカープロセス（w3wp.exe）上で任意コード実行（RCE）を達成できる。影響は 0.9.1.0 と 0.9.1 Beta。当該 OSS は 2008年12月以降更新が止まった defunct なライブラリで公式パッチは無く、Mandiant は使用中止を推奨。発見は Google Cloud/Mandiant インシデント対応チーム。CISA KEV には発行時点で未収載。悪用の規模・標的・IoC の詳細は Google 脅威情報チームは未開示。
【一時緩和】
  - Idunno.AntiCsrf（AntiCsrfModule）の使用を直ちに中止し、Web.config の machineKey と applicationHost.config のシークレットをローテーション。Web.config・bin/ を Idunno.AntiCsrf/AntiCsrfModule について監査し、.aspx エンドポイントへの異常な POST を IIS ログで点検。
【TTP】
  - T1190 (initial-access): Mandiant: 認証不要の単一 HTTP POST を公開 ASP.NET WebForms エンドポイントに送るだけで悪用可能
【IOC】IP: なし / ファイル: なし
【監視】w3wp.exe（IIS ワーカープロセス）配下の異常な子プロセス・コマンド実行、.aspx エンドポイントへの未認証 POST。
  参照: https://thehackernews.com/2026/11/hackers-exploit-critical-aspnet-anti.html (The Hacker News)
  参照: https://github.com/mandiant/Vulnerability-Disclosures/blob/master/2026/MNDT-2026-0048.md (Mandiant)
