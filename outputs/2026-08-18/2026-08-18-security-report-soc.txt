1. Windows Server 2022、メインストリームサポート終了まで60日（2026年10月13日）
観点: CVE関連
採用契機: β
------------------------------------------------------------

優先度: 低
対象: Windows Server 2022

【24時間以内の変化】
[BleepingComputer 2026-08-17] メインストリームサポート終了日(2026-10-13)、延長サポートは2031-10-14までセキュリティ更新継続、Windows Server 2025への移行を推奨する旨をMicrosoftが案内

【概要】
Windows Server 2022は2026年10月13日にメインストリームサポート（新機能・非セキュリティ更新等）を終了し、以後はセキュリティ更新のみを2031年10月14日まで無償提供する延長サポートフェーズへ移行する。セキュリティパッチ自体は当面継続されるため即時のセキュリティリスクは低いが、国内で広く稼働するサーバOSであり、機能追加停止やベンダーサポート体制変更に伴う運用計画・移行スケジュール策定が必要になるため、SOC/IT部門は資産棚卸しと移行計画の把握を進めておくことが望ましい。

【推奨アクション】
・Windows Server 2022稼働資産のインベントリ化（メインストリーム/延長サポート対象の切り分け）
・Windows Server 2025への移行検討・評価環境での検証開始
・資産管理台帳・脆弱性管理ツールのOSバージョン別ライフサイクルステータス反映
