SOC-2026-10-20-001 F5 NGINX の重大脆弱性3件（CVE-2026-15176／CVE-2026-97205／CVE-2026-93479）の定例外パッチ適用
------------------------------------------------------------
対象: NGINX Plus／Open Source／Ingress Controller／Gateway Fabric／Instance Manager

【24時間以内の変化】
[BleepingComputer 2026-10-19] F5 が定例外パッチを公開。悪用は未確認。

【概要】
ngx_http_v3_module の2件と map ディレクティブの1件。悪用は非既定設定が条件で、コード実行は ASLR 無効／回避可能時に限られる。F5 は悪用を確認していない。
【推奨アクション】
- F5 の公開アドバイザリ（K000162416／K000162608／K000162607）で影響バージョンを確認し修正版へ更新する
- 更新までの暫定策: alias と $request_filename の併用を避ける、AIO／SSI を無効化する、map の無名キャプチャを名前付きにする
【監視】
NGINX ワーカープロセスの異常終了・再起動の頻発を監視する。

【参照】
- F5 releases out-of-band patches for critical NGINX vulnerabilities (BleepingComputer) https://www.bleepingcomputer.com/news/security/f5-releases-out-of-band-patches-for-critical-nginx-vulnerabilities

SOC-2026-10-20-003 Windows Server の10月更新で Exchange の OWA サインインとメール配送に障害（Microsoft 確認）
------------------------------------------------------------
対象: Exchange Server／Windows Server

【24時間以内の変化】
[BleepingComputer 2026-10-19] Microsoft が10月の Windows Server セキュリティ更新による OWA サインイン／メール配送障害を確認。

【概要】
セキュリティ更新が一部の Exchange 環境で OWA サインインとメール配送に問題を起こすと Microsoft が確認した（詳細は要約のみ取得）。脆弱性ではなく運用影響の情報。
【推奨アクション】
- Exchange を運用する環境は、10月更新の適用前に Microsoft の既知の問題と回避策を確認する
【監視】
OWA サインイン失敗とメールキュー滞留を監視する。

【参照】
- Microsoft: October Windows Server updates break Exchange sign-in, mail flow (BleepingComputer) https://www.bleepingcomputer.com/news/microsoft/microsoft-october-windows-server-updates-cause-exchange-issues
