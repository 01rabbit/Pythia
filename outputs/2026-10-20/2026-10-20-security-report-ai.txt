AI-2026-10-20-001 OpenCode Console への侵入で保存済みの OpenAI／Anthropic／Google API キーが漏えいした可能性
------------------------------------------------------------
カテゴリ: C/C4

【24時間以内の変化】
[The Hacker News 2026-10-19] OpenCode が漏えいの可能性を公表したと報道。

【概要】
The Hacker News によれば、OpenCode は 10-16 夜にレガシーシステムへ侵入者が到達し、OpenCode Console（任意利用のホスト型サービス）にユーザーが保存した第三者 AI プロバイダーの API キーが漏えいした可能性があると公表した。攻撃者・侵入経路・実際の悪用は本文未取得のため不明（推測を含まない）。

【攻撃フロー】
1. レガシーシステムへ侵入者が到達（10-16 夜）
2. Console に保存された OpenAI／Anthropic／Google のキーが露出した可能性

【監視】
該当サービスに保存した API キーを使うプロバイダー側の利用ログで、想定外の呼び出し・利用量急増を確認する。

【参照】
- OpenCode Console Breach May Have Exposed OpenAI, Anthropic, and Google API Keys (The Hacker News) https://thehackernews.com/2026/10/opencode-console-breach-may-have.html

AI-2026-10-20-002 偽 Web3 アクセラレーターが npm パッケージで窃取マルウェアとバックドアを配布し AI エージェントの通信を乗っ取る
------------------------------------------------------------
カテゴリ: C/C6

【24時間以内の変化】
[The Hacker News 2026-10-19] Elastic の調査として報道。

【概要】
The Hacker News によれば、Anthropic Claude や Google Gemini の無料クレジット・コーディングツール・セキュリティ監査を口実にする偽の Web3 アクセラレーターが、悪意ある npm パッケージで Windows と macOS に情報窃取型マルウェアとバックドアを配布していることを Elastic が観測した。見出しは AI エージェント通信の乗っ取りに言及するが、詳細は本文未取得。

【攻撃フロー】
1. 無料 AI クレジット等を口実に開発者を誘引
2. 悪意ある npm パッケージ経由で窃取マルウェア／バックドアを配布

【監視】
開発端末で未知の npm パッケージのインストール後の外向き通信・AI ツール設定ファイルの変更を確認する。

【参照】
- Fake Web3 Accelerator Uses npm Packages to Spread Malware and Hijack AI Agent Traffic (The Hacker News) https://thehackernews.com/2026/10/fake-web3-accelerator-uses-npm-packages.html
