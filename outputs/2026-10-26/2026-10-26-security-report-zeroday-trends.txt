CYFIRMA-NKsuspected-2026-PHP2Shell-GlobalScanning Lazarus Group エコシステムとの関連が疑われる北朝鮮系クラスター（CYFIRMA 評価・中程度の確度）
------------------------------------------------------------
帰属: North Korea-linked（CYFIRMA 評価）（信頼度: medium）/ 軸P=4 軸Q=5
標的: government,finance / global

【24時間以内の変化】
[The Hacker News（CYFIRMA） 2026-10-25] CYFIRMA が、侵害済みの 21 ノードから世界の PHP 基盤をスキャンする北朝鮮系の疑いのある活動を中程度の確度で評価。閉じた I2P チャネルで調整され、標的集合は約 12 か国の 216 台の未修正・部分緩和ホストと報じられた。

【概要】
THN によれば、CYFIRMA は PHP2Shell を狙うグローバルなスキャンを、北朝鮮系の疑いのある活動と中程度の確度で評価した。侵害済みの 21 ノードを使い、標的集合は約 12 か国・複数業種の 216 台の未修正または部分緩和ホスト。根拠は C2 インフラの重複、PHP/WordPress サーバーを侵害してきた過去、政府・金融への関心である。これは CYFIRMA 単独の評価で、実際の侵入成功は報告されていない（推測の余地が大きい）。

【攻撃フロー】
1. 侵害済み 21 ノードから PHP 公開基盤をスキャン（CYFIRMA 評価）
2. 未修正・部分緩和の 216 台を標的集合として把握（CYFIRMA 評価）

【推奨アクション】
PHP を修正版（8.5.12／8.4.27／8.3.36／8.2.35 以降）へ更新する。CYFIRMA が公表した 216 台の未修正ホスト一覧に該当するか、同社の通知有無を確認する。

【検知メモ】
帰属は CYFIRMA 単独の中程度の確度の評価（C2 インフラの重複・PHP/WordPress サーバーを侵害してきた過去・政府と金融への関心が根拠）。Unit 42 の政府機関侵入とこの活動の関連は報じられていない。TTP の類似のみでは断定しない。ATT&CK は付与しない。

CVE-2026-109618 PHP（OOM 時の longjmp 処理＝PHP2Shell）（CVSS 9.8）
------------------------------------------------------------
優先度: high  軸1=13 軸2=8  KEV登録: なし  悪用: 確認（Unit 42 が侵入後の活動を観測）  パッチ: あり
影響バージョン: PHP 8.5.12 未満／8.4.27 未満／8.3.36 未満／8.2.35 未満（情報源：PHP 5.4 まで遡る広範囲。8.1 以前は公式更新なし・ソースバックポートのみ）

【24時間以内の変化】
[The Hacker News（Unit 42・CYFIRMA・ReliaQuest・Defused Cyber 引用） 2026-10-25] Unit 42 が PHP2Shell の悪用後に agentic AI プラットフォームを使う攻撃者を観測。欧州の政府機関では初期悪用から 2 時間以内にパスワードハッシュと MFA シークレットへ到達し、AD への NTLM リレートンネルを構築して Domain Admin 昇格を試みた（侵入成功の初の具体的報告）。Cloudflare は公開後に数百万件の悪用試行を報告。ReliaQuest が 10-22 に CVE-2026-109618 を再現しログ痕跡（POST→500→メモリ枯渇・ヒープ破壊→Apache ワーカー異常終了）を整理。KEV 未収載（カタログ版 2026.10.23）。[既報・更新]

【概要】
THN によれば、PHP2Shell（CVE-2026-109618／109619）は既定構成の PHP で未認証のリモートコード実行に至り得る。Unit 42 は悪用成功後の侵入を観測した：欧州の政府機関では 2 時間以内にパスワードハッシュと MFA シークレットへ到達し、AD への NTLM リレートンネル構築と Domain Admin 昇格を試みた。コマンドは ==SHELLUSER== や ==PASSWD== などの区切りで囲まれ、AI モデルが解析しやすい出力形式であった。匿名 LDAP クエリも観測された。Bitsight は、インターネット公開の PHP 関連システムが約 3,700 万あり、ホストの PHP 更新だけが対処になる（アプリ・WAF・プラグインの更新では塞がらない）と説明する。第三の RCE CVE-2026-115560 は session.serialize_handler の実行時切替と upload_progress 有効という稀な構成が条件で、通常のリリースサイクルで修正予定。Xint が露出確認ツール（phpguard.io）を公開した。

【攻撃フロー】
1. 細工した大容量マルチパート要求などでメモリ上限に到達させる
2. longjmp による異常脱出で壊れたグローバル状態が残る
3. mod_php 等で未認証のコード実行（情報源が単一リクエストでの実証と記述）

【暫定緩和策】
- PHP を 8.5.12／8.4.27／8.3.36／8.2.35 以降へ更新する（ディストリビューションの changelog で CVE を確認）
- 暫定: memory_limit=-1 を固定し post_max_size を低く保ち、Web サーバー／プロキシでリクエストサイズを制限（RLIMIT_AS／RLIMIT_DATA は使わない）
- 更新後は新しいハードメモリ上限でプロセスが終了し得るため設定を見直す

【監視】
マルチパート要求後の HTTP 500・メモリ上限エラー・Apache ワーカーの異常終了、PHP_SESSION_UPLOAD_PROGRESS に値 'p2s-rider' を含む要求、204.76.203[.]7 からの通信を監視する。侵入後は PHP ホストから DC への匿名 LDAP クエリ・NTLM リレートンネルを確認する。
