1. Djinn Stealer: CVE-2026-48558 悪用による AI 開発者認証情報・MCP コンフィグ窃取
カテゴリ: C3（AI 開発者認証情報窃取）/ 攻撃者種別: 犯罪組織
バースト検出: 3 件（BleepingComputer・Horizon3.ai・HelpNetSecurity）→ threshold_met
------------------------------------------------------------

採用契機: Q（実際のインシデント・被害報告）・R（AI セキュリティ CVE 関連の実害）
被害規模: 14,000 台以上の SimpleHelp サーバーが潜在的露出対象

【24時間以内の変化】
[BleepingComputer 2026-06-29] CVE-2026-48558 悪用で展開される Djinn Stealer が Claude・Gemini・Codex・Cline・OpenCode・Kilo 等の AI コーディングアシスタントの設定ファイルと MCP サーバー設定を標的とすることが初報

【概要】
Djinn Stealer は CVE-2026-48558（SimpleHelp OIDC 認証バイパス・CVSS 10.0）を悪用してエンドポイントに展開される新規クロスプラットフォーム型インフォスティーラーで、AI 開発者の認証情報と MCP（Model Context Protocol）コンフィグファイルを主要標的とする。Claude・Gemini・Codex・Cline・OpenCode・Kilo 等の AI コーディングアシスタント設定・SSH 秘密鍵・クラウド認証情報・Docker シークレット・Terraform 設定を収集する。窃取された AI API キーは LLMjacking（被害者コストでの不正 API 利用）または AI システムへの不正アクセスに転用される。

攻撃の流れ:
1. 攻撃者は CVE-2026-48558 を悪用して SimpleHelp サーバーに認証なしでテクニシャン権限でログインする
2. テクニシャン権限で接続中のエンドポイントに Djinn Stealer を展開し、AI ツール設定・SSH キー・クラウド認証情報を網羅的に収集する
3. 収集した認証情報を C2 へ送信し、窃取した AI API キーを LLMjacking または AI システムへの継続的不正アクセスに悪用する

【IoC / 検知シグナル】
IoC: 確認されず（ハッシュ・C2 IP は本稿時点で非公開）
検知シグナル: AI ツール設定ディレクトリへの異常な読み取りアクセス
検知シグナル: SSH キーディレクトリへの正規外プロセスアクセス
検知シグナル: クラウド認証情報ファイルへの正規外プロセスアクセス

【監視・対策ポイント】
Splunk SPL: index=endpoint_logs (file_path="*/.claude/*" OR file_path="*/.ssh/id_*" OR file_path="*/.aws/credentials*" OR file_path="*/mcp*.json") NOT process_name IN ("claude","ssh-agent","aws") | stats count by host, process_name, user, file_path | where count > 5
・SimpleHelp を v5.5.16 以上へ即時アップグレードする（CVE-2026-48558 の根本対策）
・侵害が疑われる AI API キー・クラウド認証情報・SSH キーを即時ローテーションする

【参照】
https://www.bleepingcomputer.com/news/security/djinn-stealer-targets-ai-developer-credentials-mcp-configs/
https://www.horizon3.ai/attack-research/cve-2026-48558-simplehelp-oidc/
