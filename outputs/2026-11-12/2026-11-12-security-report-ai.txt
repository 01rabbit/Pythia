AI-2026-11-12-001 [カテゴリA] AntiFox（オープンソースのエージェント型ペンテスト基盤）が AWS 認証情報窃取を伴う侵入で悪用（Arctic Wolf）
------------------------------------------------------------
The Hacker News と BleepingComputer によれば、Arctic Wolf Labs は、Alibaba Cloud 上で自己ホストされた AntiFox（GitHub 公開の自律ペンテスト基盤、251 フォーク・474 スター）の画面が、インターネット公開の Web サービスと連携 AWS 環境への悪意ある操作と関連したと報告した。初期侵入は侵害された IIS Web アプリ（脆弱性は不明）または経路不明の有効な AWS 認証情報で、w3wp.exe 経由の ASPX Web シェル、web.config の接続文字列探索、IAM・S3・Secrets Manager・Bedrock 等の列挙が観測された。特定の攻撃者名は無い。IOC は Arctic Wolf のアラート（GitHub）にあり、本記事には記載が無い。
  被害規模: Arctic Wolf によれば、複数の侵入で AWS 本番のシークレット取得（GetSecretValue 成功）を確認。被害組織数は未確認。
  参照: https://thehackernews.com/2026/11/antifox-ai-pentesting-platform-linked.html (The Hacker News)
  参照: https://www.bleepingcomputer.com/news/security/hackers-use-antifox-ai-agents-in-aws-credential-theft-attacks (BleepingComputer)

AI-2026-11-12-002 [カテゴリC] Railway：窃取された顧客の AI プロバイダ鍵で約 74 万ドルの不正利用
------------------------------------------------------------
The Hacker News と BleepingComputer によれば、PaaS の Railway は 10 月の侵害で顧客が保管していた AI プロバイダの API キーが盗まれ、推定 74 万ドルの不正利用が生じたと発表した。インフラの脆弱性が悪用されたと BleepingComputer は記述する。攻撃者・侵入経路の詳細は未確認。
  被害規模: THN によれば推定 74 万ドルの不正利用。BleepingComputer は最大 10 万ワークスペースの認証情報が露出し得ると報道。
  参照: https://thehackernews.com/2026/11/railway-says-stolen-customer-ai-keys.html (The Hacker News)
  参照: https://www.bleepingcomputer.com/news/apple/railway-breach-leads-to-740-000-in-fraudulent-ai-charges (BleepingComputer)
