1. Cleo Harmony最新脆弱性のExploit公開、既往のCl0p悪用パターンに要警戒
観点: ゼロデイ関連
採用契機: δ, α
------------------------------------------------------------

優先度: 高
対象: Cleo Harmony（MFTソフトウェア）

【24時間以内の変化】
[SecurityWeek 2026-09-02] Cleo Harmonyの新規脆弱性に対するExploitコードが公開されたと報道

【概要】
ファイル転送ソフトウェアCleo Harmonyの新規脆弱性に対するExploitコードが公開された。Cleoの同種製品（Cleo Harmony/VLTrader/LexiCom）は2024年末にCl0pランサムウェアグループによる大規模データ窃取キャンペーンで悪用された前例があり、MFT（マネージド・ファイル転送）製品は攻撃者にとって高価値標的であり続けている。CVE番号・詳細な技術情報は09-03時点で情報源が限定的なため、続報を要確認。

【推奨アクション】
・Cleo Harmony/VLTrader/LexiCom等のMFT製品の外部公開状況を棚卸しし、インターネット直接露出を可能な限り解消する
・続報のCVE番号・パッチ情報を注視し、公開次第直ちに適用する
・[ログソース: MFTアクセスログ/EDR] 異常なファイルアップロード・管理コンソールへの外部アクセスを監視する
Splunk SPL: index=mft sourcetype=cleo_harmony (admin_console OR file_upload) | stats count by src_ip, user
→ 社外IPからの管理コンソールアクセスを最優先で確認する

【参照】
https://www.securityweek.com/exploit-published-for-fresh-cleo-harmony-vulnerability/

3. Microsoft Defenderが正規Google検索リンクを誤検知、SOC運用への影響に注意
観点: AI攻撃関連
採用契機: γ
------------------------------------------------------------

優先度: 中
対象: Microsoft Defender

【24時間以内の変化】
[BleepingComputer 2026-09-02] Microsoft Defenderが正規のGoogle検索結果リンクを悪意あるものとして誤検知する不具合が報告されたと報道

【概要】
Microsoft Defenderが正規のGoogle検索結果リンクを悪意あるURLとして誤検知（フォールスポジティブ）する不具合が報告された。SOCにおいてはアラート疲れ・正規業務の妨害につながるため、当該誤検知パターンをアラートトリアージの除外条件として一時的に把握しておくことが推奨される。

【推奨アクション】
・Microsoft Defenderの検知ログでGoogle検索リンクに対する誤検知アラートの有無を確認する
・Microsoftからの修正プログラム配信状況を注視する
・[ログソース: EDR/Defenderアラートログ] 誤検知と疑われるアラートのパターンを一時的に記録しトリアージ効率化に活用する
Splunk SPL: index=defender sourcetype=alert url=*google.com/search* | stats count by verdict
→ 誤検知率が高い場合はMicrosoft側の修正パッチ適用まで当該パターンをトリアージ優先度低に設定する

【参照】
https://www.bleepingcomputer.com/news/security/microsoft-defender-flags-legitimate-google-search-links-as-malicious
