AI-2026-11-01-003 共有された ChatGPT リンクを開くだけで攻撃者のコードがログイン済みセッションで実行され、非公開チャットを読み取れた — Parameter が報告、OpenAI は P1 として修正済み
------------------------------------------------------------
カテゴリ: B/B1  X=6 Y=3  採用条件: A-P・A-S

【24時間以内の変化】
[Parameter（The Hacker News 経由） 2026-10-31] Parameter が ChatGPT の共有リンク経由のセッション内コード実行を公表。10-18 に OpenAI のバグバウンティで報告、8 日後に修正、深刻度 P1。[新規]

【概要】
セキュリティ企業 Parameter は、悪意ある ChatGPT 共有リンクを開いた人のログイン済みセッション内で攻撃者のコードを実行できたと報告した（THN）。最も確実な方式では被害者が Preview ボタンを 1 回押す必要があり、後続の方式では Preview が自動で開き、リンクを開くだけで成立した。連鎖は、Preview の隔離フレーム（別オリジン）自体は破られなかったが、対話内のグラフ描画で読み込まれる MathLive ライブラリのメッセージ受信側が送信元を検証せず、キーボード用メッセージ経由で生の HTML を受け入れた点を突き、その HTML で chatgpt.com と同一とみなされるフレームを作り、YouTube から読み込んだスクリプトでコードを実行させるものだった。実行後は被害者のアカウントとして ChatGPT 自身の API を呼べた。報告は 10-18、OpenAI は 8 日後に修正し P1 と評価した。実環境での悪用は報告されていない。

【攻撃フロー】
1. 攻撃者が細工した会話を共有リンクにして、メール・チャット・チケット・SNS などで送る
2. 被害者がリンクを開き Preview を表示すると、MathLive のメッセージ受信側の検証不備を経由して信頼されたページへ HTML が渡る
3. 被害者のセッションと同じ権限でコードが実行され、会話の一覧取得・非公開チャットの読み取りなどが可能になる（研究者の検証）

【被害規模】
実被害の報告なし。研究者は別アカウント間の検証で、被害者の最近の会話一覧の取得、共有していない非公開チャットの開封とその一部の外部送信まで実証した（The Hacker News）。

【監視】
修正は OpenAI 側で適用済み（利用者側の対応は不要）。共有リンクの出所確認と、見知らぬ共有リンクで Preview を押さない運用を周知する。
実環境での悪用は報告されていない。
