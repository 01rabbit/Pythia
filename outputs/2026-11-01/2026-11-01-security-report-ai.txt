AI-2026-11-01-001 ブロックチェーン分析企業 Chainalysis が「offensive agentic techniques」による不正アクセスを公表 — 内部ツールに侵入され顧客のユーザー ID・氏名・メール・組織内ロールが閲覧された
------------------------------------------------------------
カテゴリ: A/A4  X=6 Y=5  採用条件: A-Q・A-X

【24時間以内の変化】
[Chainalysis（The Hacker News／BleepingComputer 経由） 2026-10-30] Chainalysis が顧客向け通知で、今月「offensive agentic techniques」を使う外部の攻撃者が同社システム・内部ツールへ不正アクセスしたと公表。[新規]

【概要】
Chainalysis は 10-30（金・現地）の顧客向け通知で、今月、「offensive agentic techniques」を用いる外部の攻撃者が同社のシステムと内部ツールへ不正アクセスしたことを検知したと発表した（THN）。閲覧されたのは非機密の顧客データで、調査コンテンツ・認証情報・セッショントークンへの不正アクセスは確認されていない。同社は脆弱性の修正とシステムの堅牢化を進めている。「offensive agentic techniques」の語から AI を使った攻撃ツールが使われたとみられる（THN の解釈・推測）が、Chainalysis は具体的な手口・使用ツール・攻撃者を明らかにしておらず、詳細は未確認である。帰属情報は無い。

【攻撃フロー】
1. 外部の攻撃者が agentic（AI エージェント型）の攻撃手法で Chainalysis のシステム・内部ツールへ不正アクセスする（同社の記述・手口の詳細は非公表）
2. 内部ツール上の顧客のユーザー ID・氏名・メール・組織内ロールが閲覧される（同社の記述）

【被害規模】
非機密の顧客データ（ユーザー ID・氏名・メールアドレス・組織内ロール）が閲覧された。調査コンテンツ・認証情報・セッショントークンへの不正アクセスはなかったと Chainalysis は説明（THN）。顧客数・期間は非公表。

【検知シグナル】
- 内部ツールへの通常と異なる速度・網羅性の参照（機械的な列挙）

【監視】
顧客側は、Chainalysis 発の通知に含まれる自組織ユーザー情報の露出範囲を確認し、同社を装うフィッシング（氏名・ロール既知を悪用）への注意を周知する。
手口・IOC・攻撃者は非公表。THN の「AI を使った攻撃を示す」は解釈であり同社は AI の使用を明言していない部分がある（「agentic techniques」とは述べている）。

AI-2026-11-01-002 クラウドアプリ基盤 Northflank が侵害され、顧客の AI API キーが不正利用された — 全顧客に保存済みの認証情報・シークレットの交換を要請
------------------------------------------------------------
カテゴリ: C/C4  X=6 Y=6  採用条件: A-Q

【24時間以内の変化】
[BleepingComputer 2026-10-31] Northflank が侵害を認め、顧客に基盤上の全認証情報・シークレットのローテーションを要請。顧客の AI API キーが不正利用された。[新規]

【概要】
BleepingComputer の要約によれば、クラウドアプリケーションのホスティング基盤 Northflank は、セキュリティ侵害によって顧客の AI API キーが不正利用されたとして、基盤に保存した全ての認証情報とシークレットを交換するよう顧客に警告している。本文が取得できず（403）、侵入経路・影響顧客数・不正利用された API の提供元・被害額・攻撃者は未確認で、見出し・要約ベースの記録である。AI 向け API キー（LLM 利用権）の窃取・転売・不正利用は今月の他の AI 開発基盤の侵害報道と同種の傾向だが、本件との関連は確認できていない。

【攻撃フロー】
1. Northflank の基盤が侵害され、顧客が保存したシークレット（AI API キーを含む）にアクセスされる（要約の記述・経路は未確認）
2. 窃取された AI API キーが不正に使われる（要約の記述）

【被害規模】
顧客の AI API キーが不正に使われた（BleepingComputer の要約）。影響した顧客数・不正利用額・侵入経路・期間は取得できた情報に記載なし。

【検知シグナル】
- AI プロバイダーの API 利用量・課金の急増
- 通常と異なる送信元・地域からの API キー利用

【監視】
Northflank 利用者は保存済みシークレットを全て交換し、AI プロバイダー側の使用量・請求・キーの最終利用日時を遡って確認する。上限（スペンドキャップ）を設定する。
IOC・侵入経路は未取得。BleepingComputer 本文は取得拒否（403）。

AI-2026-11-01-003 共有された ChatGPT リンクを開くだけで攻撃者のコードがログイン済みセッションで実行され、非公開チャットを読み取れた — Parameter が報告、OpenAI は P1 として修正済み
------------------------------------------------------------
カテゴリ: B/B1  X=6 Y=3  採用条件: A-P・A-S

【24時間以内の変化】
[Parameter（The Hacker News 経由） 2026-10-31] Parameter が ChatGPT の共有リンク経由のセッション内コード実行を公表。10-18 に OpenAI のバグバウンティで報告、8 日後に修正、深刻度 P1。[新規]

【概要】
セキュリティ企業 Parameter は、悪意ある ChatGPT 共有リンクを開いた人のログイン済みセッション内で攻撃者のコードを実行できたと報告した（THN）。最も確実な方式では被害者が Preview ボタンを 1 回押す必要があり、後続の方式では Preview が自動で開き、リンクを開くだけで成立した。連鎖は、Preview の隔離フレーム（別オリジン）自体は破られなかったが、対話内のグラフ描画で読み込まれる MathLive ライブラリのメッセージ受信側が送信元を検証せず、キーボード用メッセージ経由で生の HTML を受け入れた点を突き、その HTML で chatgpt.com と同一とみなされるフレームを作り、YouTube から読み込んだスクリプトでコードを実行させるものだった。実行後は被害者のアカウントとして ChatGPT 自身の API を呼べた。報告は 10-18、OpenAI は 8 日後に修正し P1 と評価した。実環境での悪用は報告されていない。

【攻撃フロー】
1. 攻撃者が細工した会話を共有リンクにして、メール・チャット・チケット・SNS などで送る
2. 被害者がリンクを開き Preview を表示すると、MathLive のメッセージ受信側の検証不備を経由して信頼されたページへ HTML が渡る
3. 被害者のセッションと同じ権限でコードが実行され、会話の一覧取得・非公開チャットの読み取りなどが可能になる（研究者の検証）

【被害規模】
実被害の報告なし。研究者は別アカウント間の検証で、被害者の最近の会話一覧の取得、共有していない非公開チャットの開封とその一部の外部送信まで実証した（The Hacker News）。

【監視】
修正は OpenAI 側で適用済み（利用者側の対応は不要）。共有リンクの出所確認と、見知らぬ共有リンクで Preview を押さない運用を周知する。
実環境での悪用は報告されていない。

- A Shared ChatGPT Link Could Run Attacker Code in Your Session and Read Private Chats (The Hacker News) https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html
