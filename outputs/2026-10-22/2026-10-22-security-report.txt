被害規模: PyPI の LiteLLM 1.107.0 wheel（Windows／macOS／Linux 各種）と Docker イメージが対象。パッケージは隔離・悪意ある Docker イメージは削除済み。被害件数・感染数は未公表。

【概要】

【監視】

CVE-2026-109618 PHP（OOM 時の longjmp 処理＝PHP2Shell）
------------------------------------------------------------
ベンダー: PHP Group / 影響: PHP 8.5.12 未満／8.4.27 未満／8.3.36 未満／8.2.35 未満（情報源：PHP 5.4 まで遡る広範囲。8.1 以前は公式更新なし・ソースバックポートのみ）
CVSS v3: 9.8 / v4: 9.2 / KEV: 未収載 / PoC: 公開 / 実悪用: 未確認
パッチ: 8.5.12／8.4.27／8.3.36／8.2.35 以降（ディストリビューションは旧版番号のまま修正を含む場合あり）

【24時間以内の変化】
[The Hacker News（watchTowr・Cloudflare 引用） 2026-10-21] PHP が計画の 10-22 から前倒しで 14:00 UTC に修正版を公開。watchTowr は 14:19 UTC 時点で両 CVE への『悪用試行』を報告（Cloudflare も攻撃試行とペイロード変更を観測）。侵入成功の確認報告はなし。KEV 未収載。

【概要】
THN によれば、PHP は OOM 時に longjmp() で現在のコンテキストを抜けるが、リクエストメモリを指すグローバル状態が残る場合があり、未認証のリモートコード実行に至る（PHP 評価 CVSS v4.0 9.2・NVD の v3.1 は 9.8）。Wiz Research・Calif・OpenAI Codex Security が発見。Calif が 10-20 に PoC 動画を誤って投稿し、watchTowr が再現。Cloudflare が事前に攻撃試行を観測、watchTowr が 10-21 14:19 UTC に悪用試行を報告した。個別サーバーでの侵入成功は未確認。オランダの DigiD 等と BambooHR が予防的に停止した。

【攻撃フロー】
1. 細工した大容量マルチパート要求などでメモリ上限に到達させる
2. longjmp による異常脱出で壊れたグローバル状態が残る
3. mod_php 等で未認証のコード実行（情報源が単一リクエストでの実証と記述）

【ATT&CK】
- T1190 Exploit Public-Facing Application: 細工したマルチパート要求等で PHP 実行環境（mod_php／PHP-FPM 等）の脆弱性を未認証で突く（情報源の記述：mod_php で単一の未認証リクエストによる実証）

【暫定対策】
- PHP を 8.5.12／8.4.27／8.3.36／8.2.35 以降へ更新する（ディストリビューションの changelog で CVE を確認）
- 暫定: memory_limit=-1 を固定し post_max_size を低く保ち、Web サーバー／プロキシでリクエストサイズを制限（RLIMIT_AS／RLIMIT_DATA は使わない）
- 更新後は新しいハードメモリ上限でプロセスが終了し得るため設定を見直す

【監視】
マルチパート要求後のメモリ上限エラー・HTTP 500 の連続、PHPSESSID の異常に大きい応答 Cookie、PHP ワーカーの原因不明の再起動を監視する。
