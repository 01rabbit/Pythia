1. CVE-2026-68820 / Microsoft Windows Ancillary Function Driver for WinSock (afd.sys)
対象: 2026年8月Patch Tuesday時点でサポート対象の全Windowsバージョン（afd.sys搭載）
------------------------------------------------------------

優先度: 必須
CVSS: 7.0 (High)
状態: KEV登録済み / 実悪用確認 / ゼロデイ

【24時間以内の変化】
[BleepingComputer 2026-08-11] 2026年8月Microsoft Patch Tuesdayで400件の脆弱性を修正、うちCVE-2026-68820（afd.sys use-after-free権限昇格）が実悪用中のゼロデイと公表
[The Hacker News 2026-08-11] CVE-2026-68820をWindowsドライバのゼロデイとして報道、Check Point Researchが北朝鮮Lazarus GroupによるFudModuleカーネルルートキット展開への悪用を確認したと報道
[CISA KEV 2026-08-11] CVE-2026-68820がCISA KEVカタログへ本日付で新規追加（catalogVersion 2026.08.11）

【概要】
Windows Ancillary Function Driver for WinSock（afd.sys）のuse-after-freeによるローカル権限昇格の脆弱性CVE-2026-68820が2026年8月Patch Tuesdayで修正され、Check Point Researchの分析に基づき北朝鮮Lazarus Groupがカーネルモードルートキット「FudModule」を展開する目的で実悪用していたことが確認された。悪用には対象端末上で既にコード実行権を得ていることが前提となるレース条件を利用してSYSTEM権限へ昇格する。

攻撃の流れ:
1. 初期侵入（Lazarus Groupの既知手口。本CVE単体の記述には含まれない）で対象端末上のコード実行権を獲得
2. afd.sysのuse-after-freeを利用したレース条件でSYSTEM権限へ昇格
3. カーネルモードルートキットFudModuleを展開し検知回避・永続化

【暫定緩和策】（パッチが提供されるまでの間の対処）
・2026年8月Patch Tuesday累積更新プログラムの即時適用（回避策は公表されていない）

【IoC】
IoC: 確認されず

【監視ポイント】
・[SIEM/Splunk] afd.sys経由の権限昇格およびFudModule系カーネルルートキットの展開兆候を監視する
Splunk SPL: index=wineventlog EventCode=4688 (NewProcessName="*\\svchost.exe" OR NewProcessName="*\\lsass.exe") ParentProcessName!="*\\services.exe" | stats count by Computer, NewProcessName, ParentProcessName
Splunk SPL: index=wineventlog EventCode=6 OR EventCode=7045 ImageLoaded="*.sys" Signed=false | stats count by Computer, ImageLoaded
→ afd.sys自体は正規ドライバのため異常検知は権限昇格後の挙動（未署名ドライバロード・LSASSアクセス増加）に着目する

2. CVE-2026-72898 / Metabase（BI/分析プラットフォーム）
対象: 2026-08-07修正版未適用の全バージョン（自己ホスト型・Metabase Cloud両方に影響）
------------------------------------------------------------

優先度: 必須
CVSS: 10.0 (Critical)
状態: KEV登録済み / 実悪用確認 / ゼロデイ

【24時間以内の変化】
[CISA KEV 2026-08-11] CVE-2026-72898がCISA KEVカタログへ本日付で新規追加（catalogVersion 2026.08.11）
[The Hacker News 2026-08-11] 未認証SQLインジェクション経由で管理者アクセスを奪取するゼロデイの実悪用が確認され、複数組織の顧客データが窃取されたと報道

【概要】
BI/分析プラットフォームMetabaseの/reset_passwordエンドポイントに存在する未認証SQLインジェクションの脆弱性CVE-2026-72898（CVSS10.0）が、2026-08-06にMetabase Cloudへのゼロデイ攻撃として実悪用されたことが確認された。攻撃者は本脆弱性を用いてアプリケーションデータベースへ任意SQLを注入し管理者権限を奪取、接続先データベースの認証情報窃取・データ読み取り・エクスポートが可能となる。複数組織が既に顧客データ窃取の被害を受けている。

攻撃の流れ:
1. 未認証で/reset_passwordエンドポイントへSQLインジェクションペイロードを送信
2. アプリケーションデータベースを操作し管理者アクセス権を奪取
3. 接続済みデータベースの認証情報窃取・顧客データの読み取り/エクスポート

【暫定緩和策】（パッチが提供されるまでの間の対処）
