SOC-2026-11-08-001 [high] SonicWall SonicOS：悪用中の SSL-VPN 認証回避（CVE-2026-19868）を含む 7 件の修正が公開、速やかに更新
------------------------------------------------------------
対象: SonicWall SonicOS SSLVPN

【概要】
BleepingComputer によれば SonicWall は SonicOS の 7 件の脆弱性を修正し、SSL-VPN の認証回避が実際の攻撃で悪用されている。SecurityWeek によれば CVE-2026-19868 は、別の認証方式の資格情報を持つ攻撃者が SAML 検査（SAML 強制の MFA を含む）を回避できる。CISA KEV には 11-06 に収載済み（期限 11-20）。影響版・修正版の番号は未取得。

【推奨アクション】
1) SonicWall の勧告で影響版と修正版を確認し更新を適用。2) SSLVPN で SAML 以外の認証方式を無効化。3) SAML を経由しない認証成功ログとMFA 欠落を遡って確認。
  参照: https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks (BleepingComputer)
  参照: https://www.securityweek.com/sonicwall-patches-exploited-sonicos-bug-that-weakens-vpn-logins (SecurityWeek)

SOC-2026-11-08-002 [medium] Claude Code 利用リポジトリの .claude/settings.local.json に混入した秘密情報の棚卸しとローテーション
------------------------------------------------------------
対象: Claude Code（.claude/settings.local.json）

【概要】
Apiiro の調査では、公開 GitHub 上の同ファイルの約 1.1% に秘密情報が含まれる。ファイルを消しても git 履歴・フォークに残るため、先に秘密を無効化する必要がある。悪用の報告は無い。

【推奨アクション】
1) 自組織のリポジトリ（履歴・フォーク含む）で .claude/settings.local.json を検索。2) 過去に含まれた秘密を先にローテーション。3) プロジェクトの .gitignore に追加し、秘密をコマンド引数に直接書かない運用にする。
  参照: https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html (The Hacker News)

SOC-2026-11-08-003 [medium] 金融機関：サービスプロバイダー（委託先）経由の不正取引に備えた委託先接続と送金承認の点検
------------------------------------------------------------
対象: 金融機関の委託先・決済関連接続

【概要】
Crédit Mutuel Arkéa がサービスプロバイダー経由の攻撃で最大 1.33 億ドルの不正取引を受けた（BleepingComputer）。詳細は未確認だが、委託先経由の送金・承認系の経路が狙われる例として点検対象になる。

【推奨アクション】
1) 委託先から接続される送金・承認系 API の権限と上限額を確認。2) 異常な高額・短時間の連続取引の検知条件を点検。3) 委託先のインシデント通知経路を確認。
  参照: https://www.bleepingcomputer.com/news/security/hackers-pull-off-133-million-french-bank-heist-via-service-provider (BleepingComputer)
