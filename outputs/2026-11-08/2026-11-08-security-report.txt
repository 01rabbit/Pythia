AI-2026-11-08-002 [B/B2] X=4 Y=5 Apiiro：Claude Code の「今後は確認しない」承認で保存される設定ファイルに平文の秘密情報、公開 GitHub の 1,122 件に露出
------------------------------------------------------------

【概要】
THN によれば、Apiiro は、Claude Code で「Yes, and don't ask again」を選ぶと、承認したコマンドが秘密情報（パスワード・トークン）を含んだまま .claude/settings.local.json に平文保存される場合があり、公開 GitHub の 103,617 リポジトリにある 104,185 件のうち約 1.1%（1,122 件・1,379 個の秘密）に秘密が残っていると報告した。ファイルを削除しても git 履歴とフォークに残るため、ローテーションが先決とされる。攻撃者による悪用は報告されていない（推測：公開リポジトリの機械走査で収集され得る）。
被害規模: 公開 GitHub 上の 103,617 リポジトリ中 1,122 件の .claude/settings.local.json に秘密情報が含まれる（Apiiro の調査）。実際に有効かの検証は未実施で、通知した 1 社が有効と確認したとのこと。
  参照: https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html (The Hacker News)
