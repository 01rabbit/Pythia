AI-2026-11-19-001 [カテゴリC] Microsoft 公式 PyPI パッケージ『agent-framework』1.26.1／1.26.2 が侵害され資格情報窃取コードを同梱：.pth ファイルで起動時に環境変数・Azure CLI・npmrc・git-credentials・OIDC トークン・IMDS を収集し webhook[.]site へ送出（公開 45 分で隔離）
------------------------------------------------------------
The Hacker News・SecurityWeek・BleepingComputer によれば、Microsoft の AI エージェント開発基盤『Agent Framework』の公式 PyPI パッケージ agent-framework に 2026-11-17 20:35〜21:20 UTC、悪性版 1.26.1 と 1.26.2 が公開された。悪性版は agent_framework_meta.pth や af_runtime_diag.pth／af_runtime_diag.py といった .pth ファイルを同梱し、Python 起動時に自動実行されて環境変数、Azure CLI の資格情報、.npmrc・.netrc・.git-credentials、Docker 設定、Hugging Face トークン、Azure DevOps・GitHub Actions の OIDC トークン、マネージド ID トークン、IMDS 情報を収集し、webhook[.]site/d381fd80-ec62-42ad-8f5c-d1b15103c9bb へ送出した。Aikido・Chainguard・Endor Labs・OX・SafeDep・Socket・StepSecurity・Wiz が報告し、PyPI は約 45 分で隔離した。侵入経路は Microsoft 未公表。10 月の LiteLLM 1.107.0 侵害（既報・.pth 経由の資格情報窃取）と同系の手口であり、AI エージェント基盤の PyPI 供給網が連続して狙われている。
  被害規模: 悪性版 2 件（1.26.1・1.26.2）は 2026-11-17 20:35〜21:20 UTC の約 45 分間公開され PyPI が隔離。ダウンロード数・被害組織数は各社とも公表していない。侵入経路（メンテナ資格情報か CI か）は Microsoft 未公表。
  監視: agent-framework 1.26.1／1.26.2 を導入した環境を特定し、webhook[.]site への通信、.pth ファイルの追加、CI 内の資格情報利用を監視する。
  IOC: ドメイン webhook[.]site/d381fd80-ec62-42ad-8f5c-d1b15103c9bb / ハッシュ なし
  参照: https://thehackernews.com/2026/11/attackers-compromise-microsofts-agent.html (The Hacker News)

AI-2026-11-19-002 [カテゴリC] Rapid7：インターネット露出の自己ホスト AI サーバー（Ollama 等）7,600 台超を調査、半数超に第三者の痕跡・79% が ollama.com のクラウドモデルにサインイン済みで『計算資源の間借り（LLMjacking）』が常態化。Probllama 型パストラバーサルの試行も 55 台で確認
------------------------------------------------------------
Rapid7 は 2026-11-18、インターネットに露出した自己ホスト AI 推論サーバーの実態調査を公表した。11-10 の走査で 20,354 IP を調べ、未認証の AI API を公開する 7,627 台（Ollama が 7,675 台）を確認。54.8% のホストに所有者以外が投入したモデル・アーティファクトの痕跡があり、79% は ollama.com のアカウントでクラウドモデルにサインイン済みのため、第三者がホスト所有者の課金でクラウドモデルを使える状態（LLMjacking）にあった。55 台では Ollama の既知脆弱性 Probllama 型のパストラバーサル・ペイロードが観測され、コールバック先として 24.144.109[.]68:9882、103.249.201[.]108:9882、76.13.49[.]213:9882、62.31.247[.]107:9882、43.143.113[.]68:8899、185.165.171[.]21:8899 が記録された。本件は特定アクターの作戦ではなく、露出 AI 基盤が既に第三者に『占有』されているという面の調査であり、同日に KEV へ追加された LiteLLM CVE-2026-40217 とあわせ、自己ホスト AI ゲートウェイ・推論サーバーの露出面が実被害に直結している。
  被害規模: Rapid7 の 11-10 走査で 20,354 IP のうち未認証 AI API 7,627 台（Ollama 7,675 台）。54.8% に第三者のモデル・アーティファクトの痕跡、79% が ollama.com アカウントでクラウドモデルにサインイン済み（所有者の課金で利用可能）。個別被害額は不明。
  監視: Ollama／vLLM 等の API ポートの外部露出を棚卸しし、認証プロキシの前置、ollama.com アカウント連携の見直し、上記コールバック IP への通信を監視する。
  参照: https://www.rapid7.com/blog/post/tr-self-hosted-ai-renting-compute-exposed-servers (Rapid7)

------------------------------------------------------------
