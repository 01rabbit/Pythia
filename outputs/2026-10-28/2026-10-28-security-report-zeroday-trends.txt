Lazarus Group LazarusGroup-2026-OperationFlashHole-CrossWebEX（帰属信頼度: medium・P=6 Q=4）
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News（Kaspersky GReAT） 2026-10-27] Kaspersky が Operation FlashHole（Cascade Hole の最新波）を報告。INISAFE CrossWeb EX の悪用と GitHub・Dropbox 経由の配信、ML-KEM-1024 によるポスト量子暗号チャネルを確認。

【概要】
THN が伝える Kaspersky GReAT の報告によれば、Lazarus Group は Operation FlashHole で韓国の建設・ソフトウェア・有線通信機器製造の少なくとも 3 組織を標的とした。必須金融セキュリティソフト INISAFE CrossWeb EX を悪用して fsquirt.exe を起動し悪意ある DLL を読み込ませ、TechHub が GitHub から TouchHub／TouchShift を取得する。新たに確認された ClientHub は HTTPS と Dropbox API の 2 方式を持つ。Innorix Agent の 1-day 脆弱性を横展開に使い、通信は ML-KEM-1024 のポスト量子鍵交換で確立される。帰属は Kaspersky の評価（情報源が明示）。CVE-2026-68820（Windows AFD ゼロデイ）は Check Point が 8 月に報告した関連チェーンとして記事で言及されたもので、本件での関与の度合いは記事から確認できていない。

【攻撃フロー】
1. スピアフィッシング（偽の履歴書・ポートフォリオ）または改ざんした韓国サイトの水飲み場攻撃
2. INISAFE CrossWeb EX 悪用で fsquirt.exe 起動→TechHub DLL をサイドロード（メモリ内実行）
3. GitHub から TouchHub／TouchShift を取得し、キーロガー・スクリーンショット・ClientHub バックドアを展開
4. Innorix Agent の 1-day で横展開、ML-KEM-1024 の暗号化チャネルで追加マルウェアをメモリ内に取得

【TTP】
- T1566.002 Phishing: Spearphishing Link: 各標的向けに作られた偽の履歴書・ポートフォリオサイトへのリンク（情報源の記述）
- T1189 Drive-by Compromise: 改ざんした韓国のサイトによる水飲み場攻撃（情報源の記述）
- T1574.002 DLL Side-Loading: 正規の fsquirt.exe と mscoree.dll 等を利用したサイドロード（情報源の記述）
- T1102 Web Service: GitHub からのペイロード取得と Dropbox API のバックドア通信（情報源の記述）
- T1210 Exploitation of Remote Services: Innorix Agent の 1-day 脆弱性を横展開に使用（情報源の記述）

【推奨アクション】
韓国の金融・行政向け必須セキュリティソフト（INISAFE CrossWeb EX、Innorix Agent 等）を最新化し、fsquirt.exe や SyncHost.exe からの不審な DLL 読込（mscoree.dll など）、GitHub・Dropbox API への異常な通信を監視する。

- Lazarus Abuses South Korean Security Software to Deploy Malware Using Post-Quantum Encryption (The Hacker News) https://thehackernews.com/2026/10/lazarus-abuses-south-korean-security.html

Dahua IP カメラ乗っ取り：CERT-UA がウクライナ標的を警告、P2P（Easy4IP）の認証の弱さ悪用
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News 2026-10-27] CERT-UA の警告と Hunt.io の分析を報じた。

【概要】
THN によれば、CERT-UA はウクライナの Dahua 製 IP カメラ・NVR・DVR を狙う攻撃を警告した。初期アクセスは弱いまたは既知のパスワード、旧ファームウェアの認証バイパス（CVE-2021-33044／33045）で、Dahua の P2P 基盤 Easy4IP ではシリアル番号が予測可能でレート制限なく総当たりできるため、直接公開されていない機器も危険とされる。Hunt.io は別クラスターで 58 台（ウクライナ）、「CameraSwarm」と名付けた作戦で 14,530 台超の Dahua カメラ侵害を報告し、約 1,923 台にバックドアアカウント（p2pwn）が置かれ、多くのファームでパスワード変更や初期化後も残る。CERT-UA の活動の攻撃者は不明。Hunt.io の第一クラスターはロシア語話者の運用者と帰属し、7 月のオランダ情報機関の注意情報はロシア国家系アクターが EU・NATO・ウクライナで IP カメラを侵害していると述べる（本件との同一性は記事中では示されていない）。P2P 問題に対するパッチの記載はなく、P2P の無効化が推奨される。

eMudhra 中間 CA の秘密鍵 8 本が極めて脆弱：Microsoft が OOB 更新で信頼を削除
------------------------------------------------------------
【24時間以内の変化】
[BleepingComputer 2026-10-27] Microsoft が OOB 更新を公開し eMudhra 証明書の信頼を削除。

【概要】
BleepingComputer によれば、eMudhra の中間 CA 証明書 8 本の秘密鍵は 2025 年 4 月に 256 未満の値で生成されており、256 通りの試行で復元できる。偽の証明書で正規サイトになりすまし通信を傍受できる恐れがある。eMudhra は 8 本を失効し、Mozilla・Google・Apple も失効を開始した。Microsoft は 10-26 に OOB 更新（KB5134133＝Windows 11 24H2/25H2/26H2、KB5134125＝Windows 10 21H2/22H2）で 7 証明書の信頼を削除し、Edge の信頼リストからも 10-27 に削除する。信頼更新が自動で届かないオフライン環境などが対象。実悪用の報告は記事に無い。NVD には HCL Domino など下流製品の CVE（CVE-2026-108014／108015）が公開されている。

【参照】
- Microsoft releases Windows OOB updates to distrust eMudhra certificates (BleepingComputer) https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-windows-oob-updates-to-distrust-emudhra-certificates

Tailscale SSH の「Tailworm」11 件の脆弱性：修正前に詳細が公開
------------------------------------------------------------
【24時間以内の変化】
[BleepingComputer／SecurityWeek 2026-10-27] Tailworm の公開と Tailscale の対応表明。

【概要】
BleepingComputer・SecurityWeek によれば、Cyberdione Labs が Tailscale SSH などの脆弱性 11 件（総称 Tailworm）を監査で発見し、修正リリース前に詳細を公開した。最も深刻なのは Unix ソケット転送により、承認済みの利用者が対象ホストで root のコード実行を得られる問題（承認済みデバイス 1 台と SSH ポリシー 1 件が必要）。v1.104.2 と headscale v0.29.5 で再現。CVE・CVSS・修正版は記事に無く、Tailscale は 10-27 中の修正を目指すとした。悪用の報告は無い。暫定策は SSH アクセスポリシーの見直しと、不要なら tailscaled に TS_SSH_DISABLE_FORWARDING=1 を設定すること。
