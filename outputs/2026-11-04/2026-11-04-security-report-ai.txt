【概要】

AI-2026-11-04-003 LLMjacking：窃取した API キー等で企業の LLM アクセスを乗っ取り、最大 100 万ドルのクラウド課金（Google 警告）
カテゴリ A/A4・X=5 Y=6・バースト: below_threshold
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News / Dark Reading 2026-11-03] LLMjacking：窃取した API キー等で企業の LLM アクセスを乗っ取り、最大 100 万…[新規]

【概要】
Google は 11-02（月曜）に、LLMjacking（資源ハイジャックの LLM 版）で企業が最大 100 万ドルのクラウド料金を負担した例があると警告した（THN）。API キーはフィッシング、ソースコード漏えい、設定不備、クライアント側に露出したコードから入手される。Dark Reading は、クラウドの LLM アクセスの転売が犯罪の収益事業になっていると報じた。個別の攻撃者・IOC は無い。

【被害規模】
個別事例で最大 100 万ドルのクラウド課金（Google）。

【攻撃フロー】
1. フィッシング・漏えい・設定不備等で LLM の API キーを入手
2. 高額な計算資源を不正利用し、アクセスを転売

- Google Warns LLMjacking Attacks Are Costing Some Enterprises Up to $1 Million in Cloud Charges https://thehackernews.com/2026/11/google-warns-llmjacking-attacks-are.html
