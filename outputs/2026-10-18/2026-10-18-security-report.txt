------------------------------------------------------------
優先度: medium  軸1=8 軸2=2  KEV登録: なし  悪用: 未確認  パッチ: あり
影響バージョン: Entity List 3.0.10 未満（BleepingComputer 記載）。コア CVE-2026-108097（Field UI）と同時に公表

【24時間以内の変化】
[BleepingComputer 2026-10-17] Drupal が CVE-2026-108097（コア Field UI・既報）と CVE-2026-108099（Entity List）の RCE を公表。Drupal セキュリティチームは『数時間〜数日で悪用コードが出る可能性』と警告。実悪用は未確認。

【概要】
BleepingComputer によれば Drupal は、サポート中の全コア版に影響する Field UI の RCE（CVE-2026-108097・既報）と、コントリビュートモジュール Entity List の RCE（CVE-2026-108099・sa-contrib-2026-218）を修正した。コア単独では悪用できず、コントリビュートモジュールやカスタムコード経由で露出する。少なくとも1つの経路は認証不要。CVSS は記事に記載なし。実悪用・公開 PoC は確認されていない。

【攻撃フロー】
1. 認証不要の経路を持つコントリビュートモジュール／カスタムコード経由で Field UI または Entity List の欠陥に到達し任意コード実行（記事の記述に基づく概要）

【暫定緩和策】
- Drupal コアを 10.6.19 / 11.3.19 / 11.4.10、Entity List を 3.0.10 へ更新
- 更新できない場合は field_ui モジュールをアンインストール（Drupal Steward は一部経路のみ防御）

【監視】

SOC-2026-10-18-001 ConnectWise Cloud Backup M365 アプリの侵害 — 該当アプリの無効化と Entra 監査
------------------------------------------------------------
対象: ConnectWise Cloud Backup / Cloud Management（旧 SkyKick）の Microsoft 365 アプリ

【24時間以内の変化】
[The Hacker News / BleepingComputer 2026-10-17] Huntress が173テナントで不正サインインを確認、ConnectWise がサービスを停止。

【概要】
同一アプリの資格情報が同意済みの全テナントで有効なため、アプリを導入した組織は影響を受けうる。セッション失効だけではアクセスは止まらず、発行済みトークンは無効化後も最大90分有効（THN）。
【推奨アクション】
- ConnectWise が資格情報のリセットを確認するまで該当アプリをテナントで無効化する
- Microsoft Graph アクティビティログを有効化し、2026-10-13 以降に追加された資格情報・クライアントシークレットを監査する
- Entra 監査ログで ConnectWise／SkyKick アプリのディレクトリロール自己付与を確認する
- IP 144.172.64[.]128 と User-Agent Python-urllib/3.12 のサービスプリンシパルサインインを検索する
【監視】
想定外 IP（Azure/Microsoft 範囲外）からのサービスプリンシパル認証、アプリ資格情報の追加、OAuth 付与を監視する。

【参照】
- Hackers Use Compromised ConnectWise Credential to Sign In to 173 Microsoft 365 Tenants (The Hacker News) https://thehackernews.com/2026/10/hackers-use-compromised-connectwise.html
- Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack (BleepingComputer) https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack
