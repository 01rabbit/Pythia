SOC-2026-10-18-001 ConnectWise Cloud Backup M365 アプリの侵害 — 該当アプリの無効化と Entra 監査
------------------------------------------------------------
対象: ConnectWise Cloud Backup / Cloud Management（旧 SkyKick）の Microsoft 365 アプリ

【24時間以内の変化】
[The Hacker News / BleepingComputer 2026-10-17] Huntress が173テナントで不正サインインを確認、ConnectWise がサービスを停止。

【概要】
同一アプリの資格情報が同意済みの全テナントで有効なため、アプリを導入した組織は影響を受けうる。セッション失効だけではアクセスは止まらず、発行済みトークンは無効化後も最大90分有効（THN）。
【推奨アクション】
- ConnectWise が資格情報のリセットを確認するまで該当アプリをテナントで無効化する
- Microsoft Graph アクティビティログを有効化し、2026-10-13 以降に追加された資格情報・クライアントシークレットを監査する
- Entra 監査ログで ConnectWise／SkyKick アプリのディレクトリロール自己付与を確認する
- IP 144.172.64[.]128 と User-Agent Python-urllib/3.12 のサービスプリンシパルサインインを検索する
【監視】
想定外 IP（Azure/Microsoft 範囲外）からのサービスプリンシパル認証、アプリ資格情報の追加、OAuth 付与を監視する。

【参照】
- Hackers Use Compromised ConnectWise Credential to Sign In to 173 Microsoft 365 Tenants (The Hacker News) https://thehackernews.com/2026/10/hackers-use-compromised-connectwise.html
- Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack (BleepingComputer) https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack

SOC-2026-10-18-002 Drupal コア Field UI／Entity List の RCE（CVE-2026-108097・CVE-2026-108099）— 悪用コード出現前に更新
------------------------------------------------------------
対象: Drupal 10.6／11.3／11.4 系コアと Entity List モジュール

【24時間以内の変化】
[BleepingComputer 2026-10-17] Drupal セキュリティチームが『数時間〜数日で悪用コードが出る可能性』と警告。

【概要】
コア単独では悪用できないが、コントリビュートモジュール・カスタムコード経由で露出する。実悪用は未確認（本窓時点）。
【推奨アクション】
- Drupal コアを 10.6.19 / 11.3.19 / 11.4.10、Entity List を 3.0.10 へ更新する
- 更新できない場合は field_ui モジュールをアンインストールする
【監視】
Web ルート配下の新規 PHP ファイルと Field UI 関連エンドポイントへの不審なリクエストを監視する。

【参照】
- Drupal patches critical RCE flaws, warns exploits may emerge soon (BleepingComputer) https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploits-may-emerge-soon

SOC-2026-10-18-003 悪意ある npm パッケージ imgdecode（MALFEX）— 依存関係の点検
------------------------------------------------------------
対象: npm レジストリ／Windows 開発環境

【24時間以内の変化】
[The Hacker News 2026-10-17] imgdecode（979 DL）が報告時点で npm に残存。

【概要】
Windows ネイティブアドオンにシェルコードローダーを隠すとされる。詳細は原典未確認。
【推奨アクション】
- 依存関係とロックファイルに imgdecode が含まれていないか確認する
【監視】
npm install 時のネイティブアドオン（.node）ビルド／読み込みを監視する。

【参照】
- MALFEX npm Package imgdecode (The Hacker News) https://thehackernews.com/2026/10/malfex-npm-package-imgdecode-hides.html
