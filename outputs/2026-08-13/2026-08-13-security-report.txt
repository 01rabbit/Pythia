対象: it / manufacturing / telecom / global
被害規模: CloudSEK確認: 約434,000件の窃取ファイル・イベントを分析し2,500組織超の露出を確認（NVIDIA・Cisco・Deloitte・Volkswagen・FedEx・Siemens・X Corp等の名前を含むデータセット公開。ただし露出=確認済み侵害ではない点にCloudSEKも留意を促している）
独立ソース数: 2件（below_threshold）

【24時間以内の変化】
[The Hacker News 2026-08-12] CloudSEKが、2026年3月のAqua Security Trivy侵害経由で流出したPyPIトークンを用いてLiteLLM 1.82.8へ悪意あるコードが混入された事案（PyPI滞在約40分・2026-03-24 10:39〜16:00 UTC）について、約434,000件の窃取ファイル・イベント分析に基づき2,500組織超の露出を確認したと報告。悪意あるバージョンには`litellm_init.pth`というPythonインタプリタ起動時に自動実行されるファイルが含まれ、LiteLLMをインポートしなくても影響を受ける設計だったと新たに判明
[SecurityWeek 2026-08-12] CloudSEKが露出組織を名前・ドメインで検索できる公開データセット（exposure.cloudsek.com/ai-supply-chain-incident）を公開したと報道。以前は別々に語られていた複数の被害報告が「同一攻撃チェーンの異なる段階」であったことも整理された

【概要】
2026年6月19日付で既報のLiteLLM PyPIサプライチェーン侵害（Aqua Security Trivyの侵害を起点に窃取したPyPIトークンでLiteLLM 1.82.8へ悪意あるコードを混入、TeamPCPによる認証情報窃取・Vectランサムウェアとの連携）について、脅威インテリジェンス企業CloudSEKが2026-08-12、約434,000件の窃取ファイル・イベントの分析に基づき2,500組織超が露出したと報告した。技術的な新知見として、悪意あるバージョンにはPythonインタプリタ起動時に自動実行される`litellm_init.pth`ファイルが含まれ、LiteLLMを直接インポートしていない環境でも影響を受ける設計だったことが判明。CloudSEKは露出組織を検索できる公開データセットを提供し、NVIDIA・Cisco・Deloitte・Volkswagen・FedEx・Siemens・X Corp等の大企業名を含むが、リスト掲載は侵害の確定を意味しないと注記している。

攻撃の流れ:
1. 2026年3月、Aqua Security Trivyの侵害で漏洩したPyPI APIトークンを攻撃者が悪用
2. LiteLLM 1.82.8へ、Pythonインタプリタ起動時に自動実行される`litellm_init.pth`を含む悪意あるコードを混入しPyPIへ直接アップロード（滞在時間約40分）
3. ダウンロードした環境でクラウド鍵・SSH鍵・Kubernetesトークン・DBパスワード等の認証情報を窃取

【IoC / 検知シグナル】

検知シグナル: litellm_init.pth ファイルの存在（sitecustomize相当の自動実行ファイル）

【監視・対策ポイント】
・CI/CD環境・Python実行環境における`litellm_init.pth`ファイルの存在と2026年3月時点のLiteLLM 1.82.8導入履歴を確認する

【概要】
北朝鮮系Lazarus Groupが、長期継続中のOperation Dream Jobキャンペーン（LinkedIn経由の偽採用勧誘による標的接近）の一環として、2026年7月上旬からWindows Ancillary Function Driver for WinSock（AFD.sys）のuse-after-free脆弱性CVE-2026-68820をゼロデイとして実悪用し、フランス・ドイツ・ブラジル・インドの防衛・航空宇宙企業（偵察センサー・ドローン・ロボティクス関連技術を保有）を標的に、新型バックドアTroy・ForestTiger・MISTPENダウンローダ・カーネルモードルートキットFudModule 3.1を展開していたことがCheck Point Researchの調査で判明した。侵害済みのWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113悪用）をC2インフラとして利用し、PHP製の未文書化ウェブシェルRelayShellも新たに確認された。フランス国内で少なくとも1組織が侵害を受け、その組織を踏み台にした二次スピアフィッシングへの悪用も確認されている。Microsoftは本CVEを2026年8月Patch Tuesdayで修正し、CISAはKEVカタログへ初回追加、JPCERT/CCも注意喚起を発行した。

攻撃の流れ（判明分）:
1. LinkedIn経由の偽採用勧誘（Operation Dream Job）で防衛・航空宇宙企業の従業員に接触
2. 侵害済みWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113）経由でマルウェア配布・C2確立
3. CVE-2026-68820（AFD.sys UAF）を悪用しローカル権限昇格でSYSTEM権限を取得
4. FudModule 3.1でSmart App Control改ざん・EDRテレメトリ無効化、Troy/ForestTiger/MISTPENを展開し長期潜伏・偵察
5. 侵害済み組織を踏み台としたスピアフィッシングで関連組織への横展開を試行

観点: ゼロデイ関連
採用契機: ε / γ
------------------------------------------------------------

優先度: 中
対象: Windows 11（完全更新環境含む）

【24時間以内の変化】
[BleepingComputer 2026-08-12] 研究者Alejandro Hernando・Borja MartínezがDEF CON 34（2026年8月）で、Windows Plug and Play機能を悪用しUACプロンプトなしでSYSTEM権限のドライバ・co-installerを実行させる「Plug and Pwn」攻撃を発表。FaceDancer等のUSBエミュレーション機材またはRDP USB転送機能で物理アクセスなしにも再現可能、完全更新済みWindows 11でも約5分で成立

【概要】
Windows の Plug and Play 機能・co-installer 実行パスが NT AUTHORITY\SYSTEM 権限で UAC プロンプトなしに実行されることを悪用し、エミュレートしたUSBデバイスまたはRDP USBリダイレクト経由で脆弱なベンダー製ドライバ・co-installerのインストールを強制しSYSTEM権限を取得する手法。Sierra Wireless・Sony FeliCa・Intel RealSense・Wacom・Atheros等複数ベンダーのソフトウェアで実証された。既知の脆弱性（CVE-2019-10617等、旧CVEの新規適用でありトラックA新規CVEには該当しない）を利用したチェーンであり研究開示のみで実悪用の報告はないが、`DisableCoInstallers`レジストリ値の設定等の緩和策がある。

【推奨アクション】
・`DisableCoInstallers`レジストリキーの設定を検討する（完全な対策ではない点に留意）
・デバイスインストール制限ポリシー（Group Policy）の適用を検討する
・RDP経由のUSBリダイレクト機能が不要な環境では無効化する
Splunk SPL: index=wineventlog EventCode=20001 OR EventCode=7045 | stats count by Computer,DriverName
→ 通常業務で使用しないベンダーのco-installerインストールイベントを優先確認する。
