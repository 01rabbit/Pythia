1. CVE-2026-68820 / Windows Ancillary Function Driver for WinSock (AFD.sys)
対象: Windows 11 build 26100/26200 等（2026年8月Patch Tuesdayで修正）
------------------------------------------------------------

優先度: 緊急
CVSS: 7.0 (High)
状態: KEV登録済み / 実悪用確認 / ゼロデイ
パッチ提供: 提供済み

【24時間以内の変化】
[Check Point Research 2026-08-12] Lazarus Groupが2026年7月上旬からCVE-2026-68820（AFD.sys use-after-free・権限昇格）をOperation Dream Jobキャンペーンで実悪用していたと報告（レポート「Shattering the Dream」）
[Microsoft/JPCERT-CC 2026-08-12] 2026年8月Patch Tuesdayで修正版を提供、Microsoft自身が実悪用を確認と明記。JPCERT/CCが本CVEを名指しした注意喚起（at260022.html）を発行
[BleepingComputer/The Hacker News/SecurityWeek 2026-08-12] Check Pointレポートを受け、Lazarus Groupによる欧州・南米・アジアの防衛/航空宇宙企業標的の攻撃としてそれぞれ詳報

【概要】
Windows Ancillary Function Driver for WinSock（AFD.sys）のuse-after-free脆弱性CVE-2026-68820を、北朝鮮系Lazarus GroupがOperation Dream Jobキャンペーンの一環として2026年7月上旬から実悪用し、ローカル権限昇格経由でSYSTEM権限を取得しForestTiger（別名ScoringMathTea）・新型バックドアTroy・軽量ダウンローダMISTPEN・カーネルモードルートキットFudModule 3.1を展開していたことがCheck Point Researchの調査で判明した。標的はフランス・ドイツ・ブラジル・インドの防衛・航空宇宙企業で、偵察センサーやドローン等の軍事関連技術を持つ企業が狙われた。攻撃はLinkedIn経由の偽採用勧誘から始まり、侵害済みのWordPress/SharePoint/脆弱なRoundcubeウェブメールサーバ（CVE-2025-49113悪用）をC2インフラとして利用、PHP製ウェブシェルRelayShellも新たに確認された。Microsoftは2026年8月Patch Tuesdayで修正を提供し実悪用を確認、CISAは2026-08-11付でKEVカタログへ初回追加、JPCERT/CCも同CVEを名指しした注意喚起を発行した。

攻撃の流れ:
1. LinkedIn経由の偽採用勧誘（Operation Dream Job）で標的企業の従業員に接触
2. 侵害済みWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113）経由でマルウェア配布・C2確立
3. CVE-2026-68820（AFD.sys UAF）を悪用しローカル権限昇格でSYSTEM権限を取得
4. FudModule 3.1カーネルモードルートキットでSmart App Controlを改ざん・EDRテレメトリを無効化
5. Troy（17コマンド対応DLLインプラント）・ForestTiger・MISTPENを展開し持続的なアクセスと偵察を確立

【暫定緩和策】（パッチが提供されるまでの間の対処）
・2026年8月Microsoftセキュリティ更新プログラム（AFD.sys修正）を最優先で適用する
・防衛・航空宇宙セクターの企業はLinkedIn経由の未確認の採用勧誘・添付ファイル開封を制限する社内周知を行う
・Check Point公開のIOC（envell[.]xyz / enveil[.]online / uxtramine[.]org 等）を境界機器・プロキシでブロックする

CVSS: 8.6 (High)

【24時間以内の変化】
[Cisco PSIRT 2026-08-11] Remote Access SSL VPNサービスのHTTPリクエスト検証不備（CWE-244）を公表、未認証リモートDoS（デバイス再起動）の実悪用を確認
[CISA KEV 2026-08-11] KEVカタログへ初回追加（dateAdded 2026-08-11）、FCEB期限2026-08-14
[Security NEXT 2026-08-12] 国内向けにCisco ASA/FTDのSSL VPN DoS脆弱性・ゼロデイ攻撃を報道

【概要】
Cisco Secure Firewall ASA / FTDのRemote Access SSL VPNサービスにHTTPリクエスト検証不備（CWE-244）があり、未認証のリモート攻撃者が細工したHTTPリクエストを送信することでデバイスを予期せず再起動させサービス拒否を引き起こすことが可能な脆弱性CVE-2026-20349が判明した。IKEv2リモートアクセスVPN・SSL-VPN・Zero Trust Network Accessの構成が影響を受ける。CISAは2026-08-11付でKEVカタログへ初回追加しFCEB機関に2026-08-14までの対処を義務付けた。Cisco Secure Firewall Management Center（FMC）は本脆弱性の対象外。回避策は無く修正版の適用が必須。

攻撃の流れ:
1. 未認証の攻撃者がRemote Access SSL VPNサービスへ細工したHTTPリクエストを送信
2. HTTPリクエスト検証の不備によりヒープ関連の異常処理が発生
3. デバイスが予期せず再起動しサービス拒否（DoS）状態となる

IoC: 確認されず
