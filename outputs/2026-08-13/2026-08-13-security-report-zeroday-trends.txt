【概要】
北朝鮮系Lazarus Groupが、長期継続中のOperation Dream Jobキャンペーン（LinkedIn経由の偽採用勧誘による標的接近）の一環として、2026年7月上旬からWindows Ancillary Function Driver for WinSock（AFD.sys）のuse-after-free脆弱性CVE-2026-68820をゼロデイとして実悪用し、フランス・ドイツ・ブラジル・インドの防衛・航空宇宙企業（偵察センサー・ドローン・ロボティクス関連技術を保有）を標的に、新型バックドアTroy・ForestTiger・MISTPENダウンローダ・カーネルモードルートキットFudModule 3.1を展開していたことがCheck Point Researchの調査で判明した。侵害済みのWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113悪用）をC2インフラとして利用し、PHP製の未文書化ウェブシェルRelayShellも新たに確認された。フランス国内で少なくとも1組織が侵害を受け、その組織を踏み台にした二次スピアフィッシングへの悪用も確認されている。Microsoftは本CVEを2026年8月Patch Tuesdayで修正し、CISAはKEVカタログへ初回追加、JPCERT/CCも注意喚起を発行した。

攻撃の流れ（判明分）:
1. LinkedIn経由の偽採用勧誘（Operation Dream Job）で防衛・航空宇宙企業の従業員に接触
2. 侵害済みWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113）経由でマルウェア配布・C2確立
3. CVE-2026-68820（AFD.sys UAF）を悪用しローカル権限昇格でSYSTEM権限を取得
4. FudModule 3.1でSmart App Control改ざん・EDRテレメトリ無効化、Troy/ForestTiger/MISTPENを展開し長期潜伏・偵察
5. 侵害済み組織を踏み台としたスピアフィッシングで関連組織への横展開を試行

【概要】
Windows Ancillary Function Driver for WinSock（AFD.sys）のuse-after-free脆弱性CVE-2026-68820を、北朝鮮系Lazarus GroupがOperation Dream Jobキャンペーンの一環として2026年7月上旬から実悪用し、ローカル権限昇格経由でSYSTEM権限を取得しForestTiger（別名ScoringMathTea）・新型バックドアTroy・軽量ダウンローダMISTPEN・カーネルモードルートキットFudModule 3.1を展開していたことがCheck Point Researchの調査で判明した。標的はフランス・ドイツ・ブラジル・インドの防衛・航空宇宙企業で、偵察センサーやドローン等の軍事関連技術を持つ企業が狙われた。攻撃はLinkedIn経由の偽採用勧誘から始まり、侵害済みのWordPress/SharePoint/脆弱なRoundcubeウェブメールサーバ（CVE-2025-49113悪用）をC2インフラとして利用、PHP製ウェブシェルRelayShellも新たに確認された。Microsoftは2026年8月Patch Tuesdayで修正を提供し実悪用を確認、CISAは2026-08-11付でKEVカタログへ初回追加、JPCERT/CCも同CVEを名指しした注意喚起を発行した。

攻撃の流れ:
1. LinkedIn経由の偽採用勧誘（Operation Dream Job）で標的企業の従業員に接触
2. 侵害済みWordPress/SharePoint/脆弱なRoundcubeメールサーバ（CVE-2025-49113）経由でマルウェア配布・C2確立
3. CVE-2026-68820（AFD.sys UAF）を悪用しローカル権限昇格でSYSTEM権限を取得
4. FudModule 3.1カーネルモードルートキットでSmart App Controlを改ざん・EDRテレメトリを無効化
5. Troy（17コマンド対応DLLインプラント）・ForestTiger・MISTPENを展開し持続的なアクセスと偵察を確立
