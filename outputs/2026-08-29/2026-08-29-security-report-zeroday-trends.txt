【概要】
PaperCut NG/MF（印刷管理ソフトウェア）の現在サポートされている全バージョンに影響する2件の脆弱性（Webマネジメントインタフェースの認可不備CVE-2026-81578とデータベース接続ユーティリティの安全でない動的クラスロードCVE-2026-82078）が実環境で悪用されていることを2026-08-27にPaperCut自身が確認し、翌08-28にCVE番号を正式採番のうえ緊急アウトオブサイクルビルドを公開した（既報2026-08-28分レポートではCVE未採番のトラックB「注目CVE」扱いだったが、本日CVE採番・製品特定によりトラックAへ帰属し直した）。2件を連鎖させると未認証の攻撃者が任意コード実行に至る。同社の過去のCVE-2023-27350はClop・LockBitランサムウェアやイラン国家系グループに悪用された前例があり、印刷管理サーバは教育・官公庁・大企業で広く使われるため影響範囲は大きいと考えられる（推定）。本日時点で独立した公開PoCは確認されていない。

攻撃の流れ:
1. インターネットに公開されたPaperCut Application ServerのWebマネジメントインタフェースへ未認証でアクセスし、CVE-2026-81578の認可不備を悪用して設定変更を行う
2. 変更した設定を起点にCVE-2026-82078のデータベース接続ユーティリティにおける安全でない動的クラスロードを悪用し、任意コードを実行する
3. pc-app.exeプロセスからの不審な後続動作・server.logの欠落や切り詰めなどログ隠蔽の痕跡が報告事例で観測されている（侵害後の最終被害は本日時点で未確認）

【暫定緩和策】（パッチが提供されるまでの間の対処）
・インターネットに公開されたPaperCut Application ServerのWebインタフェースへのアクセスをファイアウォールで信頼済みIPアドレスのみに制限する
・緊急アウトオブサイクルビルド（v24/v25/v26、2026-08-28公開）へ直ちにアップグレードする
・pc-app.exeの異常な子プロセス生成やserver.logの欠落・切り詰めを監視する

活動タイプ: new_malware/active_campaign/ttp_update

【24時間以内の変化】
[Recorded Future 2026-08-27] 初報。GRU参謀本部情報総局傘下でAPT28/Fancy Bear/Forest Blizzardと技術重複するBlueDeltaによる新規バックドア「HOOKEDGE」の技術分析を公開。The Hacker News/SecurityAffairs/gbhackers/cyberpress/Cryptika等が追随報道（バースト検出閾値超過・6ソース以上）

【概要】
Recorded Futureが、GRU参謀本部情報総局(GU)傘下でありAPT28（Fancy Bear/Forest Blizzard）と重複するクラスタ「BlueDelta」による新規バックドア「HOOKEDGE」を報告した。2025年9月末から2026年4月にかけルーマニア・スペイン・トルコの防衛製造業・外交機関を標的に初期アクセスキャンペーンを実施し、マクロ有効化Wordドキュメントで軽量なバッチスクリプトバックドアHOOKEDGEを配布した。コマンド取得・データ持出しはヘッドレスまたは隠しウィンドウで起動したMicrosoft Edgeインスタンスからwebhook.site（無料枠）へのHTTPリクエストで行われ、正規ブラウザトラフィックへの偽装とレピュテーションの高い正規サービス悪用によりネットワーク検知を回避する。先行インプラントHEADLACEとのコード・手口の重複が確認されている。

攻撃の流れ（判明分）:
1. マクロ有効化Wordドキュメントによるスピアフィッシングで初期アクセスを獲得
2. 軽量バッチスクリプトバックドアHOOKEDGEを展開
3. ヘッドレス/隠しウィンドウのMicrosoft Edgeインスタンスからwebhook.siteへHTTPリクエストを送信しコマンド取得・データ持出しを実施

【新規TTP】
・[T1566.001] Spearphishing Attachment — マクロ有効化Wordドキュメント
・[T1102.002] Web Service: Bidirectional Communication — webhook.site無料枠へのHTTPリクエストをC2チャネルとして悪用
・[T1059.003] Windows Command Shell — 軽量バッチスクリプトバックドアによるコマンド実行

【IoC】
IoC: 確認されず

【推奨アクション】
