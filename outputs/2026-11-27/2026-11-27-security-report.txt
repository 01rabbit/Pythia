CVE-2026-120705 [9] GeoServer（gs-wfs-core / GeoTools gt-metadata・OGC WFS 実装）
------------------------------------------------------------
対象: GeoServer (OSGeo) / GeoTools / GeoServer 3.0.2 未満・2.28.6 未満・2.27.7 未満（gs-wfs-core）、GeoTools gt-metadata 35.2/34.6/33.7 未満。修正版: GeoServer 3.0.2・2.28.6・2.27.7
評点: CVSS v3 8.6
【概要】
GeoServer（OGC 準拠の地理空間データ配信サーバー）の未認証『任意ファイル読み取り』脆弱性 CVE-2026-120705（CVSS 8.6）。単一の未認証 Web Feature Service（WFS）リクエストで、GeoServer プロセスが読める任意のローカルテキストファイルを読み取り、または攻撃者指定の HTTP/HTTPS URL を取得できる（維持者の勧告では『未認証 WFS GetFeatureById XML インジェクション』と記述）。watchTowr の脅威インテリジェンス主任 Yordan Ganchev は 2026-11-25 早朝、グローバルハニーポット網で本 CVE を悪用する in-the-wild を観測したと公表した。観測された活動は『複数 IP の攻撃者が GeoServer 上にストアドクエリを作成し、作成されたか確認してから即削除する』という脆弱性の検証/探索であり、ペイロード投下や侵害の確認までは報告されていない（＝探索段階）。本 CVE は Eye Security が発見・報告し、維持者が公開した一連の勧告では未認証の多段 RCE チェーン（CVE-2026-129245・CVE-2026-120704・CVE-2026-129242・CVE-2026-129244 等）の起点になり得ると警告されている。パッチ（3.0.2／2.28.6／2.27.7）は 2026-10〜11 初に公開済で勧告は 11-24。発行時点で CISA KEV 未収載。CVSS・バージョンは一次記事（The Hacker News 2026-11-25・SecurityWeek）に基づく。
【一時緩和】
  - GeoServer を修正版（3.0.2／2.28.6／2.27.7）へ即時更新する。WFS エンドポイントのインターネット到達範囲を限定し、GetFeatureById を含む未認証 WFS リクエストの監視・レート制限を行う。ストアドクエリの作成・削除ログを点検する。
【TTP】
  - T1190 (initial-access): watchTowr（Y. Ganchev）: 2026-11-25 早朝、グローバルハニーポットで CVE-2026-120705 を悪用する in-the-wild を観測。未認証の単一 WFS リクエストで任意ファイル読み取りが可能
