CVE-2026-19868 [high] SonicWall SonicOS SSLVPN（SAML 認証強制の不備）
------------------------------------------------------------
CISA は 2026-11-06 に SonicWall SonicOS SSLVPN の CVE-2026-19868 を KEV に追加した（期限 11-20・ランサム利用は不明）。EUVD の説明では、別の認証方式の有効な資格情報を持つ利用者が SAML 認証制御を回避でき、SAML で強制している多要素認証（MFA）も回避され得る。EUVD は 11-06 を悪用確認の開始日として記録している（EUVD 表示 CVSS 7.5・EPSS 0.0）。悪用の主体・手口・規模は固定済みの一次情報では未確認。
  KEV追加: 2026-11-06 期限: 2026-11-20
  暫定対策: ベンダー修正の適用（版の詳細は未取得） / SSLVPN で SAML 以外の認証方式を無効化する / VPN 認証ログで SAML を経由しないログインを確認する
  参照: https://www.cisa.gov/known-exploited-vulnerabilities-catalog (CISA)
  参照: https://euvdservices.enisa.europa.eu/api/enisaid?id=EUVD-2026-118429 (ENISA EUVD)

CVE-2026-123158 [high] OpenSSH 'SSHole'（musl libc かつ PAM 無効環境の認証回避）
------------------------------------------------------------
THN によれば、OpenSSH の CVE-2026-123158（SSHole・CVSS 8.1）は、musl C ライブラリ上で PAM を無効にした Linux で、パスワード未設定のアカウントへのサインインを可能にする。SecurityWeek は、musl かつ PAM なしの環境で 257〜1024 文字の任意のパスワードを受け付けるアカウントがあると説明する。Previdian は公開から数時間以内に悪用の試みを観測し、ハニーポットで root を取得されたと報じた。OpenSSH は緊急パッチを公開した。KEV 収載は固定済み証跡では確認できない。
  KEV追加: None 期限: None
  暫定対策: OpenSSH の修正版へ更新する / musl libc かつ PAM 無効の SSH サーバーを洗い出し、パスワード未設定アカウントを無効化する / SSH を公開しているホストはパスワード認証を無効にし公開鍵認証に限定する
  参照: https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html (The Hacker News)
  参照: https://www.securityweek.com/openssh-rushes-patches-for-sshole-authentication-bypass (SecurityWeek)

CVE-2026-123488 [medium] Craft CMS（要素検索エンドポイントの未認証 SQL インジェクション）
------------------------------------------------------------
NVD（VulnCheck 起点）は、Craft CMS 4.0.0〜4.18.9 未満および 5.0.0〜5.11.2 未満の要素検索エンドポイントに未認証 SQL インジェクションがあると記録した（CVSS 9.8）。attribute パラメーターが無害化されずにクエリへ連結され、PDO の準備文エミュレーションにより複文実行が可能で、DB の読み書き・管理者フラグの設定やパスワードハッシュの上書きによる乗っ取りにつながり得る。窓内に悪用・PoC の報告は確認できていない。
  KEV追加: None 期限: None
  暫定対策: Craft CMS を 4.18.9 または 5.11.2 以降へ更新する
  参照: https://nvd.nist.gov/vuln/detail/CVE-2026-123488 (NVD)
