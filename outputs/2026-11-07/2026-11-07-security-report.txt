CVE-2026-123158 [high] OpenSSH 'SSHole'（musl libc かつ PAM 無効環境の認証回避）
------------------------------------------------------------
THN によれば、OpenSSH の CVE-2026-123158（SSHole・CVSS 8.1）は、musl C ライブラリ上で PAM を無効にした Linux で、パスワード未設定のアカウントへのサインインを可能にする。SecurityWeek は、musl かつ PAM なしの環境で 257〜1024 文字の任意のパスワードを受け付けるアカウントがあると説明する。Previdian は公開から数時間以内に悪用の試みを観測し、ハニーポットで root を取得されたと報じた。OpenSSH は緊急パッチを公開した。KEV 収載は固定済み証跡では確認できない。
  KEV追加: None 期限: None
  暫定対策: OpenSSH の修正版へ更新する / musl libc かつ PAM 無効の SSH サーバーを洗い出し、パスワード未設定アカウントを無効化する / SSH を公開しているホストはパスワード認証を無効にし公開鍵認証に限定する
  参照: https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html (The Hacker News)
  参照: https://www.securityweek.com/openssh-rushes-patches-for-sshole-authentication-bypass (SecurityWeek)
