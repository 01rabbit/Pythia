AI-2026-10-29-001 Dream：AI 支援の疑いがある PHP2Shell＋カーネル権限昇格攻撃が米日台韓のファイアウォール 25 台を root 化（China-nexus の疑い・帰属未確定）（カテゴリ A・X=6 Y=5）
------------------------------------------------------------
【24時間以内の変化】
[The Hacker News（Dream） 2026-10-28] Dream が、攻撃インフラに Claude Code が導入され、AI 攻撃基盤 aiscan（DeepSeek・Kimi 構成）の API キーがあったと報告。観測日 2026-10-25。

【概要】
THN が伝える Dream の報告によれば、China-nexus の疑いがある攻撃者が、PHP2Shell（CVE-2026-109618／109619）と Linux カーネル権限昇格 Fragnesia（CVE-2026-46300）を連鎖させ、ファイアウォールの管理サーバーを root 化した。攻撃インフラには Claude Code が導入され、FOFA と AI 攻撃基盤 aiscan（DeepSeek・Kimi 構成）の API キーが残され、約 40 本のスクリプトのコード構造・コメントが一貫していて AI で開発された形跡があるとされる。エクスプロイトは公開版の流用ではなく独自ビルドと Dream は評価。標的選定（米・日・台・韓）から国家系の可能性があるとするが、Dream の評価で確定した帰属ではない。侵害の全容（資格情報の窃取・バックドアアカウントの有無）は未確定。

【被害規模】
25 台のサーバー（ファイアウォールの管理サーバー）が root 化。うち米政府関連組織の 2〜3 台。FOFA で約 19,000 台を列挙し、約 5,000 台がバージョン照会に応答、240 台を標的とした。記事に件数の不整合（24／25 台）あり。

【監視】
ファイアウォールの Web 管理面を公開しない。PHP とカーネルの修正を適用し、管理サーバーからの外向き SSH を監視する。
