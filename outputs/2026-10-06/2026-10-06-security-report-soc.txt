1. Microsoft Exchange Server の権限昇格 CVE-2026-96940（CVSS 8.8・他ユーザーのメールボックス読取）に対する緊急外部更新
観点: cve  採用契機: η
------------------------------------------------------------
優先度: medium
対象: Microsoft Exchange Server（SE RTM / 2016 CU23 / 2019 CU14-15）

【24時間以内の変化】
[The Hacker News 2026-10-05] Microsoftが CVE-2026-96940 の定例外セキュリティ更新を公開と報道。

【概要】
Exchange Server の弱い認可により、認証済み攻撃者が同一組織内の他ユーザーのメールボックスのメール・添付ファイルを読めるようになる（テナント越えは不可）。Exchange Online はサービス側で修正済み。Microsoftは悪用評価を『Exploitation More Likely』とし、実環境での悪用は確認されていない（報道）。

【推奨アクション】
・オンプレミスの該当 Exchange に定例外更新を適用する
・更新までメールボックスアクセス監査ログの異常な他者メールボックス参照を確認する

【参照】
・The Hacker News: Microsoft Exchange Flaw Lets Authenticated Attackers Read Other Users' Mailboxes https://thehackernews.com/2026/10/microsoft-exchange-flaw-lets.html

2. Dell System Update（DSU）CLI のクリティカルな脆弱性 CVE-2026-86360（パストラバーサル・未認証RCEの可能性）ほか4件を修正
観点: cve  採用契機: η
------------------------------------------------------------
優先度: medium
対象: Dell System Update（DSU）CLI（PowerEdge サーバー向け）

【24時間以内の変化】
[BleepingComputer 2026-10-05] DellがDSUのクリティカル脆弱性を修正し早期更新を要請と報道。

【概要】
CVE-2026-86360 は、未認証のリモート攻撃者がroot権限でコード実行につながり得るパストラバーサル（Dell説明はファイルシステムアクセス）。同時に CVE-2026-63697 / 71168（高・RCE）と CVE-2026-86361 / 86362（高・権限昇格）も修正された。修正版は DSU 2.3.0.0 以降。悪用は報告されていない。

【推奨アクション】
・DSU を 2.3.0.0 以降へ更新する
・DSU CLI をネットワークへ公開している場合は到達性を管理ネットワークに限定する

【参照】
・BleepingComputer: New Dell System Update flaw lets hackers gain root privileges https://www.bleepingcomputer.com/news/security/new-dell-system-update-flaw-lets-hackers-gain-root-privileges

3. cPanel & WHM のクリティカル脆弱性3件（CVE-2026-93698 ほか）修正
観点: cve  採用契機: η
------------------------------------------------------------
優先度: medium
対象: cPanel & WHM（WebPros International）

【24時間以内の変化】
[Security NEXT 2026-10-05] WebPros Internationalが cPanel & WHM の3件のクリティカルな脆弱性の修正を公開と報道（更新公開は2026-09-29）。

【概要】
CVE-2026-93698（CVSS 9.9）は Multilang adminbin の入力検証不備でroot権限の任意OSコマンド実行につながり得る（低権限アカウントが前提）。CVE-2026-93697 / 93029 は保存型XSS（管理者セッションでスクリプト実行）。修正版番号と悪用状況は取得記事に記載がなく未確認。

【推奨アクション】
・cPanel & WHM を WebPros の最新セキュリティ更新へ更新する（修正版は公式アドバイザリで確認）
・共有ホスティング運用では低権限アカウントの棚卸しを行う

【参照】
・Security NEXT: 「cPanel & WHM」に3件の脆弱性 - いずれも「クリティカル」 https://www.security-next.com/191015

1. Google がオープンソース脆弱性報奨金（OSS VRP）の受付を一時停止、AI生成の無効報告の急増が理由
観点: ai_attack  採用契機: η
------------------------------------------------------------
優先度: low
対象: Google OSS VRP

【24時間以内の変化】
[BleepingComputer / SecurityWeek 2026-10-05] AI生成レポートの氾濫によりOSS VRPへの報告受付を一時停止と報道。

GoogleがAI生成の無効な自動レポートの急増を受け、Open Source Software Vulnerability Rewards Program への脆弱性報告の受付を一時停止し対象を絞る。OSS側の脆弱性トリアージ負荷とAI支援による脆弱性発見の増加を示す動向（事実は報道ベース）。

【推奨アクション】

【参照】
・BleepingComputer: Google halts open-source bug bounty program amid AI spam surge https://www.bleepingcomputer.com/news/google/google-halts-open-source-bug-bounty-program-amid-ai-spam-surge
