SOC-2026-11-13-001 [high] ScreenConnect 利用組織：不正クライアントと RMM+ 拡張の点検
------------------------------------------------------------
対象: ConnectWise ScreenConnect

【概要】
ConnectWise が 5 つの拡張を無効化し、約 48 組織で侵入が報告されている。MSP は顧客端末へ波及させる経路になり得る。

【推奨アクション】
1) ScreenConnect サーバーとクライアントを最新へ更新（CVE-2026-84869）。2) RMM+ 拡張の RMMPlus.AccessKey が空でないか確認、不要な拡張は無効化。3) 不審な ScreenConnect Access クライアントの登録と Run Command 履歴、技術者端末のブラウザセッションを点検。4) ns.mo7sen[.]dev への通信を遮断・遡及確認。
【監視】ScreenConnect の管理コマンド履歴、sc.msi・sckit-run.bat・sckit-decoder.ps1 の作成、ns.mo7sen[.]dev への名前解決を確認する。
  参照: https://thehackernews.com/2026/11/sckit-malware-targets-screenconnect.html (The Hacker News)

SOC-2026-11-13-003 [high] GitHub Actions：wfx キャンペーンの指標確認と認証情報のローテーション
------------------------------------------------------------
対象: GitHub Actions / クラウド CI

【概要】
4,837 アカウントの乗っ取りで CI のシークレットが窃取された。クラウドの永続化（IAM キー・信頼ポリシー改変）も報告されている。

【推奨アクション】
1) wfx-docs ブランチ、PR『docs: dependency audit notes』、build-audit-*.yml を検索。2) 該当リポジトリの全シークレットとクラウドロールを失効・再発行。3) CloudTrail の wfx-* セッション、CreateAccessKey、UpdateAssumeRolePolicy、Entra の wfx-ci-* を点検。4) 194.150.166[.]244・18.143.168[.]96・153.75.82[.]159 への通信を遮断。
【監視】ワークフロー実行履歴の欠落、実行番号の無いコミット、外部への HTTP POST と Telegram 接続を確認する。
  参照: https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html (The Hacker News)

SOC-2026-11-13-004 [medium] Apache HTTP Server 2.4.71 への更新（mod_http2 の RCE）
------------------------------------------------------------
対象: Apache HTTP Server

【概要】
HTTP/2 有効の 2.4.55〜2.4.70 が対象。悪用は未確認だが Red Hat は信頼できる悪用の研究があるとする。

【推奨アクション】

【監視】mod_http2 のクラッシュ・再起動の増加と HTTP/2 の異常なストリームを確認する。
  参照: https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html (The Hacker News)
