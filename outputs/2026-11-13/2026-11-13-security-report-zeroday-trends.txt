CVE-2026-125883 [high] N-able N-central（XXE・XML スキーマ汚染。同時開示の OGNL インジェクション・ファイルアップロード経由 RCE 等を含む一連のゼロデイ）
------------------------------------------------------------
対象: N-able / N-central 2026.4.0.31（プレリリース版で確認）。早期版にも影響する可能性があるが未検証（研究者の見解）。修正は 2026.4 HF2
【概要】
The Hacker News によれば、N-able は 11-12（木）、オンプレ N-central 2026.4.1 HF2 に対する追加脆弱性の公開を調査中と発表した。研究者 Sean Bales が公開した 4EverAble2Shell（未認証で root 権限の RCE）と Agent2Shell（管理下 Windows エージェントで NT AUTHORITY\SYSTEM 実行・10 件超のゼロデイ・対象アプライアンス ID が必要）の PoC は、修正済みビルド 2026.4.1.26 にも有効と報じられている。N-able は、サーバー側の問題は Legacy API を有効にして公開した非既定構成に依存し、ホスト型は影響を受けないと説明している。Previdian は PoC 公開から数時間以内に 157.20.241[.]16 から 4EverAble2Shell への標的型の探索を観測し、CVE-2026-90436（Apache Axis・CVSS 9.8）の悪用試行から root 昇格、curl によるシェルスクリプト取得・実行という流れを報告した。成功した悪用は確認されておらず、watchTowr も Legacy API 有効ビルドへの探索を報告している。新規分に CVE は報じられていない。悪用の成功が未確認のため actively_exploited は false とした（探索・試行は観測、成功は未確認）。
【一時緩和】
  - Legacy API を直ちに無効化する（N-able の勧告・既定は無効）
  - HF2（2026.4.1.26）と Apache Axis 修正（CVE-2026-90436）を適用
  - 適用までオンプレ N-central を非公開にする
  参照: https://thehackernews.com/2026/11/new-n-central-exploits-work-against.html (The Hacker News)
  参照: https://www.securityweek.com/hackers-target-n-central-zero-days-as-n-able-rushes-patches (SecurityWeek)
