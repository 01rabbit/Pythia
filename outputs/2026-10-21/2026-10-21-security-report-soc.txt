SOC-2026-10-21-001 SiteGuard Server Edition CVE-2026-106931 が KEV 追加（期限 10-23）— 更新前に診断情報を保全
------------------------------------------------------------
対象: SiteGuard Server Edition（EGセキュアソリューションズ）

【24時間以内の変化】
[CISA KEV 2026-10-20] KEV 追加（期限 2026-10-23）。ベンダーは 10-14 に悪用確認を告知済み。

【概要】
国産 WAF の統計機能（既定で有効）に root／SYSTEM 権限の OS コマンド実行が可能な脆弱性。ベンダーが悪用を確認している。更新で攻撃痕跡が消える可能性があるため、適用前の診断情報の取得が必要。
【推奨アクション】
- Ver8.00 Update5（FreeBSD 版は Ver7.00 Update6）へ更新するか、ベンダー提供パッチを適用する
- 適用前に管理画面の［診断情報］をダウンロードして保全し、侵害調査に備える
- Ver2.20 以降・統計機能有効の環境を棚卸しし、侵害を前提に WAF ホストの不審なプロセス・設定改変を点検する
【監視】
WAF ホストの想定外のプロセス起動・外向き通信、統計処理関連ファイルの改変を監視する。

【参照】
- SiteGuard Server EditionにおけるOSコマンドインジェクションの脆弱性(緊急) (EGセキュアソリューションズ) https://www.eg-secure.co.jp/siteguard/news/alert-202610-1
- JVN#88474777 (JVN) https://jvn.jp/jp/JVN88474777/

SOC-2026-10-21-002 Siemens Software Center CVE-2026-110936（KEV 追加・ClickFix で悪用）— 4.0.9.8 へ更新と IOC 探索
------------------------------------------------------------
対象: Siemens Software Center

【24時間以内の変化】
[CISA KEV / The Hacker News 2026-10-20] KEV 追加（期限 2026-11-03）。Siemens が悪用を確認、Romulus 基盤の ClickFix 活動に関連。

【概要】
署名済み正規アプリを DLL サイドローディングのキャリアとして悪用し、リモートアクセス型トロイの木馬を展開する手口。
【推奨アクション】
- Software Center を 4.0.9.8 以上へ更新し、起動して適用する
- Siemens 共有の IOC（96.62.218[.]59、wizardexpensive[.]com、2.27.248[.]127）を遮断・過去ログ検索する
- msiexec.exe を親に AppData\Local\Programs から起動する SiemensSoftwareCenter.exe を探索する
【監視】
msiexec.exe → AllMyBasic.msi → SiemensSoftwareCenter.exe の連鎖、archive.dll のロードを監視する。

【参照】
- ClickFix Attackers Exploit Siemens Software Center Flaw to Deploy Remote Access Trojan (The Hacker News) https://thehackernews.com/2026/10/clickfix-attackers-exploit-siemens.html

SOC-2026-10-21-004 PAN-OS CVE-2026-0257: ランサムウェア運用者が VPN から vCenter／ESXi／VMDK へピボット — 仮想化基盤の防御確認
------------------------------------------------------------
対象: PAN-OS／Prisma Access（GlobalProtect）、VMware vCenter／ESXi

【24時間以内の変化】
[Unit 42 2026-10-20] Qilin／INC が悪用主体と明記、仮想化層への直接ピボットを報告。

【概要】
パッチ（2026-05）未適用の GlobalProtect が MFA バイパスの足場になり、vCenter 経由で ESXi の execInstalledOnly を無効化、DC の VMDK をオフラインで解析する。ゲスト内 EDR を回避される。
【推奨アクション】
- PAN-OS の修正版適用を確認し、GlobalProtect の成功ログインを遡って確認する
- vCenter／ESXi 管理面を VPN 経由の到達から分離し、execInstalledOnly の設定変更を監視する
- Veeam の既知脆弱性（CVE-2023-27532）の修正を確認する
【監視】
vCenter の新規管理者・ESXi の execInstalledOnly 変更、DC の VMDK への異常な読み取り、RMM ツールの新規導入を監視する。

【参照】
- Threat Brief: Active Exploitation of PAN-OS CVE-2026-0257 (Updated October 20) (Unit 42) https://unit42.paloaltonetworks.com/active-exploitation-of-pan-os-cve-2026-0257/
