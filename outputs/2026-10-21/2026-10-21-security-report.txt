AI-2026-10-21-001 中国語圏の攻撃者がオープンソース AI ツール Cairn の自律エージェントで 1,200 超のサイトを攻撃、100 社超の Web サイトに到達
------------------------------------------------------------
カテゴリ: A/A4

【24時間以内の変化】
[The Hacker News / Dark Reading（Reuters・NorForge 引用） 2026-10-20] NorForge の Snorre Fagerland が 10 月 2 日ごろから露出した Cairn インスタンス約 24 件の悪用を観測し、10-19 に報告。Reuters が攻撃者の記録から被害企業を特定。

【概要】
THN によれば、NorForge の研究者は露出した Cairn（認可済みペネトレーションテスト向けオープンソース AI ツール）の管理画面を走査し、約 24 インスタンスの悪用を確認した。最大クラスタ AIA0001（中国語、14 パネル・1,100 超の攻撃プロジェクト）は米国・日本・オーストラリアのオンラインショップ・決済系への持続的アクセスを狙い、『コード実行手段を探し Web シェルのアップローダーを設置する』という短い指示だけでエージェントが自律的に侵入する。ハードウェア部品ベンダーでは稼働中の Web シェルを確認し、大手米国小売業者の侵害を独立に確認した。侵入経路は被害ごとに異なり、1 件は memcached セッションストアへの不正書込み・PHP オブジェクトの安全でない処理・旧 Zend Framework の弱点を連鎖していた。Cairn の作者は悪用を意図していないと述べている。2026-09-24 計上の自律型 AI エージェント（Strix/Cairn/Hermes）による EC 攻撃の続報。

【攻撃フロー】
1. 攻撃者が Cairn に開始点と目標（コード実行手段の発見・Web シェルアップローダー設置）を与える
2. エージェントが共有ボードに調査結果を投稿しながら自律的に脆弱経路を探索・侵入（人間は途中でヒントを追加）
3. Web シェル設置による持続的アクセスの確保（後に差し替え可能）

【監視】
EC サイトの Web ルート配下への新規アップローダー／Web シェルの出現、セッションストア（memcached 等）への外部からの書込み、短時間の多数の探索リクエストを監視する。

AI-2026-10-21-002 Claude Agent SDK（Python）の resume オプションに引数注入の脆弱性 CVE-2026-96620、修正版を公開
------------------------------------------------------------
カテゴリ: C/C4

【24時間以内の変化】
[Security NEXT 2026-10-20] Claude Agent SDK for Python の引数注入 CVE-2026-96620 と修正版の公開を報道。

【概要】
Security NEXT によれば、Anthropic の Python 向け Claude Agent SDK で、セッション再開の resume オプションの値を検証せず Claude CLI へ渡すため、値が『-』で始まると新たな CLI オプションとして解釈され、MCP サーバー定義の読み込みなどを通じて起動時に任意コマンドが実行され、SDK の権限制御を回避されるおそれがある。アプリケーションが信頼できない入力をセッション ID に使う場合に影響する。修正版が公開済み（版数は本文未取得）。悪用の報告は確認できていない。

【攻撃フロー】
1. 信頼できない入力を resume のセッション ID としてアプリケーションが SDK に渡す
2. 『-』で始まる値が CLI オプションとして解釈され、MCP サーバー定義等を読み込ませる
3. CLI 起動時に任意コマンドが実行され、SDK の権限制御を回避される可能性

【監視】
SDK を組み込んだアプリケーションで、ユーザー入力が resume の値に渡る箇所と、『-』で始まる値の拒否を確認する。

【参照】
- 「Claude Agent SDK」に引数注入の脆弱性 - 修正版を公開 (Security NEXT) https://www.security-next.com/191686

1. CVE-2026-106931 SiteGuard Server Edition（国産 WAF・統計機能の OS コマンドインジェクション CWE-78）（CVSS 8.5）
------------------------------------------------------------
優先度: critical  軸1=11 軸2=6  KEV登録: あり  悪用: 確認  パッチ: あり
影響バージョン: Ver2.20 以降で統計機能が有効（初期値は有効）のもの。Apache／Nginx／IIS 版は Ver8.00 Update5 より前、FreeBSD Apache／Nginx 版は Ver7.00 Update6 より前（IIS 版 Ver3.10〜Ver4.00 Update4 は影響なし）

【24時間以内の変化】
[CISA KEV 2026-10-20] CVE-2026-106931 が CISA KEV に追加（dateAdded 2026-10-20・期限 2026-10-23・ランサムウェア利用は Unknown・forensicTriage: Yes）。10-15 に計上済みの CVE の KEV 登録状態の更新（2026-10-15 の初報では KEV 未収載）。[既報・KEV登録の更新]
[EGセキュアソリューションズ（ベンダー警告） 2026-10-14] 本脆弱性の悪用が確認されていると公表（緊急）。サポート契約のある顧客には 2026-09-29 に個別通知済みと記載。JVN#88474777 を併記。
[NVD 2026-10-14] NVD に公開（CVSS v4.0 8.5／v3.0 7.8・JPCERT/CC 提供）。

【概要】
ベンダーによれば、SiteGuard Server Edition の統計機能に OS コマンドインジェクション（CWE-78）があり、当該製品が動作するサーバー上で root または SYSTEM 権限の任意 OS コマンドが実行される可能性がある。ベンダーは『すでに悪用が確認されている』と明記し、2026-10-14 に緊急告知した。CVSS はローカル攻撃ベクトル（v4.0 AV:L／PR:L）と評価されているが、悪用の具体的な手口・攻撃主体・被害件数はベンダー・CISA とも公表していない。本窓（2026-10-20）で CISA KEV に追加された（期限 2026-10-23）。ベンダーは更新前に『診断情報』を保全するよう警告している（更新で攻撃痕跡が消える可能性）。

【攻撃フロー】
1. 統計機能（既定で有効）の入力に OS コマンドを注入（CWE-78・ベンダー記述。具体的な到達経路は非公表）
2. root／SYSTEM 権限で任意コマンドが実行される（ベンダー記述）

【暫定緩和策】
- 最新版（Ver8.00 Update5／FreeBSD は Ver7.00 Update6）へ更新、更新困難な場合はベンダー提供パッチを適用する
- 更新・パッチ適用の前に管理画面［診断情報］から診断情報をダウンロードして保全する（攻撃痕跡が消える可能性があるとベンダーが警告）
- 統計機能を使用していない場合の無効化可否はベンダー情報を確認する（初期値は有効）

【監視】
WAF 管理サーバーでの想定外のプロセス起動・統計処理ファイルの改変、管理サーバーからの不審な外向き通信を確認する。
（検知メモ: ATT&CK Technique は手口の記述が無いため付与しない（初期アクセス経路が未公表）。）

2. CVE-2026-110936 Siemens Software Center（DLL サイドローディング・信頼できない検索パス CWE-427）（CVSS 8.4）
------------------------------------------------------------
優先度: high  軸1=8 軸2=7  KEV登録: あり  悪用: 確認  パッチ: あり
影響バージョン: Siemens Software Center 4.0.9.8 未満（攻撃で悪用されたのは同梱の署名済み 3.5.8.7 とする記述あり）

【24時間以内の変化】
[CISA KEV 2026-10-20] CVE-2026-110936 が CISA KEV に追加（期限 2026-11-03・ランサムウェア利用は Unknown）。前日（10-20 報告）は EUVD の悪用フラグのみで除外サマリーに記録していた案件。[既報・除外→採用へ更新]
[The Hacker News（Siemens ProductCERT 引用） 2026-10-20] Siemens が ClickFix 攻撃での悪用を確認。署名済みの正規 Software Center の隣に細工 DLL（archive.dll）を置いて実行させる手口。Romulus（ClickFix 配信基盤）に帰属と報じられた。

【概要】
Siemens によれば、Software Center が信頼できない検索パスから DLL を読み込むため、認証済みローカル攻撃者が細工 DLL を置くと、アプリケーションの権限で任意コードを実行できる（CVSS v4 8.4）。Siemens の別警告では、攻撃者が正規・署名済みの Software Center（3.5.8.7）をキャリアとして使い、同じフォルダーに細工 DLL（archive.dll）を置いて悪意あるコードを実行させる悪用を確認した。msiexec.exe が AllMyBasic.msi を起動し SiemensSoftwareCenter.exe を実行する流れ。THN によれば、この活動は ClickFix 配信基盤 Romulus（Forescout が先週詳述）に帰属され、Huntress は悪意ある ChatGPT Custom GPT を経由して偽 URL の ClickFix 誘導に至る事例も確認している。発見者は Huntress の Jose Oregon。

【攻撃フロー】
1. 被害者を偽 URL の ClickFix 誘導に導き、コピーした PowerShell コードを実行させて MSI インストーラーを取得（Huntress の記述）
2. msiexec.exe が AllMyBasic.msi を起動し、署名済み SiemensSoftwareCenter.exe を AppData\Local\Programs 配下から実行（Siemens の記述）
3. 同フォルダーの細工 DLL（archive.dll）がサイドローディングされ、リモートアクセス型トロイの木馬が展開される（THN の記述）

【ATT&CK】
T1574.002 DLL Side-Loading: 署名済みの正規 Software Center と同じフォルダーに細工 DLL（archive.dll）を置いて読み込ませる（Siemens）
T1059.001 PowerShell: ClickFix 誘導でコピーさせた PowerShell コードが MSI インストーラーを取得（Huntress／THN）

【暫定緩和策】
- Software Center を 4.0.9.8 以上へ更新し、起動して更新を適用する（KEV 期限 2026-11-03）
- Siemens 共有の IOC（96.62.218[.]59、wizardexpensive[.]com、2.27.248[.]127）を遮断・検索する
- msiexec.exe を親として AppData\Local\Programs から起動する SiemensSoftwareCenter.exe を探索する

【IOC】
ips: 96.62.218[.]59, 2.27.248[.]127
domains: wizardexpensive[.]com
filenames: archive.dll, AllMyBasic.msi, SiemensSoftwareCenter.exe

【監視】
msiexec.exe → AllMyBasic.msi → SiemensSoftwareCenter.exe の親子関係、AppData 配下の SiemensSoftwareCenter.exe 実行、archive.dll のロードを監視する。

2. CVE-2026-110936 Siemens Software Center（DLL サイドローディング・信頼できない検索パス CWE-427）（CVSS 8.4）
------------------------------------------------------------
優先度: high  軸1=8 軸2=7  KEV登録: あり  悪用: 確認  パッチ: あり
影響バージョン: Siemens Software Center 4.0.9.8 未満（攻撃で悪用されたのは同梱の署名済み 3.5.8.7 とする記述あり）

【24時間以内の変化】
[CISA KEV 2026-10-20] CVE-2026-110936 が CISA KEV に追加（期限 2026-11-03・ランサムウェア利用は Unknown）。前日（10-20 報告）は EUVD の悪用フラグのみで除外サマリーに記録していた案件。[既報・除外→採用へ更新]
[The Hacker News（Siemens ProductCERT 引用） 2026-10-20] Siemens が ClickFix 攻撃での悪用を確認。署名済みの正規 Software Center の隣に細工 DLL（archive.dll）を置いて実行させる手口。Romulus（ClickFix 配信基盤）に帰属と報じられた。

【概要】
Siemens によれば、Software Center が信頼できない検索パスから DLL を読み込むため、認証済みローカル攻撃者が細工 DLL を置くと、アプリケーションの権限で任意コードを実行できる（CVSS v4 8.4）。Siemens の別警告では、攻撃者が正規・署名済みの Software Center（3.5.8.7）をキャリアとして使い、同じフォルダーに細工 DLL（archive.dll）を置いて悪意あるコードを実行させる悪用を確認した。msiexec.exe が AllMyBasic.msi を起動し SiemensSoftwareCenter.exe を実行する流れ。THN によれば、この活動は ClickFix 配信基盤 Romulus（Forescout が先週詳述）に帰属され、Huntress は悪意ある ChatGPT Custom GPT を経由して偽 URL の ClickFix 誘導に至る事例も確認している。発見者は Huntress の Jose Oregon。

【攻撃フロー】
1. 被害者を偽 URL の ClickFix 誘導に導き、コピーした PowerShell コードを実行させて MSI インストーラーを取得（Huntress の記述）
2. msiexec.exe が AllMyBasic.msi を起動し、署名済み SiemensSoftwareCenter.exe を AppData\Local\Programs 配下から実行（Siemens の記述）
3. 同フォルダーの細工 DLL（archive.dll）がサイドローディングされ、リモートアクセス型トロイの木馬が展開される（THN の記述）

【ATT&CK】
T1574.002 DLL Side-Loading: 署名済みの正規 Software Center と同じフォルダーに細工 DLL（archive.dll）を置いて読み込ませる（Siemens）
T1059.001 PowerShell: ClickFix 誘導でコピーさせた PowerShell コードが MSI インストーラーを取得（Huntress／THN）

【暫定緩和策】
- Software Center を 4.0.9.8 以上へ更新し、起動して更新を適用する（KEV 期限 2026-11-03）
- Siemens 共有の IOC（96.62.218[.]59、wizardexpensive[.]com、2.27.248[.]127）を遮断・検索する
- msiexec.exe を親として AppData\Local\Programs から起動する SiemensSoftwareCenter.exe を探索する

【IOC】
ips: 96.62.218[.]59, 2.27.248[.]127
domains: wizardexpensive[.]com
filenames: archive.dll, AllMyBasic.msi, SiemensSoftwareCenter.exe

【監視】
msiexec.exe → AllMyBasic.msi → SiemensSoftwareCenter.exe の親子関係、AppData 配下の SiemensSoftwareCenter.exe 実行、archive.dll のロードを監視する。
