1. CVE-2026-76519 Cisco Secure Email Gateway（AMP ファイルレピュテーション経由の未認証ファイル書込み→root コマンド実行）（CVSS 9.8）
------------------------------------------------------------
優先度: critical  軸1=15 軸2=4  KEV登録: あり（追加 2026-10-14・期限 2026-10-17）  悪用: 確認  パッチ: あり
影響バージョン: File Reputation（AMP）が有効でメールポリシーに割り当て済み、かつ Content Scanner Tools が 25.3.0.5525 より前の物理/仮想 SEG。Secure Email and Web Manager / Secure Web Appliance は影響なし（THN）

【24時間以内の変化】
[CISA KEV Catalog 2026-10-14] CISA が CVE-2026-76519 を KEV へ追加（期限 2026-10-17・ランサムウェア利用: Unknown）。
[BleepingComputer / The Hacker News / Cisco 2026-10-14] Cisco が SEG の実悪用ゼロデイを公表し修正版を公開。被害台数・攻撃者・root 取得の有無は未公表。

【概要】
Cisco は Secure Email Gateway（SEG）の AMP ファイルレピュテーション機能で、細工した添付ファイルを含むメールにより未認証のリモート攻撃者が基盤 OS に任意のファイルを書き込める脆弱性 CVE-2026-76519（CVSS 9.8）が実環境で悪用されていると公表した（THN）。書込みに成功すると root 権限でコマンドを実行され得る。悪用された台数・攻撃者・root 取得の有無・IOC・マルウェア名は未公表。同製品では 2026-09-14 公表の SQL インジェクション CVE-2026-76461（未認証 root コマンド実行・KEV 収載）に続く実悪用であり、Cisco は同時期のハードニングリリースの CVE のうち2件が悪用されていると述べている。回避策はなく、修正版または Content Scanner Tools の更新が必要。

【攻撃フロー】
1. 細工した添付ファイル付きメールを SEG 経由で送付（未認証）
2. AMP ファイルレピュテーションの不備で OS 上に任意ファイルを書込み
3. 書込みファイルを足掛かりに root 権限でコマンド実行（Cisco の記述）

【ATT&CK】
・T1190 Exploit Public-Facing Application: インターネット側から到達するメールゲートウェイの脆弱性を未認証で悪用（Cisco）

【暫定緩和策】
・Content Scanner Tools を 25.3.0.5525 以降へ更新し contentscannerstatus で確認する
・AsyncOS を 15.5.5-014 / 16.5.0-780 へ更新する（16.0 は修正版へ移行）
・侵害確認は system_logs の grep "System Security" 結果（Suspected compromise indicator）と、外部 IP への不審なアップロード/ダウンロードの FW ログ点検を併用する
・侵害時は仮想アプライアンスの法的証拠を保全してから修正版に再構築し、旧構成をインポートせず資格情報と鍵を更新する

【監視】
SEG の system_logs で 'System Security' の判定結果を確認する。SEG から外部 IP への想定外のアップロード・外部からのダウンロードを FW/プロキシログで確認する。
Cisco は IOC・攻撃者インフラを公表していない。root 取得後は痕跡が隠される可能性があるためネットワーク側ログでの確認も併用する。

【参照】
・The Hacker News: Cisco Warns of Active Attacks Exploiting New Critical Secure Email Gateway Vulnerability https://thehackernews.com/2026/10/cisco-warns-of-active-attacks.html
・BleepingComputer: Cisco patches new Secure Email Gateway zero-day exploited in attacks https://www.bleepingcomputer.com/news/security/cisco-patches-actively-exploited-secure-email-gateway-zero-day

2. CVE-2026-0322 Palo Alto Networks PAN-OS（管理インタフェースの認証済み RCE・root 権限）（CVSS 8.6）
------------------------------------------------------------
優先度: high  軸1=9 軸2=3  KEV登録: あり（追加 2026-10-14・期限 2026-10-17）  悪用: 確認  パッチ: あり
影響バージョン: PAN-OS の管理インタフェース（具体的な影響バージョンは本日取得した情報源で未確認。EUVD 記載は『認証済みでネットワーク到達可能な攻撃者が root で任意コード実行』）

【24時間以内の変化】
[CISA KEV Catalog / EUVD 2026-10-14] CISA が CVE-2026-0322 を KEV へ追加（期限 2026-10-17）。EUVD はベンダー（palo_alto）の記述と CVSS v4.0 8.6 を収録。

【概要】
Palo Alto Networks の PAN-OS 管理インタフェースに、認証済みでネットワーク到達可能な攻撃者がファイアウォール上で root 権限の任意コードを実行できる脆弱性 CVE-2026-0322（CVSS v4.0 8.6・PR:H）があり、CISA が 2026-10-14 に KEV へ追加した（期限 10-17）。ベンダーは管理インタフェースを信頼できる内部 IP に限定する推奨構成でリスクが軽減されると述べている（EUVD 収録の記述）。本窓では報道記事（二次情報）による悪用の詳細・攻撃者・被害規模は確認できていない。KEV 追加が悪用の根拠であり、悪用手口の詳細は不明。

【攻撃フロー】
1. 管理インタフェースへ到達できる認証済みアカウントで接続（前提: 管理面の露出または資格情報の入手）
2. RCE により root 権限で任意コードを実行

【暫定緩和策】
・PAN-OS の管理インタフェースをインターネットに公開せず、信頼できる内部 IP のみに限定する
・ベンダーアドバイザリで修正版を確認して適用する（KEV 期限 2026-10-17）

【監視】
PAN-OS 管理インタフェースへの接続元 IP と管理者アカウントの不審なログインを確認する。
悪用の詳細・IOC は本窓で未確認。

・CISA: CISA Known Exploited Vulnerabilities Catalog（2026-10-14 追加分） https://www.cisa.gov/known-exploited-vulnerabilities-catalog

3. CVE-2026-105134 Ahsay AhsayCBS（認証回避 CVE-2026-105133 と Replication Receiver の OS コマンドインジェクション CVE-2026-105134 の連鎖）（CVSS 10.0）
------------------------------------------------------------
優先度: critical  軸1=15 軸2=4  KEV登録: あり（追加 2026-10-14・期限 2026-10-17）  悪用: 確認  パッチ: あり
影響バージョン: AhsayCBS 10.3.2 以前（VulDB 記載）。Huntress は 10.3.4.0 でも修正が不完全で影響を受けると報告

【24時間以内の変化】
[CISA KEV Catalog 2026-10-14] CISA が CVE-2026-105133・CVE-2026-105134 を KEV へ追加（期限 2026-10-17）。
[Huntress / SecurityWeek / BleepingComputer / The Hacker News（検索結果の要約） 2026-10-08] Huntress が 2026-10-07 23:20 UTC に初回悪用を観測、10-08 時点で5組織を確認。JSP Web シェルと XMRig マイナーが投下された。

【概要】
AhsayCBS（バックアップ管理サーバ）の認証回避 CVE-2026-105133（checkSysPwd・VulDB v4.0 6.9）と Replication Receiver の OS コマンドインジェクション CVE-2026-105134（v4.0 10.0）が連鎖して未認証 RCE（SYSTEM 権限と報じられる）に至り、実環境で悪用されている。CISA が 2026-10-14 に両 CVE を KEV へ追加した（期限 10-17）。Huntress は 2026-10-07 に初回悪用を観測し、JSP Web シェルと Microsoft Edge を装った XMRig の投下を報告した。Ahsay は 2026-10-10 に 10.3.4.0 では両 CVE が完全には修正されていないと説明しホットフィックス 10.3.4.45 を案内した。EUVD は PoC 公開済みとして収録している。以上は検索結果の要約に基づく二次情報で、一次レポートの全文は本日未確認。

【攻撃フロー】
1. CVE-2026-105133 の認証回避で AhsayCBS の API へ未認証アクセス
2. CVE-2026-105134（UpdateReceivers.do の引数 random）で OS コマンドを実行
3. JSP Web シェルと XMRig マイナーを設置（Huntress）

【ATT&CK】
・T1190 Exploit Public-Facing Application: AhsayCBS の認証回避と OS コマンドインジェクションを連鎖（Huntress ほか報道）
・T1505.003 Web Shell: JSP Web シェルの設置（Huntress）
・T1496 Resource Hijacking: XMRig マイナーの投下（Huntress）

【暫定緩和策】
・ホットフィックス 10.3.4.45 を適用し再起動する（10.3.4.0 では不十分）
・AhsayCBS の管理面・Replication Receiver をインターネットから到達不能にする
・適用前に JSP Web シェル、Edge を装う実行ファイル、不審な常駐プロセスを点検する

【監視】
AhsayCBS の Web ディレクトリ内の新規 JSP ファイルと /rps/api/json/UpdateReceivers.do への外部リクエストを確認する。
具体的な IOC 値は本日未取得。
