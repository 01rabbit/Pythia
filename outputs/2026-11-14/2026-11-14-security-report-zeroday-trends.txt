CVE-2026-123039 [high] Check Point Security Gateway（Gaia OS の DynamicCLI デーモンの権限昇格・root）。PHP2Shell（CVE-2026-109618・CVE-2026-109619）で侵入後に連鎖して悪用
------------------------------------------------------------
対象: Check Point / R82.20・R82.10・R82・R81.20・R81.10・R81（The Hacker News 経由の Check Point の記述）。修正は緊急ホットフィックス
【概要】
The Hacker News（Check Point の発表を引用）によれば、未特定の攻撃者が未修正の Check Point Security Gateway へ PHP2Shell で侵入し、Gaia OS の DynamicCLI の権限昇格（CVE-2026-123039・CVSS 7.8）で root を得て TSGA バックドアと TSProxy を設置した。10-30 にイスラエルの組織が狙われ、11-02 から複数国・業種へ拡大した。一部の組織では ESXi ホストへ SSH で横展開してワイパー destroy_v6 が展開された。Check Point は『数十の顧客に対する悪用を観測』と述べた。攻撃者の帰属は情報源に記載が無い。
【一時緩和】
  - Check Point の緊急ホットフィックスを適用する（CVE-2026-123039）
  - PHP2Shell（CVE-2026-109618・CVE-2026-109619）の修正版 PHP／Check Point 側の修正が未適用のゲートウェイを優先して更新する
  - ゲートウェイから ESXi への SSH 接続と /tmp の DynamicCLI ソケット周辺の不審な書き込みを確認する
【IOC】IP: 130.94.19[.]204 / ファイル: TSGA, TSProxy, destroy_v6, DREAM_ANNEXATION.txt
