SOC-2026-11-14-001 [high] Check Point ゲートウェイ利用組織：Gaia の緊急ホットフィックス適用と侵害確認（KEV・期限 11-16）
------------------------------------------------------------
対象: Check Point Security Gateway（Gaia OS）

【概要】
CVE-2026-123039 は KEV に追加され（FCEB 期限 11-16）、PHP2Shell との連鎖で root 化・バックドア設置・ESXi ワイパー展開が報告された。ゲートウェイは境界機器で、侵害されると背後の仮想基盤へ波及する。

【推奨アクション】
1) Gaia のホットフィックスと PHP2Shell 関連の修正を適用する。2) Mobile Access ポータルを持つゲートウェイで PHP Web シェル・TSGA・TSProxy・130.94.19[.]204 発の通信を探索する。3) ゲートウェイから ESXi への SSH と DREAM_ANNEXATION.txt の有無を確認し、ESXi のバックアップを隔離保管する。
【監視】ゲートウェイ上の不審なプロセス・Web シェル、ゲートウェイ発の ESXi への SSH ログイン、/tmp 配下の DynamicCLI ソケットへの書き込みを監視する。
  参照: https://thehackernews.com/2026/11/hackers-exploit-php2shell-flaws-in.html (The Hacker News)
  参照: https://www.bleepingcomputer.com/news/security/check-point-patches-zero-day-that-lets-hackers-get-root-access (BleepingComputer)

SOC-2026-11-14-002 [high] N-able N-central（オンプレ）管理者：実悪用（21 台感染）を前提にした点検と Legacy API 無効化
------------------------------------------------------------
対象: N-able N-central

【概要】
4EverAble2Shell・Agent2Shell が HF2 適用済みの環境でも悪用され、暗号資産マイナーが展開された。N-central は多数の顧客端末を管理するため、侵害は顧客へ波及する（MSP の場合）。

【推奨アクション】
1) Legacy API を無効化し、Agent・Probe を更新する。2) サーバー上の不審なプロセス・マイナー・新規管理者を確認する。3) N-able の追加ガイダンスに従い、制限された機能・連携を再有効化しない。
【監視】N-central サーバーからの外向き通信、匿名エージェントセッション、root で動く未知のプロセスを監視する。
  参照: https://thehackernews.com/2026/11/hackers-exploit-n-central-flaws-to.html (The Hacker News)

SOC-2026-11-14-003 [high] UnrealIRCd を運用する組織：6.2.7.1 以降へ更新（KEV・期限 11-16）
------------------------------------------------------------
対象: UnrealIRCd

【概要】
CVE-2026-114713 が KEV に追加された。IRC サーバーは社内チャットや旧来の運用基盤で見落とされやすい。

【推奨アクション】

【監視】UnrealIRCd プロセスからの想定外の子プロセスと外向き通信を監視する。
  参照: https://www.cisa.gov/news-events/alerts/2026/11/13/cisa-adds-two-known-exploited-vulnerabilities-catalog (CISA)

SOC-2026-11-14-004 [medium] Citrix NetScaler 管理者：10 件の重大な脆弱性の修正版適用（悪用の報告なし）
------------------------------------------------------------
対象: Citrix NetScaler ADC / Gateway / Console

【概要】
NetScaler は過去に繰り返し悪用された（本リポジトリの既報に多数）。今回の 10 件はメモリ破損・DoS が中心で悪用の報告は無いが、修正版の公開後に差分解析が進む（推測）。

【推奨アクション】
1) 該当ビルドを確認し、修正版へ更新する。2) 管理インターフェースを非公開にする。3) NetScaler Console の既報の認証バイパス（CVE-2026-120869）も併せて適用する。
【監視】NetScaler の異常再起動・クラッシュ、DNS/DoH・SMPP・EPA 等の機能への不審なリクエストを監視する。
  参照: https://www.security-next.com/192789 (Security NEXT)
  参照: https://www.securityweek.com/citrix-patches-10-critical-netscaler-vulnerabilities/ (SecurityWeek)

SOC-2026-11-14-005 [medium] 暗号資産・Web3 関係者：既知の相手を装うビデオ会議（FaceStealer）への警戒
------------------------------------------------------------
対象: ビデオ会議・暗号資産取引

【概要】
FBI は北朝鮮に結び付くアクターが 18 か月で 4 億ドル超を窃取したと確認した。盗まれたアカウントからの招待とディープフェイクで信頼させる手口は、金融以外の組織にも転用され得る（推測）。

【推奨アクション】
1) 予定外のビデオ会議の招待は別経路（電話・既知のチャット）で確認する。2) 会議中の『ソフトの更新』『画面共有』の要求を拒否する。3) 重要な送金は複数人承認とコールバック確認を必須にする。
【監視】会議アプリからの不審なインストーラー実行、ブラウザ・ウォレット拡張の改変、通常外の出金承認を監視する。
  参照: https://thehackernews.com/2026/11/fbi-says-north-korean-hackers-stole.html (The Hacker News)
  参照: https://www.securityweek.com/fbi-says-us-seized-1-2-billion-worth-of-cryptocurrency-stolen-from-binance/ (SecurityWeek)

------------------------------------------------------------
対象: PostgreSQL

【概要】
オブジェクトを作成できる DB ユーザーがサーバー上でコードを実行できる型混同（CVSS 8.8）。完全な防御には C 言語拡張の再ビルドも要る。

【監視】DB ユーザーによる拡張・関数の作成、サーバープロセスからの想定外の子プロセスを監視する。
  参照: https://thehackernews.com/2026/11/postgresql-patches-52-flaws-including.html (The Hacker News)

SOC-2026-11-14-007 [medium] AI ペネトレーション基盤（ARTEX 等）の検知：2〜25 秒のバースト動作と短時間の特権取得への備え
------------------------------------------------------------
対象: AWS CloudTrail／ID 基盤／EDR

【概要】
FBI は ARTEX で初期標的選定から特権取得まで 3 時間未満の侵入があったと述べ、Elastic は 5 フレームワークが短い間隔のバーストで動くと分析した。

【推奨アクション】
1) 短時間に集中する API 呼び出し・列挙の検知ルールを、複数ルールを相関させる形で見直す。2) 認証の弱い公開 API・パスワードスプレー対策を点検する。3) 特権取得までの検知・封じ込めの目標時間を 3 時間未満に置く。
【監視】CloudTrail の 1 秒未満・複数 ID の連続呼び出し、新規管理者の作成、公開ストレージへの無認証書き込みを監視する。
  参照: https://blog.talosintelligence.com/artex-and-beyond (Cisco Talos)
  参照: https://www.elastic.co/security-labs/threat-command/agentic-offensive-frameworks-detection-artex (Elastic Security Labs)
  参照: https://www.elastic.co/security-labs/threat-command/cyberstrikeai-aws-cloudtrail-intrusion (Elastic Security Labs)

SOC-2026-11-14-008 [low] 国内の大規模漏えい（ブックオフ子会社・ノジマ・ネットマイル・大阪市ほか）：委託先・外部サービス経由の点検
------------------------------------------------------------
対象: 会員管理・ポイント・委託先システム

【概要】
委託先や外部プラットフォーム経由の侵害が複数報じられた。手口・攻撃者は未確認で、一般的な委託先管理の点検が要る。

【推奨アクション】

【監視】委託先からの大量エクスポート、利用終了アカウントのログインを監視する。
  参照: https://therecord.media/city-of-osaka-japan-email-data-breach (The Record (Recorded Future))
