SOC-2026-10-27-001 Brotli（CVE-2026-111497）の修正が各製品で出そろいつつある — 同梱コピーを含めて更新と再起動
------------------------------------------------------------
対象: Node.js・Python（Brotli／brotlicffi）・.NET・PowerShell・PHP（Windows）

【24時間以内の変化】
[BleepingComputer／JPCERT/CC 2026-10-26] Microsoft が .NET の定例外更新を公開、JPCERT/CC が注意喚起 AT-2026-0034 を発行、PHP が Windows パッケージを再ビルド。

【概要】
公開 PoC があり、悪意ある悪用の確認報告は現時点でない。システムの Brotli だけでなく Node.js やアプリ同梱のコピーも対象になる。

【推奨アクション】
- 各製品の修正版へ更新し、プロセス再起動とコンテナイメージの再ビルド・再配備を行う。更新できない場合は Python アプリの Brotli 対応を外し、Brotli 圧縮要求を遮断する。

【監視】
Brotli を扱う Node.js・Python・.NET プロセスの異常終了と、Content-Encoding: br の外部通信を確認する。

【参照】
- Critical 'HTTP2Shell' Brotli vulnerability triggers emergency patches (BleepingComputer) https://www.bleepingcomputer.com/news/security/critical-http2shell-brotli-vulnerability-triggers-emergency-patches
- 注意喚起: Brotli … （CVE-2026-111497） (JPCERT/CC) https://www.jpcert.or.jp/at/2026/at260034.html

SOC-2026-10-27-003 GitHub トークン窃取キャンペーン Gheist — ci-sync ブランチの確認とシークレットのローテーション
------------------------------------------------------------
対象: GitHub Actions を使うリポジトリ（private／Enterprise 含む）・セルフホストランナー

【24時間以内の変化】
[The Hacker News（Wiz） 2026-10-26] Wiz が Gheist の手口と検知項目を公表。10-24 時点で継続中。

【概要】
盗まれたトークンで sync-check.yml を持つ ci-sync-xxxxxx ブランチが作られ、全シークレットがログに出力される。

【推奨アクション】

【監視】
GitHub 監査ログで gheist ユーザーエージェント、1 分以内に削除された ci-sync-* の実行を確認する。クラウド監査ログで OIDC の subject に ci-sync- を含む役割引受を確認する。

SOC-2026-10-27-004 Microsoft 365 トークン再利用による侵害 — 不正デバイス・MFA 登録・受信ルールの点検
------------------------------------------------------------
対象: Microsoft 365／Entra ID

【24時間以内の変化】
[The Hacker News（Huntress） 2026-10-26] Huntress が AitM によるトークン再利用で 79 組織・97 アカウントが侵害されたと報告。

【概要】
MFA を通過した後のセッショントークンが奪われるため、パスワード変更だけでは不十分。

【推奨アクション】
- セッションの失効とパスワードリセットを行い、Entra の不正デバイス登録と新規 MFA 方式、不審な受信ボックスルール（短い記号名・給与／入金のメールを隠す）を点検する。条件付きアクセスでデバイスコードフローを制限する。

【監視】
193.26.115[.]0/24 からのサインイン、Entra デバイスの新規登録、MFA 方式の削除と追加の連続を確認する。

【参照】
- Microsoft 365 Token-Replay Attacks Compromise 97 Accounts at 79 Organizations (The Hacker News) https://thehackernews.com/2026/10/microsoft-365-token-replay-attacks.html
