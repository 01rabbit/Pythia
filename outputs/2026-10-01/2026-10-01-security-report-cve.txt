1. CVE-2026-76504 Cisco Catalyst SD-WAN Manager（APIログインセッション認証管理）（Cisco）
------------------------------------------------------------
優先度: high
CVSS v3: 9.8  KEV: 登録済み 2026-09-30  悪用: 確認  FCEB期限: 2026-10-03
影響バージョン: 全構成（20.9未満は修正版へ移行要。修正版: 20.9.10.1 / 20.12.8.2 / 20.15.6.1 / 20.18.4.1 / 26.1.2.1 / 26.2.1。Cloud Hosted は対策済み）

【24時間以内の変化】
[Cisco PSIRT 2026-09-30] CVE-2026-76504（SD-WAN Manager APIログインセッション認証管理の認証回避・CVSS 9.8）のアドバイザリを公開。2026年9月にTAC対応中に実悪用を把握したと説明。回避策なし・修正版あり。
[CISA KEV Catalog 2026-09-30] CISAがCVE-2026-76504をKEVカタログへ追加（FCEB期限2026-10-03・ランサムウェア利用: Unknown）。
[BleepingComputer / The Hacker News 2026-09-30] Catalyst SD-WAN Managerのゼロデイが管理者権限への昇格に悪用されていると報道。

【概要】
Cisco Catalyst SD-WAN Managerは、APIログインセッションの認証管理におけるURIエンコードの処理不備（j_security_checkのログインパスで「%6a」等のエンコードを用いる）により、ネットワーク到達性のみで未認証の攻撃者が管理者としてAPIを利用できる脆弱性CVE-2026-76504（CVSS 9.8）を修正した。CiscoはTAC対応中に2026年9月の実悪用を把握したと説明し、CISAが2026-09-30にKEVへ追加した（FCEB期限2026-10-03）。回避策はなく、インターネットに公開されたManagerが最もリスクが高いとされる。攻撃者の帰属・IOC・被害件数は公表されていない（未確認）。

【攻撃の流れ】
1. SD-WAN ManagerのAPIログインパス（j_security_check）へURIエンコードした細工リクエストを送信し認証規則を回避
2. 認証なしで管理者としてManager APIを利用（以降の具体的な連鎖は非公開）

【ATT&CK】
・T1190 Exploit Public-Facing Application: Manager APIログインセッションの認証回避脆弱性の悪用（Ciscoが実悪用を確認）

【暫定対策】
・修正版（20.9.10.1 / 20.12.8.2 / 20.15.6.1 / 20.18.4.1 / 26.1.2.1 / 26.2.1）へ更新（FCEB期限2026-10-03）
・Manager APIへのアクセスを信頼できるホストに限定し、インターネットから到達可能な状態を解消する
・制御コンポーネントをファイアウォール配下に置く

【監視】
SD-WAN ManagerのWeb/APIアクセスログで、j_security_checkへのURIエンコード（%6a等）を含むリクエストと、その直後の管理者APIの利用を確認する。予期しない管理者アカウント・設定変更の有無を点検する。

・The Hacker News: Cisco Warns of Attackers Exploiting Critical Authentication Bypass in SD-WAN Manager https://thehackernews.com/2026/09/cisco-warns-of-attackers-exploiting.html

1. CVE-2026-84411 MikroTik RouterOS（ウェブ管理のHTTPリクエスト処理）（MikroTik）
------------------------------------------------------------
優先度: medium
CVSS v3: None  KEV: 未登録  悪用: 未確認
影響バージョン: RouterOS 7.24未満（7.23以降へ更新。最新stable 7.24.4・long-term 7.23.7が2026-09-16から提供）

【24時間以内の変化】
[BleepingComputer 2026-09-30] CISAがMikroTik RouterOSの認証前RCE/DoSの重大な脆弱性CVE-2026-84411について注意喚起。実悪用は公表されていないと報道。

【概要】
CISAは、MikroTik RouterOSのウェブ管理のHTTPリクエスト処理における認証前の整数アンダーフローCVE-2026-84411について注意喚起した。単一の細工リクエストでroot権限のコード実行またはDoSが可能とされる。実悪用・PoCは報道範囲では公表されておらず、CVSS値は記事に記載がない。修正版は2026-09-16から提供されている。MikroTikは過去にも別CVEで悪用された経緯がある（報道の言及）。

【攻撃の流れ】
1. ウェブ管理インターフェースへ細工した単一HTTPリクエストを送信し整数アンダーフローを誘発（認証不要）
2. root権限のコード実行またはDoS（実悪用は未確認）

【暫定対策】
・RouterOS 7.23以降へ更新する
・ウェブ管理（HTTP/HTTPS）をインターネットへ公開せず、ファイアウォール・VPNで接続元を制限する

【監視】
RouterOSのバージョン棚卸しと、ウェブ管理ポートが外部から到達可能な機器の洗い出し。

【参照】
・BleepingComputer: CISA warns of critical pre-auth RCE flaw in MikroTik RouterOS https://www.bleepingcomputer.com/news/security/cisa-warns-of-critical-pre-auth-rce-flaw-in-mikrotik-routeros

2. CVE-2026-73570 Zimbra Collaboration Suite（zimbra-snmp・SNMP通知経由の未認証OSコマンドインジェクション）（Synacor / Zimbra）
------------------------------------------------------------
優先度: medium
CVSS v3: 8.9  KEV: 登録済み 2026-08-21  悪用: 確認  FCEB期限: 2026-08-24
影響バージョン: 10.1.20未満（2026-07-20に修正版提供）

【24時間以内の変化】
[The Hacker News（Microsoft Security Research引用） 2026-09-30] MicrosoftがCVE-2026-73570の実悪用後の挙動（JSPウェブシェル・リバースシェル・sudo(pam.d)改変による権限昇格・systemd/cron永続化・SSH経由の横展開・localconfig.xmlからの認証情報窃取・AzCopyでの持ち出し試行）を公開。攻撃者の帰属は示されていない。

【概要】
CVE-2026-73570はKEV登録・実悪用確認済みの既報事案。本窓でMicrosoft Security Researchが侵害後の挙動を公開した。SMTP経由の細工リクエストでOSコマンドを実行し、JSPウェブシェル、リバースシェル、/etc/pam.d/sudoの改変による権限昇格、systemdサービス（zimlog.service）とcronによる永続化、SSH鍵を使った横展開、/opt/zimbra/conf/localconfig.xmlからの認証情報窃取、メールボックスDBへのアクセスとAzCopyによる持ち出し試行を確認した。スキャンは2026-07-28〜08-07に観測されている。帰属は示されていない（未確認）。

【攻撃の流れ】
1. 細工したSMTP要求でzimbra-snmpのSNMP通知処理を経由しOSコマンドを実行（未認証）
2. JSPウェブシェル設置・リバースシェル・pam.d/sudo改変で権限昇格、systemd/cronで永続化
3. localconfig.xmlの認証情報窃取、SSH鍵での横展開、メールボックスDBの収集とAzCopyによる持ち出し試行

【ATT&CK】
・T1190 Exploit Public-Facing Application: SNMP通知処理経由の未認証OSコマンドインジェクションの悪用
・T1505.003 Web Shell: JSPウェブシェルの設置
・T1543.002 Systemd Service: systemdサービス（zimlog.service）による永続化

【暫定対策】
・10.1.20以降へ更新する
・更新できない場合はzimbra-snmpをアンインストールしSNMP通知を無効化、SNMP/SMTPへのアクセスを制限する
・永続的なウェブシェルの走査と、Zimbraに保存された認証情報・シークレットのローテーション

【IOC】
ファイル/マルウェア名: Zimdown2（Go製ダウンローダ）, Zimclient2（遠隔操作エージェント）, zimlog.service

【監視】
mailboxd/Jetty配下の不審なJSPファイル、/etc/pam.d/sudoの改変、zimlog.service等の不審なsystemdユニット、AzCopyの外部ストレージ宛通信を確認する。

【参照】
・The Hacker News: Attackers Exploit Zimbra Flaw to Deploy Web Shells and Harvest Authentication Secrets https://thehackernews.com/2026/09/attackers-exploit-zimbra-flaw-to-deploy.html
