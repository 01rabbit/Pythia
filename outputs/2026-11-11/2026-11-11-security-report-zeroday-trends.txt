Turla（別名 Snake・ESET 追跡） / Turla-2026-CerealExchange （P=7 Q=5・帰属確度: high）
------------------------------------------------------------
THN によれば、ESET は Turla（ロシア寄りの国家支援アクター）が未公開の .NET 製モジュール型ツール群 Cereal を使い、政府機関の Microsoft Exchange サーバーからメールを収集していると報告した。Cereal は 8 コンポーネントから成り、CerealNeuron は通常の Exchange 通信に見える Web 要求を待ち受けるパッシブ型バックドアで外部 C2 を持たず、侵害した Exchange サーバー自体を指令経路とする。CerealBox は EdgeTransport.exe に注入され、送信者・宛先・件名・添付名の固定リストに合致する DOC/DOCX/PDF 添付メールを圧縮・暗号化・一時保存して外部へ送り出す。観測された標的は 2025 年後半のカザフスタンとルーマニアの政府機関各 1 で、ルーマニアでは NATO・EU 機関のアドレスとのメールを収集する設定だった（THN。The Record も同内容を報道）。初期侵入の手口は ESET の記述の範囲で不明で、CVE の言及はない。帰属は ESET の明示による。
  推奨: Exchange サーバーの EdgeTransport.exe への不審なモジュール注入、Exchange 通常通信に紛れた Web 要求への応答、ディスク上の暗号化ステージングファイルを点検する。ESET の原典 IOC を取得して照合する。
