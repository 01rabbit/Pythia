【高優先度】
------------------------------------------------------------
SOC-2026-11-11-001 [high] CISA KEV 追加 6 件（Barracuda ESG×2・Outlook・Chrome・Cisco BroadWorks・Openwave）：Barracuda の期限は 11-13、その他は 11-24
------------------------------------------------------------
対象: Barracuda ESG／Microsoft Outlook／Google Chrome／Cisco BroadWorks／Openwave Webtop Media Transcoder

【概要】
2026-11-10 に CISA が CVE-2026-111560・CVE-2026-116606（Barracuda）、CVE-2026-124194（Outlook）、CVE-2026-125350（Chrome）、CVE-2026-20320（Cisco BroadWorks）、CVE-2026-111793（Openwave）を KEV へ追加した。Barracuda ESG の 2 件は短期限で、root 実行に至る。

【推奨アクション】
1) 6 製品の導入有無と公開状況を確認。2) Barracuda ESG の修正適用と管理画面の非公開化を最優先。3) Outlook は 11 月月例更新、Chrome は最新版へ更新して再起動。4) BroadWorks・Openwave は各ベンダーの案内を確認する。
  参照: https://www.cisa.gov/known-exploited-vulnerabilities-catalog (CISA KEV)

【中優先度】
------------------------------------------------------------
SOC-2026-11-11-002 [medium] 11 月の月例更新が集中：Microsoft（Outlook ゼロデイ）・SAP（最大深刻度 4 件）・Adobe（9 製品 110 件）・Apple（iOS ほか）。優先順位を付けて適用する
------------------------------------------------------------
対象: Microsoft／SAP／Adobe／Apple／Roundcube／Synology／Siemens／OpenSSL／Firefox

【概要】
Microsoft は悪用済みの Outlook ゼロデイを含む更新を公開（件数は BleepingComputer 1,235 件・SecurityWeek 1,094 件で食い違い）。SAP は NetWeaver／Web Dispatcher／Gateway の最大深刻度 4 件、Adobe は 9 製品 110 件。CERT-FR は同日、SAP・Roundcube・Synology DSM・Siemens SIMATIC・Apple・Firefox・OpenSSL・Chrome 等の注意喚起を出した。窓内に悪用の報告があるのは Outlook と Chrome。

【推奨アクション】
1) 悪用済みの Outlook・Chrome を最優先。2) SAP は外部公開の Web Dispatcher／ICM を優先。3) 公開 Web メール（Roundcube）、NAS（Synology）、OT（Siemens）を棚卸しする。
  参照: https://www.bleepingcomputer.com/news/security/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day (BleepingComputer)
  参照: https://www.securityweek.com/adobe-patches-110-vulnerabilities-across-9-products (SecurityWeek)
  参照: https://www.cert.ssi.gouv.fr/ (CERT-FR (ANSSI))

------------------------------------------------------------
SOC-2026-11-11-003 [medium] 国内の個人情報流出が相次ぐ：ニトリ約 3,762 万件、ドコモ最大約 30 万件ほか。自組織の関連サイト・委託先の侵害を点検する
------------------------------------------------------------
対象: ニトリグループ／NTTドコモ（オンラインショップ・My docomo）／ドトール／阪急阪神百貨店／イープラスほか

【概要】
BleepingComputer によればニトリはシステム侵害で 3,762 万件の顧客記録が盗まれた可能性を公表した。ScanNetSecurity はドコモオンラインショップ・My docomo への不正アクセス（最大約 30 万件）、イープラスの管理画面への総当たり攻撃などを報じ、Security NEXT はドトール通販サイトと阪急阪神百貨店の関連サイトの侵害を報じた。手口は多くが要約の範囲で未確認。

【推奨アクション】
1) 管理画面への総当たり対策（多要素認証・試行制限）を点検。2) 関連サイト・通販・アプリなど周辺システムの資産棚卸し。3) 影響を受けた利用者へのパスワード再設定の案内を確認する。
  参照: https://www.bleepingcomputer.com/news/security/japanese-furniture-giant-nitori-says-hackers-stole-376m-customer-records (BleepingComputer)
  参照: https://scan.netsecurity.ne.jp/article/2026/11/10/56724.html (ScanNetSecurity)

【低優先度】
------------------------------------------------------------
SOC-2026-11-11-004 [low] Git 2.56.1 ほか：再帰クローン時にコード実行され得る整数切り捨ての脆弱性（CVE-2026-111760）を修正
------------------------------------------------------------
対象: Git

【概要】
THN によれば、悪意あるリポジトリを子モジュールごと再帰的にクローンするとコードが実行され得る Git の脆弱性 CVE-2026-111760 が修正された。悪用の報告は窓内に無い。

【推奨アクション】
開発端末・CI の Git を修正版へ更新し、信頼できないリポジトリの再帰クローンを避ける。
  参照: https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html (The Hacker News)
