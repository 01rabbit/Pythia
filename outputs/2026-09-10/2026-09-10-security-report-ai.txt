------------------------------------------------------------

ATLAS: 該当タクティクスなし / 調査中
OWASP: AG05
対象: it / global
被害規模: 規模: 不明

【24時間以内（または期間内）の変化】
[OffSeq Threat Radar 2026-09-09] Google Cloud Agent Development Kit(ADK) for Python 2.0.0-2.6.0（pytestインストール済みのPython/Cloud Run/GKE環境）で、加工したテストセッションリプレイにより未認証の任意コード実行が可能な脆弱性CVE-2026-79696（CVSS10.0）が公開された

【概要】
Googleが提供するAIエージェント開発フレームワーク（ADK for Python）のadk web機能に、pytestがインストールされた環境（Cloud Run/GKE含む）で加工したテストセッションのリプレイにより未認証の攻撃者が任意コード実行できる脆弱性が判明した。CVSS10.0の最高深刻度だが、実稼働環境でのpytestインストールは限定的であり影響範囲は特定条件下に留まる（推測）。実悪用・PoC公開は本日時点で未確認。

攻撃の流れ:
1. pytestが有効なADK for Python環境に対し加工したテストセッションリプレイを送信
2. 未認証のままコード実行に到達

【IoC / 検知シグナル】
IoC: 確認されず

【監視・対策ポイント】
・ADK for Pythonのadk web機能へのテストリプレイ関連エンドポイントへの外部からのアクセスを監視する

【参照】
https://radar.offseq.com/threat/cve-2026-79696-cwe-184-incomplete-list-of-disallowed-inputs-in-google-cloud-agent-development-kit-adk-3b96714136b44311

Amazon awslabs postgres-mcp-server: SQL検証コンポーネントのOSコマンドインジェクション（CVE-2026-87911）
カテゴリ: CC1 / 攻撃者種別: 不明
------------------------------------------------------------

採用契機: A-R
ATLAS: 該当タクティクスなし / 調査中
OWASP: AG02
対象: it / global
被害規模: 規模: 不明

【24時間以内（または期間内）の変化】
[NVD 2026-09-09] AWS Labs提供のpostgres-mcp-server（v1.1.7未満）のSQL検証コンポーネント『read-only enforcement』機能にOSコマンドインジェクション脆弱性CVE-2026-87911（CVSS9.6）が公開された

【概要】
AIエージェントがPostgreSQLへ安全にアクセスするためのMCP（Model Context Protocol）サーバ実装postgres-mcp-serverにおいて、読み取り専用強制のSQL検証コンポーネントを起点とするOSコマンドインジェクションが判明した。未認証のアクターが悪用できる可能性がある。v1.1.7で修正済み。実悪用・PoC公開は本日時点で未確認。

攻撃の流れ:
1. MCPサーバのSQL検証コンポーネントへ加工クエリを送信
2. read-only enforcement処理を経由してOSコマンドインジェクションに到達

【IoC / 検知シグナル】
IoC: 確認されず

【監視・対策ポイント】
・postgres-mcp-serverのバージョンとMCPサーバプロセスからの異常な子プロセス生成を確認する

【参照】
https://radar.offseq.com/
