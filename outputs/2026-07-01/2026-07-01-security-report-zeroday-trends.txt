CVE-2026-46817 / Oracle E-Business Suite（Oracle Payments / File Transmission）
CVSS: 9.8 (Critical) 状態: 実悪用確認
CVE-2026-46817はOracle E-Business Suite（EBS）のOracle Paymentsモジュール内File Transmissionコンポーネントに存在する権限管理不備・認証不備に起因する重大な脆弱性で、CVSSv3基本値は9.8。未認証の攻撃者がネットワーク経由でOracle Paymentsを完全に乗っ取ることが可能。Oracleは2026年5月のCritical Patch Updateで修正済みだが、脅威インテリジェンス企業Defusedによれば、パッチ公開から約6週間後の2026年6月27日から28日にかけて、ハニーポット上で未認証のファイル読み取り攻撃が観測されており、公開PoCが存在しない段階での実悪用という点で警戒度が高い。Shadowserverの調査では約950台のインスタンスが依然インターネットに公開されている。現時点で日本国内での被害報告や国内メディアでの報道は確認されていない。
参照: https://www.helpnetsecurity.com/2026/06/30/oracle-payments-cve-2026-46817-exploitation/

CVE-2026-48558 / SimpleHelp RMM
CVSS: 10.0 (Critical) 状態: KEV登録済み / 実悪用確認 / PoC公開
CVE-2026-48558はSimpleHelp（RMMソフトウェア）のOIDC認証フローにおいて、ログイン時に提示されるIDトークンの暗号署名検証を行わない不備に起因する認証バイパスの脆弱性で、CVSSv3基本値は10.0。既に既報の脆弱性だが、2026年6月29日にCISA KEVカタログへ新規登録（連邦機関対応期限7月2日）され、さらに本レポート期間中にBlackpoint Cyberが本脆弱性を悪用した新たな攻撃キャンペーンの詳細（TaskWeaverという難読化されたNode.jsローダーを介した二段階目のDjinn Stealer展開）を報告した。SimpleHelpはMSPで広く使われているため、一つの侵害が多数の顧客組織へ波及するリスクがある。
参照: https://thehackernews.com/2026/06/attackers-exploit-simplehelp-cve-2026.html

CVE-2026-8037 / Progress Kemp LoadMaster / ECS Connection Manager / Object Scale Connection Manager / MOVEit WAF
CVSS: 9.8 (Critical) 状態: 実悪用確認 / PoC公開
CVE-2026-8037はProgress Kemp LoadMaster（ロードバランサー/ADC製品）のAPI処理に存在する未認証の事前認証リモートコード実行脆弱性で、CVSSv3基本値は9.8。原因はescape_quotes()関数がmalloc()で確保したバッファを未初期化のまま使用し、かつNULL終端を書き込まないことで隣接ヒープメモリへの範囲外読み取りが発生する点にある。既報の脆弱性だが、2026年6月29日にwatchTowr Labsが独自解析による技術詳細と動作するPoCを公開し、同日から実際の悪用試行がeSentireにより観測された。観測された試行は失敗に終わったとされるが、PoC公開に伴い今後の悪用拡大が懸念される。
参照: https://labs.watchtowr.com/enterprise-tech-in-shell-out-progress-kemp-loadmaster-uninitialized-heap-to-pre-auth-rce-cve-2026-8037/
