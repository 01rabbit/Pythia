CVE-2026-120705 [9] GeoServer（gs-wfs-core / GeoTools gt-metadata・OGC WFS・未認証任意ファイル読み取り）
------------------------------------------------------------
対象: GeoServer (OSGeo) / GeoServer 3.0.2／2.28.6／2.27.7 未満（修正版 3.0.2・2.28.6・2.27.7）
KEV 追加: 2026-11-27（FCEB 期限 2026-11-30）
評点: CVSS v3 8.6
【概要】
CISA は 2026-11-27、GeoServer の未認証任意ファイル読み取り CVE-2026-120705（CVSS 8.6）を実悪用を根拠に KEV へ追加した（期限 11-30）。watchTowr が 2026-11-25 にグローバルハニーポットで in-the-wild 悪用（検証/探索）を観測していた CVE で、本リポジトリは 11-27 に E1 予報 fc-20261127-1（確度低・確率 0.30・期限 11-30）を発行済。発行翌窓での KEV 収載により予報は的中見込みとなる（的中判定は検証ステージ 04 が担当し、本日の正規化・予報段階では verified_outcome を書き込まない＝行動原則4）。未認証多段 RCE チェーンの起点であり、修正版 3.0.2／2.28.6／2.27.7 への即時更新が必要。
【一時緩和】
  - GeoServer を修正版へ更新し WFS エンドポイントの到達範囲を限定する。未認証 WFS リクエストとストアドクエリ作成/削除ログを点検する。

TREND-2026-11-28-002 Java4Shell（CVE-2026-114938・OpenJDK/HotSpot メモリ破壊）: CISA が 11-17 に緊急更新を勧告、CrowdStrike は『露出と post-exploitation 検知』を提供（確証ある実悪用の観測報告はなし）
------------------------------------------------------------
OpenJDK/HotSpot JVM の AVX-512 Base64 デコードのメモリ破壊（ヒープ境界外書き込み）CVE-2026-114938（Oracle CVSS 8.1／Red Hat 9.8）について、CISA は 2026-11-17 に緊急更新を勧告済（Fixes 11-17）。CrowdStrike は本窓で『Java4Shell の露出把握と post-exploitation 活動の検知』を提供すると公表したが、実際の被害者に対する in-the-wild 実悪用を観測したとは述べていない（『潜在的な悪用ベクトルを分析中』）。ISC SANS も『警戒色 Yellow には上げない』としている。未認証リモートで trigger 可能だが『DoS が最も確実な結果』とされ RCE は難度が高い。確証ある実悪用の観測報告が無いため E1（KEV 初回追加）の予報対象にはしない（行動原則2・断定しない）。露出が大きいため Java の修正版への更新を優先する。
  参照: https://www.cisa.gov/news-events/alerts/2026/11/17/critical-java-vulnerability-requires-immediate-patching (CISA)
