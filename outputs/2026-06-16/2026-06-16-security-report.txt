1. CVE-2026-47281  /  Microsoft Defender
   対象: Windows 10 / Windows 11 — 全バージョン・全ビルド
------------------------------------------------------------

  優先度 : 必須
  CVSS   : 9.6  (Critical)
  状態   : ゼロデイ・未パッチ・PoC公開・実悪用確認


  【24時間以内の変化】

    [BleepingComputer 2026-06-10]
      研究者 Nightmare-Eclipse が PoC "RoguePlanet" を公開。
      GitHub / GitLab のリポジトリは削除されたが、
      自己ホストリポジトリ経由で現在も拡散継続中。

    [SecurityWeek 2026-06-10]
      完全パッチ済み端末（6月 Patch Tuesday KB5094126 適用済み）でも
      SYSTEM 昇格が成功することが実証・報告された。

    [threat-modeling.com 2026-06-14]
      24h 窓直前まで悪用継続を確認。
      Nightmare-Eclipse による今年 6 本目の Defender 系未パッチ PoC。


  【概要】

    Microsoft Defender の TOCTOU（時間差チェック）競合状態を突く
    LPE（ローカル権限昇格）脆弱性。

    攻撃の流れ:
      1. フィッシング / ドライブバイ等で被害者端末上でのコード実行を取得
      2. RoguePlanet PoC を実行 → SYSTEM 権限を取得
      3. EDR / Defender を無効化し横展開・データ窃取・ランサムウェア展開へ

    成功率は競合状態のため端末によってばらつきがあるが、
    一部環境では 100% の再現性が報告されている。
    Microsoft は6月 Patch Tuesday でこの CVE を修正しておらず、
    パッチリリース時期は未公表。


  【IoC】

    IoC: 公開 PoC 自体は拡散中。特定インフラの IoC は未確認。


  【監視ポイント】

    ・ [Windows Security Event Log 4688]
        SYSTEM 権限で CMD.EXE / PowerShell が
        Defender 関連プロセス（MsMpEng.exe 等）の子として生成される事象

    ・ [EDR]
        MsMpEng.exe から生成される予期しない子プロセス

    ・ [EDR]
        Token Impersonation / SeDebugPrivilege の不審な取得

    ・ [Sysmon ID 1]
        Defender サービスアカウント配下からの非標準実行パス

    https://www.securityweek.com/new-windows-zero-day-exploit-rogueplanet-released/

2. CVE-2026-35273  /  Oracle PeopleSoft Enterprise PeopleTools
   対象: PeopleTools 8.61 / 8.62
------------------------------------------------------------

  優先度 : 必須
  CVSS   : 9.8  (Critical)
  状態   : KEV 登録済み（2026-06-12）・実悪用確認・ゼロデイ悪用確認
           ランサムウェア展開確認


  【24時間以内の変化】

    [Security NEXT 2026-06-15]  ← 国内報道確認
      「Oracle PeopleSoft」脆弱性、ランサム攻撃にも悪用
       — 米当局が注意喚起（国内メディアへの初掲載）

    [CISA BOD 26-04  2026-06-15]
      3日ルールによる FCEB 機関向けパッチ適用期限が本日到来。

    [ShinyHunters (UNC6240) — キャンペーン継続中]
      100社以上の大学・教育機関への侵害を確認。
      一部でランサムウェア展開、被害データはリークサイトに公開済み。


  【概要】

    PeopleSoft EMHub コンポーネントの SSRF-to-RCE 脆弱性。

    攻撃の流れ:
      1. 単一の HTTP POST リクエストに細工したパラメータを送信
      2. 認証ハンドラーを欺き、完全管理者権限のセッショントークンを取得
      3. 機密データ窃取 / ランサムウェア展開へ

    認証不要・ユーザー操作不要。
    ShinyHunters (UNC6240) が 2026-05-27 から Oracle の公式アドバイザリ（6/10）より
    2週間前にゼロデイとして悪用開始。
    日本国内でも大学・研究機関での PeopleSoft 利用が確認されており、
    未パッチ環境は即時対応が必要。


  【IoC】

    攻撃インフラ（第1波 2026-05-18）: Vultr ホスティング経由
    攻撃インフラ（第2波 2026-05-21）: Dromatics Systems 経由
    ※ 具体的 IP は Rapid7 ETR レポート参照


  【監視ポイント】

    ・ [Web サーバーログ]
        /PSIGW/RESTListeningConnector および EMHub エンドポイントへの
        異常な POST リクエスト

    ・ [ネットワーク]
        PeopleSoft サーバーから内部サービスや外部 IP への
        予期しない発信接続（SSRF 兆候）

    ・ [認証ログ]
        管理者セッションが通常とは異なるソース IP から確立される事象


  【参照】
