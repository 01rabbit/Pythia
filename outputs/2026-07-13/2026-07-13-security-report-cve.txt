1. CVE-2026-56271 / FlowiseAI/Flowise
対象: 3.0.13以前
------------------------------------------------------------

優先度: 必須
CVSS: 9.8 (Critical)
状態: PoC未公開・実悪用未確認（パッチ提供済み）

【24時間以内の変化】
[NVD 2026-07-12] CVE-2026-56271がNVDに公開。enterprise passport認証ミドルウェアでJWT_AUTH_TOKEN_SECRET等の環境変数未設定時に公開既知のデフォルト値へフォールバックし、任意ユーザー（管理者含む）へのなりすましJWT偽造が可能なことが判明

【概要】
FlowiseAI/Flowise（AIエージェント/LLMワークフロー構築プラットフォーム、3.0.13以前）のenterprise passport認証ミドルウェアにおいて、JWT_AUTH_TOKEN_SECRET等の環境変数が未設定の場合に公開既知のデフォルト値へフォールバックする実装不備が2026-07-12にNVD公開された（GHSA-cc4f-hjpj-g9p8）。既知のデフォルトシークレットを用いることで管理者を含む任意ユーザーへのなりすましJWTを偽造でき認証をバイパスできる。実悪用・PoC公開は本日時点で確認されていない。NVD側CVSSは9.8（Critical）だが、関連する別件アドバイザリ（GHSA-m7mq-85xj-9x33）ではCVSS5.6と評価されており出典間でスコアに差異がある点に留意が必要（事実として両者のスコア差を記録・原因は不明）。本編優先配置理由: CVSS9.0以上のCritical脆弱性としてD2高インパクト条件に該当するため軸1×軸2の閾値によらず本編へ優先配置した。同カテゴリのAIオーケストレーションツールLangflowはランサムウェアの侵入起点として実悪用が継続しており、AIエージェント基盤特有の攻撃対象領域として注視が必要（推測）。

攻撃の流れ:
1. 環境変数（JWT_AUTH_TOKEN_SECRET等）が未設定の状態で稼働しているFlowiseインスタンスを特定
2. 公開されている既知のデフォルトシークレット値を用いて、管理者を含む任意ユーザーになりすましたJWTを偽造
3. 偽造JWTでAPIへ認証済みリクエストを送信し、管理者権限でワークフロー・API鍵・接続情報等へアクセス

【IoC】
IoC: 確認されず

【監視ポイント】
・[アプリケーションログ / SIEM] JWT認証イベントにおける既知デフォルトシークレットの使用兆候、環境変数未設定時のフォールバック動作を監視
Splunk SPL: index=app_logs sourcetype=flowise (event="jwt_issue" OR event="jwt_validate") | stats count by src_ip, user_id, role
→ JWT_AUTH_TOKEN_SECRET等の環境変数が実際に設定されているか資産棚卸しで確認し未設定インスタンスを最優先で是正する。正規ログインとの誤検知除外には直前のログイン履歴が存在しない管理者アクションの急発生を判断材料とする

2. CVE-2026-56260 / Crawl4AI Docker API Server
対象: 0.8.7未満
------------------------------------------------------------

優先度: 必須
CVSS: 9.1 (Critical)
状態: PoC未公開・実悪用未確認（パッチ提供済み・0.8.7）

【24時間以内の変化】
[NVD 2026-07-12] CVE-2026-56260がNVDに公開。/screenshot・/pdfエンドポイントのoutput_pathパラメータが未検証でパストラバーサル可能、任意ファイル書き込み（サーバファイル上書き・DoS）が判明

【概要】
Crawl4AI Docker API Server（LLM向けWebクロール/スクレイピングツール、0.8.7未満）において、/screenshot・/pdfエンドポイントのoutput_pathパラメータへの入力検証が欠如しておりパストラバーサルによる任意ファイル書き込みが可能な脆弱性が2026-07-12にNVD公開された（GHSA-365w-hqf6-vxfg）。認証不要でサーバファイルシステムの任意パスへ書き込み可能なため、既存ファイルの上書きによるDoSやさらなる侵害の足掛かりとなり得る。実悪用・PoC公開は本日時点で確認されていない。同日同一開示バッチ内に関連CVE（CVE-2026-56259・認証情報窃取）も公開されている。本編優先配置理由: CVSS9.0以上のCritical脆弱性としてD2高インパクト条件に該当するため軸1×軸2の閾値によらず本編へ優先配置した。AI/LLM関連ツールのDocker API露出パターンとして継続監視が必要（推測）。

攻撃の流れ:
1. 認証不要で公開されたDocker API Serverの/screenshotまたは/pdfエンドポイントへリクエスト送信
2. output_pathパラメータに../等のパストラバーサル文字列を指定
3. サーバファイルシステム上の任意パスへファイルを書き込み、既存ファイルの上書き・DoS・さらなる侵害の足掛かりを作る

【IoC】
IoC: 確認されず

【監視ポイント】

Splunk SPL: index=app_logs sourcetype=crawl4ai_docker uri_path IN ("*/screenshot*", "*/pdf*") | regex form_data="\.\.\/" | stats count by src_ip, uri_path
→ output_pathパラメータに../等の相対パス指定が含まれるリクエストを異常とみなす。正規利用では出力先が固定ディレクトリ配下に限定されるため上位ディレクトリへの逸脱パスは全て要確認とする
