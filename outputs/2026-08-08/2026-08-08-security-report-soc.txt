1. Djangoフレームワークの脆弱性4件（最大CVSS8.8）を修正するセキュリティアップデート公開
観点: CVE関連
採用契機: β
------------------------------------------------------------

優先度: 中
対象: Django（Webアプリケーションフレームワーク）

【24時間以内の変化】
[Security NEXT 2026-08-07] Django 6.0.8/5.2.17でCVE-2026-15307（CVSS8.8）を含む4件の脆弱性を修正するセキュリティアップデートを公開したと報道。実悪用の報告はなし

【概要】
Django公式が2026-08-04付でCVSS9.0未満の脆弱性4件（空間ルックアップ経由のファイル書込み/外部リクエスト、GEOMETRYCOLLECTIONネストによる異常終了、管理画面XSS、言語コード処理によるDoS）を修正するセキュリティリリースを公開した。広く利用されるOSS Webフレームワークのミドルウェア層の脆弱性であり、CVSS9.0未満・KEV未登録・PoC未公開のためSection3の主要枠には該当しないが、SOCとして把握し今週中のパッチ適用を確認すべき事案である。

【推奨アクション】
・Django公式セキュリティリリース（6.0.8 / 5.2.17）へ今週中にアップデートする
・GeoDjango等で外部入力を伴う空間クエリを扱うアプリケーションはCVE-2026-15307の影響有無を優先確認する
・管理画面（/admin/）のXSS（CVE-2026-15920）対策として管理者アカウントへのアクセス制限を再確認する
→ パッチ未適用環境でのエラーログ急増は悪用試行の可能性があるため通常のデプロイ起因エラーと切り分けて確認する

【参照】
https://www.security-next.com/188462
https://thehackernews.com/2026/08/veeam-terraform-mcp-django-patch.html

2. Microsoft/Appleが2026年8月の追加セキュリティ更新を公開、Azure/Entra/TeamsでCVSS9.9〜10.0の複数脆弱性を修正
観点: CVE関連
採用契機: β
------------------------------------------------------------

優先度: 中
対象: Microsoft Azure / Entra ID / Teams / SharePoint、Apple macOS

【24時間以内の変化】
[SecurityWeek 2026-08-07] MicrosoftがPlanetary Computer Pro（CVE-2026-63508）・Azure SQL Database（CVE-2026-56162）・Teams（CVE-2026-65667）でCVSS10.0、Azure Service Bus等でCVSS9.9の脆弱性を修正。AppleがmacOSのScreen Sharing認証バイパス（CVE-2026-65400・CVSS7.5）を修正するアップデートを公開したと報道。両ベンダーとも実悪用の言及はなし

【概要】
MicrosoftはActive Directory・Azure・Entra・SharePoint・Teamsにまたがる複数の脆弱性を修正し、うちPlanetary Computer Pro・Azure SQL Database・Teamsの3件はCVSS10.0、Azure Service Bus等4件はCVSS9.9だった。クラウド側で提供者により修正済みのためエンドユーザー側のパッチ適用は不要だが、認証・認可欠如という性質上、修正前の期間の不審なアクセスの遡及確認が望ましい。AppleはmacOSのScreen Sharing認証バイパス（CVE-2026-65400）を修正するアップデート（Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9）を公開しており、端末側での適用が必要。いずれもCISA KEV未登録・実悪用未確認。

【推奨アクション】
・Microsoft 365/Azure/Entraの管理者は修正されたCVEに関連するサインインログ・管理操作ログを遡って確認し異常なテナント間アクセスがないか点検する
・macOS端末をTahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9以降へ今週中にアップデートする
・Active DirectoryおよびEntra Provisioning Serviceの権限昇格系CVEを踏まえTier0/Tier1管理者アカウントの棚卸しと最小権限化を実施する
→ クラウド側修正のため直接の攻撃痕跡ログは限定的だが修正日以前の管理操作ログとの突合で予兆確認が可能

【参照】
https://www.securityweek.com/microsoft-apple-release-fresh-security-updates/
