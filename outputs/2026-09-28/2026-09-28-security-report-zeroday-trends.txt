1. CVE-2026-88771 / Citrix NetScaler ADC / NetScaler Gateway
対象: NetScaler ADC/Gateway 14.1 before 14.1-73.37; 13.1 before 13.1-64.23; 14.1 FIPS before 14.1-73.37 FIPS; 13.1 FIPS/NDcPP before 13.1-37.279
------------------------------------------------------------

優先度: 緊急（パッチなし）
CVSS: 9.5 (Critical) [v4.0]
状態: KEV登録済み / 実悪用確認 / ゼロデイ
パッチ提供: 提供済み

【24時間以内の変化】
[Citrix (Cloud Software Group) 2026-09-27] セキュリティ速報CTX697096でCVE-2026-88771を含む計8件の脆弱性を公開し、非パッチ適用環境での実悪用を確認したと発表。修正版14.1-73.37/13.1-64.23等をリリース。
[The Hacker News 2026-09-27] 未認証攻撃者による任意コマンド実行が可能で全NetScaler ADC/Gateway展開に追加設定なしで影響すると報道。watchTowr Labsが前日26日時点で同種の未修正RCEの兆候を検知していたと報告。
[BleepingComputer 2026-09-28] Citrixが正式に非パッチ適用のNetScaler展開環境での悪用を確認したと声明。管理者へ即時パッチ適用または露出低減を推奨。
[CISA KEV Catalog 2026-09-27] CISAがKnown Exploited VulnerabilitiesカタログへCVE-2026-88771を新規追加（catalogVersion 2026.09.27・FCEB期限2026-09-30）。

【概要】
Citrixは2026-09-27、NetScaler ADCおよびNetScaler Gatewayに存在する未認証RCEの緊急脆弱性CVE-2026-88771（入力検証不備・CVSS9.5）を修正パッチとともに公開し、非パッチ適用環境で実悪用が確認されたと発表した。追加のライセンス機能や設定を必要とせず全てのNetScaler ADC/Gateway展開が影響を受ける。watchTowr Labsは調査の過程で同種の未修正RCEの兆候を検知しており、オランダNCSC-NLは事前通知を受け複数の顧客組織で実悪用が確認されたと報告している。CISAは同日KEVカタログへ本CVEを新規追加しFCEB機関に2026-09-30までの対応を義務付けた。攻撃者の身元・具体的なIOCは本日時点で未公開。

攻撃の流れ:
1. 未パッチのNetScaler ADC/Gatewayに対し、未認証のリモート攻撃者が入力検証不備を悪用したリクエストを送信
2. 検証不備を突いて機器上で任意のコマンドを実行
3. 侵害された境界機器を足掛かりに内部ネットワークへの侵入・横展開を試みる可能性がある（具体的な侵害後の挙動は本日時点で未公開）

【暫定緩和策】（パッチが提供されるまでの間の対処）
・緊急パッチ（14.1-73.37 / 13.1-64.23 等）の即時適用
・パッチ適用が即時に行えない場合はNetScaler管理インターフェース・VPN仮想サーバのインターネットへの露出を可能な限り低減する
・DTLSを使用しないVPN仮想サーバ構成が運用上可能な場合は無効化しCVE-2026-88772の攻撃面を縮小する
・侵害が疑われる場合は証跡を保全した上で機器を隔離し、関連する認証情報をリセットする

【IoC】
IoC: 確認されず

【監視ポイント】
・NetScaler管理インターフェース・VPN仮想サーバへの想定外の認証試行・コマンド実行痕跡、設定改ざん、および子プロセスの異常起動を監視する。DTLSを使用しないVPN構成へ切替可能な場合はCVE-2026-88772の攻撃面縮小になる。
Splunk SPL: index=network sourcetype=citrix_netscaler_syslog (message="*command*" OR message="*exec*" OR message="*shell*") | table _time src_ip user message
Splunk SPL: index=network sourcetype=citrix_netscaler_syslog event_type=vpn | stats count by src_ip | where count > 50
→ 既知の正規メンテナンス作業（管理者によるCLI操作等）と外部IPからの想定外コマンド実行・設定変更を区別すること。DTLS未使用のVPN仮想サーバ構成ではCVE-2026-88772の影響を受けないため誤検知除外の判断材料にする。

2. CVE-2026-88772 / Citrix NetScaler ADC / NetScaler Gateway
対象: NetScaler ADC/Gateway 14.1 before 14.1-73.37; 13.1 before 13.1-64.23（DTLS有効なVPN仮想サーバ・NetScaler Gateway展開が対象。DTLSはVPN仮想サーバで既定有効）
------------------------------------------------------------

優先度: 緊急（パッチなし）
CVSS: 9.5 (Critical) [v4.0]
状態: KEV登録済み / 実悪用確認 / ゼロデイ
パッチ提供: 提供済み

【24時間以内の変化】
[Citrix (Cloud Software Group) 2026-09-27] CVE-2026-88771と同一のセキュリティ速報CTX697096でCVE-2026-88772を公開し、非パッチ適用環境での実悪用を確認したと発表。
[The Hacker News 2026-09-27] DTLS有効時のメモリオーバーフローによりRCEまたはDoSが可能と報道。DTLSはVPN仮想サーバで既定有効なためNetScaler Gatewayは明示的に無効化しない限り影響を受けると指摘。
[CISA KEV Catalog 2026-09-27] CISAがKEVカタログへCVE-2026-88772を新規追加（catalogVersion 2026.09.27・FCEB期限2026-09-30）。

【概要】
CVE-2026-88771と同一のCitrixセキュリティ速報CTX697096（2026-09-27公開）で修正されたNetScaler ADC/GatewayのCVE-2026-88772は、DTLS有効時（VPN仮想サーバでは既定で有効）のメモリオーバーフローにより、未認証の遠隔攻撃者がリモートコード実行またはサービス拒否を引き起こせる脆弱性である。Citrixは非パッチ適用環境での実悪用を確認しており、CISAは同日KEVカタログへ本CVEも新規追加した（FCEB期限2026-09-30）。攻撃手口の詳細・IOCはCVE-2026-88771のエントリと共通の情報源に基づく。

攻撃の流れ:
1. DTLSが有効なNetScaler Gateway（VPN仮想サーバ）に対し、未認証のリモート攻撃者がメモリオーバーフローを誘発するデータを送信
2. メモリ破壊によりリモートコード実行またはサービス拒否（クラッシュ）を引き起こす
3. RCEに成功した場合は境界機器を足掛かりに内部ネットワークへの侵入を試みる可能性がある（具体的な侵害後の挙動は本日時点で未公開）

・DTLSを使用しないVPN仮想サーバ構成が運用上可能な場合は無効化しCVE-2026-88772の攻撃面を縮小する
・侵害が疑われる場合は証跡を保全した上で機器を隔離し、関連する認証情報をリセットする
