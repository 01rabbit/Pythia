1. acmailer 複数の脆弱性（XSS + 権限不備）
観点: CVE関連
採用契機: alpha, beta
------------------------------------------------------------

優先度: 高
対象: acmailer CGI（4.1.2以前）/ acmailer DB（1.2.2以前）

【24時間以内の変化】
[JVN #47716829 / JVN iPedia 2026-08-19] 情報セキュリティ早期警戒パートナーシップに基づきJPCERT/CCが開発者と調整。CVE-2026-66358（XSS, CVSS8.8）とCVE-2026-70408（認可不備, CVSS6.1）の2件が公表された（詳細はSection3参考A参照）。

【概要】
acmailerは国内のレンタルサーバー事業者経由で広く導入されているメール配信CGI/DB製品であり、認可不備と組み合わさるとサブアカウント経由での管理者権限奪取からの二次被害につながる恐れがあるため、SOCは自組織・委託先の利用有無を至急確認すべきである。

【推奨アクション】
・自社・委託先（レンタルサーバー環境含む）でacmailer CGI/DBの利用有無を棚卸し、利用があればバージョンを確認する
・ベンダー提供の最新版へのアップデートを最優先で適用する
・サブアカウント一覧を確認し、意図しない管理者権限アカウントが作成されていないか監査する
・[ログソース / SIEM（Splunk等）] acmailer管理パネルへのスクリプトインジェクション試行、想定外のサブアカウント作成イベントを監視する
Splunk SPL: index=web_proxy OR index=waf uri="*acmailer*" (uri="*<script*" OR uri="*onerror=*") | table _time, src_ip, uri, http_status

【参照】
https://jvn.jp/jp/JVN47716829/
https://jvndb.jvn.jp/ja/contents/2026/JVNDB-2026-000118.html

6. パスワードスプレー攻撃が155倍に急増（Azure CLI/ROPC悪用・Huntress報告）
観点: CVE関連
採用契機: delta, epsilon
------------------------------------------------------------

優先度: 中
対象: Microsoft Azure CLI / Entra ID

【24時間以内の変化】
[BleepingComputer (Huntress Labs) 2026-08-19] Huntress Labsが2026年上半期にパスワードスプレー攻撃が155倍に急増したと報告。Azure CLIを狙う「LSHIY」キャンペーンは2週間で8,100万件超のログイン試行・78件の侵害を記録。MFAの適用漏れがあるROPC（Resource Owner Password Credentials）フローを悪用。

【概要】
攻撃者はMFA導入済みの組織であってもAzure CLI経由のROPC認証フローがMFA・条件付きアクセスの対象外になっているギャップを突いており、海外での急増が国内Azure利用企業にも波及しうるため、SOCはConditional Accessポリシーの網羅性を至急点検すべきである。

【推奨アクション】
・Entra IDでROPCフローおよびAzure CLIに対するConditional Access適用状況を確認する
・不要なROPC依存アプリケーションを無効化し、Azure CLIアクセスを管理者に限定する
・全ユーザー・全クラウドアプリを対象としたMFA強制設定（除外なし）へ見直す
・[ログソース / SIEM（Splunk等）] 単一送信元から多数ユーザーへの低頻度・分散型認証試行（パスワードスプレーパターン）を監視する
