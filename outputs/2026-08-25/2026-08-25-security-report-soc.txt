1. Spring Application Framework 一括脆弱性公開（91件・2026年通算200件超）
観点: CVE関連
採用契機: alpha, beta
------------------------------------------------------------

優先度: 中
対象: Spring Framework / Spring Security / Spring Cloud Config / Spring for GraphQL / Spring AI

【24時間以内の変化】
[SecurityWeek 2026-08-24] Broadcomが2026-08-20付でSpring関連91件のCVEを一括公開したと報道（2026年通算200件超）

【概要】
Broadcomが2026-08-20付でSpring関連CVEを91件一括公開し、2026年の累計登録数が200件超（2025年は16件）に急増した。うちCVSS Criticalとして、Spring Security組み込みUnboundID LDAPサーバの認証・改ざん脆弱性（CVE-2026-59270）と、Spring for GraphQLのRCE（CVE-2026-59285）が指摘されている。Spring AIのツール呼び出し機能に関するプロンプトインジェクション経由権限昇格（CVE-2026-59318、medium）も注目される。

【推奨アクション】
・自社のSpring/Spring Boot依存関係バージョンを棚卸しし、CVE-2026-59270／CVE-2026-59285の該当有無を確認する
・Spring Securityの組み込みLDAPサーバを本番運用していないか確認する
・Spring AIのtool-calling機能利用時はプロンプトインジェクション対策の適用状況を確認する
・次回パッチサイクルで優先適用する（KEV/PoC未確認のため即時対応は不要）
→ Critical判定の2件（LDAP認証・GraphQL RCE）を優先確認する

【参照】
https://www.securityweek.com/91-vulnerabilities-patched-in-spring-application-framework/
https://www.sonatype.com/blog/91-spring-cves-highlight-the-growing-ai-vulnerability-consumption-problem

2. miniOrange WordPress SSOプラグイン 認証バイパスの実悪用確認
観点: ゼロデイ関連
採用契機: eta, delta
------------------------------------------------------------

優先度: 中
対象: miniOrange SAML 2.0 Single Sign On / miniOrange OAuth SSO（WordPressプラグイン）

【24時間以内の変化】
[BleepingComputer 2026-08-24] SAML応答署名アルゴリズム誘導とOpenSSL検証エラー誤判定の連鎖によるSAML認証偽造の実悪用をDigitalOceanが2026-08-16に確認したと報道

【概要】
miniOrangeのWordPress向けSAML SSO/OAuth SSOプラグインにおいて、SAML応答の署名アルゴリズムをHMAC-SHA1へ誘導しIdP公開鍵を共有シークレットとして誤処理させる手法と、OpenSSL検証エラーを成功と誤判定させる手法を連鎖させることで管理者アカウントを乗っ取れる認証バイパスが、7月の修正公開後も実悪用が確認されている（DigitalOcean、2026-08-16初観測）。

【推奨アクション】
・WordPressサイトでminiOrange SAML SSO/OAuth SSOプラグインの利用有無を棚卸しする
・利用中の場合は最新版へ即時更新する（安全な回避策なしとの報告あり）
・SAMLレスポンス署名アルゴリズム改ざん試行・想定外IPからの管理者セッション確立をWAF/アクセスログで監視する
Splunk SPL: sourcetype=access_combined uri_path="*miniorange*" (uri_query="*SAMLResponse*")
→ 検知時は該当管理者アカウントの即時パスワードリセット・セッション無効化を行う

【参照】
https://www.bleepingcomputer.com/news/security/hackers-target-wordpress-sites-in-miniorange-auth-bypass-attacks/
