SOC-2026-10-31-001 Ivanti Connect Secure：3 件連鎖の悪用（CVE-2026-104935／111357／118527）— KEV 期限 11-02、侵害確認と復旧手順の実施
------------------------------------------------------------
対象: Ivanti Connect Secure

【24時間以内の変化】
[Ivanti／CISA KEV 2026-10-30] Ivanti がアドバイザリを更新し 3 件の連鎖悪用を確認。CVE-2026-111357（期限 11-02）・CVE-2026-118527（期限 11-13）が KEV へ追加。

【概要】
認証回避→ファイルアップロード→権限昇格の連鎖が実環境で悪用され、一部の顧客が侵害された。単独スコアの低い 118527（CVSS 4.3）も連鎖の一部として KEV 収載された点に注意。

【監視】
ICS の管理者ログ、予測可能な名前のファイル作成、権限変更。

SOC-2026-10-31-003 Cursor 上の Claude Code 拡張 2.1.313 の確認 — ~/.ssh/authorized_keys の svc-telemetry 鍵と 134.209.82.225 への通信を点検
------------------------------------------------------------
対象: Cursor / VS Code 系拡張（anthropic.claude-code）

【24時間以内の変化】
[Cursor／OpenSourceMalware 2026-10-29] 悪性版 2.1.313 が約 11 時間配布。正規版 2.1.314 を公開。

【概要】
開発者端末の SSH 鍵・環境変数名が漏れうる。自動更新で取り込まれた可能性がある。

【推奨アクション】
- 該当期間に Cursor で導入した端末を特定して隔離し、authorized_keys の不審鍵・crontab／LaunchAgent／スケジュールタスクを削除、認証情報を交換する。拡張の公開者 ID 一致だけでは安全の根拠にならない点を運用に反映する。

【監視】
開発者端末から 134.209.82.225 への TCP 8099 通信、authorized_keys の変更。

【参照】
- Official Claude Code Extension on Cursor Marketplace Trojanized with Persistent SSH Backdoor (The Hacker News) https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html
