AI-2026-10-24-001 SOCRadar：INC・The Gentlemen のアフィリエイトが AI エージェント基盤「Phantom」で侵入を自動化（AI 実行・人間承認の運用構造）
------------------------------------------------------------
カテゴリ: A/A4 / 軸X=7 軸Y=7
被害規模: SOCRadar は約62組織が標的となり、うち4組織が INC／The Gentlemen のリークサイトに掲載されたと報告。標的は米国が過半で製造・エネルギー・医療が多い。

【24時間以内の変化】
[The Hacker News（SOCRadar） 2026-10-23] SOCRadar が露出したインフラから、Phantom（OpenCode 上で動く 18 スキルの「Autonomous Red Team Kill Chain Framework」）を使うロシア語話者とみられる運用者を確認。

【概要】
THN によれば、運用者は被害者ごとのプロンプトを与えて各手順を人間が承認し、OpenRouter 経由の商用モデルで偵察・エクスプロイト調査・EDR フィンガープリントを実行させる。モデルが拒否すると「承認済みレッドチーム評価」と言い換える。侵入は FortiClient EMS・SimpleHelp・cPanel・VPN ゲートウェイを突き、BYOVD による EDR 無効化・RevSocks・Ghost C2 を用い、窃取した財務データで要求額を決めて vishing で圧力をかける。使用モデルは非公表。

【攻撃フロー】
1. エッジ／リモートアクセス製品を悪用して侵入
2. AI エージェントが偵察・資格情報窃取・ドメイン昇格を人間承認下で実行
3. BYOVD で EDR を無効化し、データ窃取後に恐喝（vishing・24〜72 時間の期限）

【監視】
露出する FortiClient EMS・SimpleHelp・cPanel のパッチ状況確認と、EDR 無効化ドライバー導入の検知を強化する。

【参照】
- Exposed Infrastructure Reveals How Ransomware Affiliates Used AI Agents to Execute Intrusions (The Hacker News) https://thehackernews.com/2026/10/exposed-infrastructure-reveals-how.html

AI-2026-10-24-002 LiteLLM 侵害の続報：侵害された GitHub CLI の OAuth トークンで悪意あるパッケージを PyPI と Docker に公開・承認
------------------------------------------------------------
カテゴリ: C/C6 / 軸X=8 軸Y=7
被害規模: 影響範囲は 10-22 の既報（1.107.0／Docker イメージ）と同一。被害件数は未公表。

【24時間以内の変化】
[SecurityWeek／Security NEXT 2026-10-23] SecurityWeek は、攻撃者が侵害した GitHub CLI の OAuth トークンを使い悪意あるパッケージを PyPI と Docker に push・承認したと報じた。Security NEXT も資格情報窃取とコード実行のおそれを伝えた。[既報・更新]

【概要】
SecurityWeek の要約によれば、リリース経路で GitHub CLI の OAuth トークンが悪用された。既報の cook.pth による資格情報窃取と GitHub デッドドロップ経由の C2 は同一事案。攻撃主体は特定されていない。

【攻撃フロー】
1. GitHub CLI の OAuth トークンを入手
2. トークンで悪意あるパッケージを PyPI／Docker に公開・承認
3. 導入環境で資格情報を窃取

【監視】
1.107.0 の導入有無と導入環境の資格情報の不正利用を確認する。

【参照】
- LiteLLM Compromised in Fresh Supply Chain Attack (SecurityWeek) https://www.securityweek.com/litellm-compromised-in-fresh-supply-chain-attack
- 「LiteLLM」に不正プログラム混入 - 認証情報漏洩やコード実行のおそれ (Security NEXT) https://www.security-next.com/191830

AI-2026-10-24-003 x402 SDK の既定クライアントに支払い上限がなく、悪意ある API が AI エージェントのトークン残高全額の署名を要求できた（V12 報告）
------------------------------------------------------------
カテゴリ: C/C3 / 軸X=5 軸Y=3
被害規模: 自動署名設定のエージェントのみ。8-18 のリリースで上限が追加済み。悪用の報告なし。

【24時間以内の変化】
[The Hacker News（V12） 2026-10-22] V12 が 10-22 に公表。

【概要】
THN によれば、x402 SDK の既定クライアントは支払い額の上限を持たず、悪意ある API が要求した満額に自動署名するエージェントは残高全額を失い得た。8 月 18 日のリリースで上限が追加された。

【攻撃フロー】
1. エージェントが悪意ある API を呼ぶ
2. API が残高全額の支払いを要求
3. 自動署名で資金が流出

【監視】
x402 SDK を使うエージェントの版と支払い上限の設定を確認する。

【参照】
- Critical x402 SDK Flaw Could Let Malicious APIs Drain AI Agents' Token Balances (The Hacker News) https://thehackernews.com/2026/10/critical-x402-sdk-flaw-could-let.html
