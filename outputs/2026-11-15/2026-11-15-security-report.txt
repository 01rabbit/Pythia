AI-2026-11-15-001 [カテゴリC] Cursor：侵害の経緯を公表（Fireworks AI の認証情報窃取→AI エージェント履歴バケット→一部 API 認証情報露出）。10-29 の Claude Code 拡張改ざんの原因
------------------------------------------------------------
BleepingComputer によれば、Cursor は侵害を認めた。攻撃者は第三者の AI 基盤事業者 Fireworks AI に保管されたアクセスキーを入手し、Cursor が Fireworks と情報共有に使う読み取り専用ストレージのバケットから、AI コーディングエージェントの過去の履歴をコピーした。履歴の一部には平文の API 認証情報が含まれ、それが Cursor の他システムへの足掛かりになったという。SaaS ツールからは非本番のソースコードのアーカイブ、限定的なサポートメール・顧客情報、利用指標、エージェント会話の要約、顧客がサポートに共有した認証情報が窃取されたと Cursor は述べた。10-29 に Cursor マーケットプレイスで配布された Claude Code 拡張の改ざん版（2.1.312・2.1.313）は約 11 時間配布され、SSH バックドア設置を試みるコードを含んでいた（既報）。BleepingComputer は Wiz が『Black October』と呼ぶ AI 開発基盤への攻撃の波の一部と記述する。Cursor は Fireworks への推論トラフィックを移し、認証情報を失効・更新し、マーケットプレイスを再構築した。攻撃者の帰属は情報源に記載が無い。
  被害規模: BleepingComputer によれば Cursor は、Privacy Mode 無効ユーザーの AI エージェント履歴（主に 2025 年）が露出したのは全体の 0.05% 未満、API 認証情報が侵害された顧客は 0.01% 未満と述べた。改ざん版拡張（2.1.312・2.1.313）を受け取った可能性があるのは最大 5,000 ユーザー。
  監視: 端末の authorized_keys への未知の SSH 鍵追加、sshd の意図しない有効化、拡張機能の導入履歴（2.1.312・2.1.313）を確認する。
  参照: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension

SOC-2026-11-15-001 [medium] Cursor 利用組織：2.1.312・2.1.313 導入端末の確認と、AI 開発基盤に預けた認証情報の棚卸し
------------------------------------------------------------
対象: Cursor・Claude Code 拡張・AI 基盤事業者連携

【概要】
Cursor は、改ざん版 Claude Code 拡張（2.1.312・2.1.313）の配布と、Fireworks AI 経由の認証情報窃取による内部データの流出を認めた。履歴に平文の API 認証情報が残っていた例があるとされ、AI エージェントに渡した秘密情報の扱いが論点になる。

【推奨アクション】
1) 10-29 前後に Cursor で Claude Code 拡張を導入・更新した端末で、拡張のバージョンと authorized_keys・sshd の状態を確認する。2) AI コーディングエージェントに貼り付けた API キーを洗い出して更新し、Privacy Mode の有効化を方針化する。3) サポートへ共有した認証情報があれば失効させる。

【監視】
開発端末での sshd の有効化と authorized_keys の変更、AI エージェント経由で使われた API キーの異常な利用元を監視する。
参照: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension
