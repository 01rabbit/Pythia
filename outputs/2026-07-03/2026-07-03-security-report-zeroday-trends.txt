・ToddyCat（別名: なし / 国家帰属: CN / 帰属信頼度: medium）
活動概要: 中国nexusのAPTグループToddyCatが、パスワードを窃取せずOAuth経由でGmailへアクセスする新規ツール「Umbrij」（.NET製）を使用していることをKaspersky GReATが報告した（Securelist初報2026-06-30、The Hacker Newsが2026-07-02に追跡報道）。手口（Shadow Token via Remote Debug）は、被害者のChromium系ブラウザをリモートデバッグポート有効でヘッドレス起動し、Puppeteer-Sharpで操作してGoogleのOAuth同意画面へ遷移、Gmail/Drive/Contacts/Calendar/Tasksへのスコープを持つ偽装アプリ（「Google Workspace Migration for Microsoft Outlook」等を詐称）への同意をクリック操作で自動化し、認可コードを取得してアクセストークンに交換する。既にログイン済みのGmailセッションに便乗するためパスワード窃取を伴わない。署名済みバイナリへのDLLサイドローディング（BDSubWiz.exe→log.dll 等）で配布され、explorer.exeのプロセストークン複製でユーザーコンテキストを取得する（旧ツールTomBerBilと同一手口）。（推測）本ツールの初回開示は2026-06-30であり、当パイプラインでは本日（バックフィル対象日）が初めての捕捉となる。
推奨アクション: 組織のGoogle Workspace管理コンソールでOAuthクライアントID 279448736670・1095133494869（いずれも「Google Workspace Migration/Sync for Microsoft Outlook」を詐称）からの認可を確認し、不審な同意があれば取り消す。BDSubWiz.exe・VSTestVideoRecorder.exe・GoogleDesktop.exe等の署名済みバイナリと同ディレクトリに不審なDLL（log.dll等）がないか確認する。
参照: https://securelist.com/toddycat-apt-umbrij-tool-and-oauth/120251/

・[トレンド記事] Google・FBIが2百万台超のNetNut(Popa)住宅用プロキシネットワークを摘発
Google Threat Intelligence Group（GTIG）はFBI・Lumen等と連携し、住宅用プロキシネットワーク「NetNut」（別名Popa）を摘発した。スマートTV・ストリーミングボックス等の家庭用デバイスに組み込まれたSDK経由でMirai系DDoSマルウェアに感染させ、少なくとも200万台規模のボットネットを構築していた。GTIGは大規模ボットネット「Badbox 2.0」との関連コンポーネントも確認。2026年6月の1週間で316件の異なる脅威クラスタ（サイバー犯罪グループ・国家系スパイ活動グループ双方）がNetNut出口ノードを悪用していたことを観測した。GoogleはC2に悪用されたGoogleアカウント・サービスを無効化。FBIはプラットフォームを押収した。
参照: https://cloud.google.com/blog/topics/threat-intelligence/google-continued-disruption-residential-proxy-networks/

・[トレンド記事] ConsentFixとClickFix: わずか3秒でM365アカウントを乗っ取る新手口
BleepingComputerは、OAuth同意フィッシング（ConsentFix）とClickFix型のクリップボード注入攻撃を組み合わせ、Microsoft 365アカウントをわずか3秒程度で乗っ取る新手口を報じた。被害者が偽の確認プロンプトに従い自らクリップボードにコピーしたコマンドを実行することで、攻撃者は多要素認証を経ずにアカウントへ持続的アクセスを確保する。
参照: https://www.bleepingcomputer.com/news/security/consentfix-and-clickfix-how-microsoft-365-accounts-are-hijacked-in-3-seconds/
