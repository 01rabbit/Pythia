1. CVE-2026-106931 EG Secure SiteGuard Server Edition（統計機能の OS コマンドインジェクション）（CVSS v4.0 8.5 / v3 7.8）
------------------------------------------------------------
優先度: high  軸1=10 軸2=4  KEV登録: なし  悪用: あり（ベンダー確認・報道）  パッチ: あり
影響バージョン: 統計機能が有効な構成（既定で有効）。Apache httpd／Nginx／IIS 版（FreeBSD 除く）は 2.20 以降〜8.00 Update 5 未満、FreeBSD の Apache httpd／Nginx 版は 2.20 以降〜7.00 Update 6 未満。IIS 版 3.10〜4.00 Update 4 は対象外（BleepingComputer 経由・JPCERT/CC 記載）

【24時間以内の変化】
[BleepingComputer 2026-10-18] 英語圏で初報。攻撃者が root／SYSTEM 権限で任意コマンドを実行できる状態で悪用中と報道。攻撃者・被害者・規模・手口は不明。修正後に痕跡が消える恐れがあるため、事前に管理画面から『診断情報』を取得するようベンダーが警告。KEV 収載はなし（カタログ版 2026.10.16）。

【概要】
国産 WAF「SiteGuard Server Edition」の統計機能の OS コマンドインジェクション CVE-2026-106931（CVSS v4.0 8.5 / v3.0 7.8）について、BleepingComputer が悪用中と報じた（10-15 に既報の続報）。root／SYSTEM 権限でコマンドが実行される。攻撃者・被害者・規模・手口は不明。IOC は報道・参照した勧告に記載なし。2026-09-29 にベンダーが契約者へ個別通知済み、10-14 に公開アドバイザリと JPCERT/CC 注意喚起（AT-2026-0032）。KEV 収載なし。

【攻撃フロー】
1. 統計機能に対する細工リクエストで OS コマンドを注入
2. root（Apache/Nginx 版）または SYSTEM（IIS 版）で任意コマンドが実行される

【暫定緩和策】
- ベンダー（EG-Secure）のアドバイザリに従い修正版へ更新する
- 更新までは統計機能の無効化など、ベンダー案内の回避策を適用する
- JPCERT/CC 注意喚起とベンダー案内の IOC・確認方法を参照して侵害調査を行う

【監視】
SiteGuard の統計機能に関連するリクエストと、WAF ホスト上の不審な子プロセスを確認する。修正適用前に管理画面の診断情報を保全する。

【参照】
- Hackers exploit SiteGuard WAF flaw to run commands as admins (BleepingComputer) https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root
- 国産WAF「SiteGuard Server Edition」に脆弱性 - 悪用も確認 (Security NEXT) https://www.security-next.com/191420
- 注意喚起: SiteGuard Server EditionにおけるOSコマンドインジェクションの脆弱性（CVE-2026-106931）に関する注意喚起 (JPCERT/CC) https://www.jpcert.or.jp/at/2026/at260032.html

------------------------------------------------------------
対象: EG Secure SiteGuard Server Edition（Apache／Nginx／IIS 版）

【24時間以内の変化】
[BleepingComputer 2026-10-18] 悪用中と英語圏で報道。修正により攻撃痕跡が消える恐れがあるとしてベンダーが診断情報の事前取得を警告。

【監視】
SiteGuard の統計処理に関連するリクエストと、WAF プロセス配下の想定外の子プロセスを監視する。
