SOC-2026-10-19-001 SiteGuard Server Edition の統計機能 OS コマンドインジェクション（CVE-2026-106931）— 修正適用前に診断情報を保全
------------------------------------------------------------
対象: EG Secure SiteGuard Server Edition（Apache／Nginx／IIS 版）

【24時間以内の変化】
[BleepingComputer 2026-10-18] 悪用中と英語圏で報道。修正により攻撃痕跡が消える恐れがあるとしてベンダーが診断情報の事前取得を警告。

【概要】
統計機能が有効（既定）の構成が対象で、悪用されると root／SYSTEM 権限でコマンドが実行される。ベンダーは 9月29日に契約者へ通知済みで、公開は 10-14。攻撃者・規模は不明で、KEV 収載はない。
【推奨アクション】
- 対象バージョン（8.00 Update 5 未満／FreeBSD 版は 7.00 Update 6 未満）かを確認する
- 更新・パッチ適用の前に、管理画面から『診断情報』をダウンロードして保全する
- ベンダー提供の修正版またはパッチを適用する（EOL 版にもパッチあり）
- WAF ホストで不審な子プロセス・新規ファイル・外向き通信を点検する（侵害済みの可能性を前提とする）
【監視】
SiteGuard の統計処理に関連するリクエストと、WAF プロセス配下の想定外の子プロセスを監視する。

【参照】
- Hackers exploit SiteGuard WAF flaw to run commands as admins (BleepingComputer) https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root
- 注意喚起: SiteGuard Server Edition の OS コマンドインジェクション (JPCERT/CC) https://www.jpcert.or.jp/at/2026/at260032.html
