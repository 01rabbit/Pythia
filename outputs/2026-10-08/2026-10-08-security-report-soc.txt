1. Splunk Enterprise: サーチヘッドクラスタメンバーの Patroni REST API に未認証 OS コマンド実行（CVE-2026-76268・CVSS 9.8）ほか集約 CVE（CVE-2026-76284）— 10.4.3 / 10.2.7 / 10.0.10 / 9.4.15 で修正
観点: CVE関連
採用契機: η, β
------------------------------------------------------------

優先度: 高
対象: Splunk Enterprise 10.4.3 / 10.2.7 未満（CVE-2026-76268）、10.4.3 / 10.2.7 / 10.0.10 / 9.4.15 で修正される内部発見脆弱性群（CVE-2026-76284）

【24時間以内の変化】
[NVD（Cisco PSIRT） 2026-10-08 06:17] CVE-2026-76268（サーチヘッドクラスタメンバーの Patroni REST API にネットワーク到達できる未認証ユーザーが攻撃者制御の OS コマンドを実行可能・重要な構成操作に認証が不要・CVSS 9.8）と CVE-2026-76284（CWE 単位でグループ化された複数の内部発見脆弱性・CVSS 9.8）が NVD に新規公開。

【概要】
SIEM 製品そのものの重大脆弱性。Splunk Enterprise 10.4.3 / 10.2.7 未満では、サーチヘッドクラスタ（SHC）メンバー上の Patroni REST API が重要な構成操作に認証を要求せず、ネットワーク到達可能な未認証ユーザーが OS コマンドを実行できる（CVE-2026-76268・NVD 記載）。あわせて 10.4.3 / 10.2.7 / 10.0.10 / 9.4.15 で修正される内部発見の脆弱性群が CVE-2026-76284 として公開された。Splunk Enterprise の未認証 RCE は 2026年6月に CVE-2026-20253（PostgreSQL サイドカー）が KEV に追加された前例があり（既報事実）、SOC 基盤の侵害はログ改ざん・検知回避に直結する。本窓で報道・悪用・PoC・KEV 登録は確認されておらず、Section 3 の軸1は7点で閾値未満のため、SIEM 製品の脆弱性（η）として SOC 推奨の高優先度に置く。

【推奨アクション】
・今日中に SHC メンバーの Splunk Enterprise バージョンを確認し、10.4.3 / 10.2.7（9.4 系は 9.4.15・10.0 系は 10.0.10）以降へ更新計画を確定する
・更新までの間、Patroni REST API（既定 TCP 8008）および SHC メンバー間通信ポートへの到達元を SHC メンバーとデプロイヤに限定する（ホストファイアウォール/セグメント ACL）
・Splunk ホストで splunkd / patroni を親とする予期しないシェル起動を監査する
・[監視] Splunk サーバ自身の OS 監査ログで、splunkd・patroni・postgres プロセスを親とするシェル・ネットワークツールの実行と、TCP 8008 への SHC メンバー以外からの接続を確認する。
Splunk SPL: index=linux sourcetype=auditd host IN (<SHCメンバー>) (parent_comm="patroni*" OR parent_comm="splunkd" OR parent_comm="postgres") (comm="sh" OR comm="bash" OR comm="curl" OR comm="wget" OR comm="python*") | stats count by host, parent_comm, comm, cmdline
Splunk SPL: index=firewall dest_ip IN (<SHCメンバー>) dest_port=8008 NOT src_ip IN (<SHCメンバー>,<デプロイヤ>) | stats count by src_ip, dest_ip
→ patroni の正規ヘルスチェックは SHC メンバー間のみ。それ以外からの 8008 到達は構成不備または攻撃。
